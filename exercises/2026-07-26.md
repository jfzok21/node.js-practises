# 第 3 週今日練習題：Express 路由參數與查詢字串

## 題目說明

建立一個簡單的「商品目錄 API」，透過路由參數（`:id`）查詢特定商品，並透過查詢字串（`?search=`、`?category=`、`?sort=`）篩選與排序商品列表。本題目重點在熟悉 Express 的動態路由與 `req.params`、`req.query` 的使用方式。

---

## 技術要求

- **Express.js**：使用路由參數（`req.params`）與查詢字串（`req.query`）處理不同的請求情境
- **PostgreSQL**：建立 `products` 資料表，並使用 `WHERE`、`LIKE`、`ORDER BY` 等 SQL 語法根據查詢條件篩選資料

---

## 具體任務

### 1. 建立資料庫結構

建立 `products` 資料表，欄位如下：

```sql
CREATE TABLE products (
  id SERIAL PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  category VARCHAR(50) NOT NULL,
  price NUMERIC(10, 2) NOT NULL,
  stock INTEGER NOT NULL DEFAULT 0,
  created_at TIMESTAMP DEFAULT NOW()
);
```

並插入至少 10 筆測試資料（涵蓋不同 category，如 `electronics`、`clothing`、`food`）。

### 2. 建立路由：取得全部商品（含篩選與排序）

**`GET /products`**

支援以下查詢字串：

| 參數 | 說明 | 範例 |
|------|------|------|
| `search` | 依商品名稱模糊搜尋 | `?search=手機` |
| `category` | 依分類篩選 | `?category=electronics` |
| `sort` | 排序欄位（`price` 或 `name`）| `?sort=price` |
| `order` | 排序方向（`asc` 或 `desc`，預設 `asc`）| `?order=desc` |

回應格式：
```json
{
  "total": 3,
  "products": [
    { "id": 1, "name": "無線耳機", "category": "electronics", "price": "1299.00", "stock": 50 }
  ]
}
```

### 3. 建立路由：取得單一商品

**`GET /products/:id`**

- 若找到商品，回傳該筆資料（HTTP 200）
- 若 `id` 不是正整數，回傳 `400 Bad Request`（錯誤訊息：`"id 必須為正整數"`）
- 若查無資料，回傳 `404 Not Found`（錯誤訊息：`"找不到 id 為 [id] 的商品"`）

### 4. 建立路由：取得特定分類的所有商品

**`GET /categories/:category/products`**

- 依 URL 中的分類名稱查詢並回傳該分類商品列表
- 若該分類無任何商品，回傳空陣列（HTTP 200）而非 404

### 5. 輸入驗證

- `sort` 只允許 `price` 或 `name`，其餘值忽略（改用預設排序）
- `order` 只允許 `asc` 或 `desc`，其餘值視為 `asc`
- `id` 路由參數須驗證為正整數

---

## 提示

- 使用 `req.params.id` 取得路由參數，記得用 `parseInt()` 轉換並驗證是否為正整數
- 使用 `req.query.search`、`req.query.category` 等取得查詢字串，它們的值皆為字串型別
- SQL 模糊搜尋可使用 `ILIKE '%${keyword}%'`（PostgreSQL 不分大小寫版本的 LIKE）
- 為避免 SQL Injection，請使用 parameterized query（`$1`, `$2` 佔位符）而非字串拼接
- 動態組合 SQL WHERE 條件時，可考慮用陣列收集條件再以 `AND` 合併：

```js
const conditions = [];
const values = [];

if (search) {
  values.push(`%${search}%`);
  conditions.push(`name ILIKE $${values.length}`);
}
if (category) {
  values.push(category);
  conditions.push(`category = $${values.length}`);
}

const whereClause = conditions.length > 0
  ? `WHERE ${conditions.join(' AND ')}`
  : '';
```

## 進階挑戰（選做）

1. **分頁支援**：在 `GET /products` 加上 `?page=1&limit=5` 參數，並在回應中包含 `page`、`limit`、`totalPages` 資訊。

2. **多欄位排序**：支援 `?sort=price,name` 同時依多個欄位排序（逗號分隔）。

3. **價格區間篩選**：支援 `?min_price=100&max_price=500` 篩選特定價格區間的商品。

4. **統計端點**：新增 `GET /categories/stats` 回傳各分類的商品數量與平均價格：
   ```json
   [
     { "category": "electronics", "count": 5, "avg_price": "3200.00" }
   ]
   ```
