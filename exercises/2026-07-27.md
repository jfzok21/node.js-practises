# 第 3 週今日練習題：Express 路由參數與查詢字串

## 題目說明

建立一個簡單的「書籍管理 API」，練習使用 Express 的路由參數（`:id`）與查詢字串（`?search=`、`?sort=`）來篩選與取得資料。本週不需要連接真實資料庫，使用記憶體內的陣列模擬資料即可。

---

## 技術要求

- **Express.js**：定義含路由參數的路徑（`/books/:id`）、解析查詢字串（`req.query`）、回傳 JSON 回應
- **PostgreSQL**：本週不強制連線，但可選擇性地將書籍資料存入 DB 並從中查詢

---

## 具體任務

1. **初始化專案**
   - 建立 `week3/` 資料夾，執行 `npm init -y` 並安裝 `express`
   - 建立 `app.js` 作為主程式入口

2. **準備測試資料**
   在 `app.js` 中建立一個陣列作為假資料：
   ```js
   const books = [
     { id: 1, title: 'Node.js 實戰', author: 'Alice', genre: 'tech', year: 2022 },
     { id: 2, title: '乾淨架構', author: 'Bob', genre: 'tech', year: 2018 },
     { id: 3, title: '百年孤寂', author: 'García Márquez', genre: 'fiction', year: 1967 },
     { id: 4, title: '深夜加油站遇見蘇格拉底', author: 'Dan Millman', genre: 'self-help', year: 1980 },
   ];
   ```

3. **實作以下路由**

   | 方法 | 路徑 | 說明 |
   |------|------|------|
   | GET | `/books` | 回傳所有書籍 |
   | GET | `/books/:id` | 依 ID 回傳單本書；找不到回傳 404 |
   | GET | `/books?search=關鍵字` | 依書名或作者模糊搜尋 |
   | GET | `/books?genre=tech` | 依類型篩選 |
   | GET | `/books?sort=year` | 依出版年份排序（升冪） |

   > 查詢字串可同時組合，例如：`/books?genre=tech&sort=year`

4. **錯誤處理**
   - ID 不是數字時，回傳 `400 Bad Request`
   - 找不到書籍時，回傳 `404 Not Found`，附帶 `{ error: "Book not found" }`

5. **測試你的 API**
   使用 `curl` 或 Postman 測試：
   ```bash
   curl http://localhost:3000/books
   curl http://localhost:3000/books/2
   curl "http://localhost:3000/books?search=node"
   curl "http://localhost:3000/books?genre=tech&sort=year"
   curl http://localhost:3000/books/999   # 應回傳 404
   curl http://localhost:3000/books/abc   # 應回傳 400
   ```

---

## 提示

- 使用 `req.params.id` 取得路由參數（注意型別是字串，需用 `parseInt()` 轉換）
- 使用 `req.query.search` 取得查詢字串
- 模糊搜尋可用 `String.includes()` 或 `toLowerCase()` 配合比對
- 多個查詢條件可用 `if (req.query.xxx)` 依序套用篩選
- 排序可用 `Array.sort()` 搭配比較函式

---

## 進階挑戰（選做）

- **分頁**：加入 `?page=1&limit=2` 查詢字串，每次只回傳指定數量的結果
- **新增書籍**：實作 `POST /books`，接收 JSON body 並 push 進陣列（需使用 `express.json()` middleware）
- **連接 PostgreSQL**：將假資料改存入 PostgreSQL，並將篩選邏輯改為 SQL 查詢（使用 `WHERE`、`ILIKE`、`ORDER BY`）
