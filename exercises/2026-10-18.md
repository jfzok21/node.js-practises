# 第 15 週今日練習題：部落格 API 實戰專案

## 題目說明

建立一個完整的部落格後端 REST API，整合 Express.js 與 PostgreSQL，實作文章管理與評論系統，並加入 JWT 身份驗證與完整的錯誤處理機制。

## 技術要求

- **Express.js**：RESTful 路由設計、Middleware 架構、錯誤處理中介層
- **PostgreSQL**：多資料表設計（users、posts、comments）、JOIN 查詢、交易處理
- **JWT**：使用者登入/註冊、受保護路由
- **資料驗證**：輸入驗證與統一錯誤回應格式

## 具體任務

### 資料庫設計

1. 建立以下三張資料表：
   ```sql
   -- 使用者表
   CREATE TABLE users (
     id SERIAL PRIMARY KEY,
     username VARCHAR(50) UNIQUE NOT NULL,
     email VARCHAR(100) UNIQUE NOT NULL,
     password_hash TEXT NOT NULL,
     created_at TIMESTAMP DEFAULT NOW()
   );

   -- 文章表
   CREATE TABLE posts (
     id SERIAL PRIMARY KEY,
     author_id INTEGER REFERENCES users(id) ON DELETE CASCADE,
     title VARCHAR(200) NOT NULL,
     content TEXT NOT NULL,
     published BOOLEAN DEFAULT false,
     created_at TIMESTAMP DEFAULT NOW(),
     updated_at TIMESTAMP DEFAULT NOW()
   );

   -- 評論表
   CREATE TABLE comments (
     id SERIAL PRIMARY KEY,
     post_id INTEGER REFERENCES posts(id) ON DELETE CASCADE,
     author_id INTEGER REFERENCES users(id) ON DELETE CASCADE,
     content TEXT NOT NULL,
     created_at TIMESTAMP DEFAULT NOW()
   );
   ```

### API 端點實作

2. **身份驗證路由** (`/api/auth`)
   - `POST /api/auth/register` — 註冊新使用者（bcrypt 加密密碼）
   - `POST /api/auth/login` — 登入，回傳 JWT token

3. **文章路由** (`/api/posts`)
   - `GET /api/posts` — 取得所有已發布文章（含作者名稱、評論數量）
   - `GET /api/posts/:id` — 取得單篇文章（含作者資訊與所有評論）
   - `POST /api/posts` — 建立新文章（需驗證 JWT）
   - `PUT /api/posts/:id` — 更新文章（只有作者可修改）
   - `DELETE /api/posts/:id` — 刪除文章（只有作者可刪除）

4. **評論路由** (`/api/posts/:postId/comments`)
   - `GET /api/posts/:postId/comments` — 取得文章的所有評論
   - `POST /api/posts/:postId/comments` — 新增評論（需驗證 JWT）
   - `DELETE /api/posts/:postId/comments/:commentId` — 刪除評論（只有評論作者可刪除）

### Middleware 設計

5. 實作以下中介層：
   - `authMiddleware`：驗證 JWT，將 `req.user` 注入使用者資訊
   - `validatePost`：驗證 title（必填，最少 5 字）、content（必填，最少 20 字）
   - `errorHandler`：統一錯誤格式 `{ error: string, statusCode: number }`

### 查詢最佳化

6. 在 `GET /api/posts` 使用 JOIN 查詢，一次取得文章列表、作者姓名、以及每篇文章的評論數量，避免 N+1 查詢問題。

## 提示

- 使用 `pg` 套件連線 PostgreSQL，建議建立 `db/pool.js` 集中管理連線池
- JWT 密鑰存放於 `.env`，使用 `dotenv` 載入
- 密碼使用 `bcrypt`（rounds: 10）加密，切勿明文儲存
- 路由結構建議：`routes/auth.js`、`routes/posts.js`、`routes/comments.js`
- 更新文章時記得同步更新 `updated_at` 欄位
- 可用 Postman 或 Thunder Client 測試 API

## 進階挑戰（選做）

1. **分頁功能**：為 `GET /api/posts` 加入 `?page=1&limit=10` 查詢參數
2. **全文搜尋**：加入 `?search=關鍵字` 支援以標題模糊搜尋文章
3. **文章草稿**：允許作者將文章儲存為草稿（`published: false`），並提供 `PATCH /api/posts/:id/publish` 發布端點
4. **交易處理**：刪除文章時，在同一個 Transaction 中同步刪除所有關聯評論，確保資料一致性
5. **速率限制**：使用 `express-rate-limit` 限制每個 IP 每分鐘最多 60 次請求
