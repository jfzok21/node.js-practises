# 第 3 週今日練習題：Express 路由參數與查詢字串

## 題目說明

建立一個簡易「圖書館書籍管理 API」，學習如何透過路由參數（`:id`）取得特定資源，以及透過查詢字串（`?search=`、`?genre=`、`?limit=`）進行篩選、搜尋與分頁，讓 API 更靈活實用。

---

## 技術要求

- **Express.js**：路由參數（`req.params`）、查詢字串（`req.query`）、路由模組化
- **PostgreSQL**：動態 SQL 查詢、參數化查詢（防 SQL injection）、`LIKE` 模糊搜尋、`LIMIT` / `OFFSET` 分頁

---

## 具體任務

### 1. 初始化資料庫

建立 `books` 資料表並插入測試資料：

```sql
CREATE TABLE IF NOT EXISTS books (
  id SERIAL PRIMARY KEY,
  title VARCHAR(200) NOT NULL,
  author VARCHAR(100) NOT NULL,
  genre VARCHAR(50),
  published_year INT,
  available BOOLEAN DEFAULT true
);

INSERT INTO books (title, author, genre, published_year) VALUES
  ('JavaScript 全攻略', '張三', '技術', 2023),
  ('Node.js 實戰', '李四', '技術', 2022),
  ('設計模式', '王五', '技術', 2021),
  ('百年孤寂', '馬奎斯', '文學', 1967),
  ('小王子', '聖修伯里', '文學', 1943),
  ('深夜加油站遇見蘇格拉底', '米爾曼', '勵志', 2000);
```

### 2. 建立取得單本書籍路由（路由參數）

```
GET /api/books/:id
```

- 從 `req.params.id` 取得書籍 ID
- 若書籍不存在，回傳 `404` 與 `{ error: "找不到此書籍" }`
- 若 `id` 非正整數，回傳 `400` 與 `{ error: "無效的書籍 ID" }`

### 3. 建立書籍列表路由（查詢字串）

```
GET /api/books
```

支援以下查詢字串參數：

| 參數 | 說明 | 範例 |
|------|------|------|
| `search` | 依書名或作者模糊搜尋 | `?search=JavaScript` |
| `genre` | 依類型篩選 | `?genre=技術` |
| `available` | 篩選是否可借閱 | `?available=true` |
| `limit` | 每頁筆數（預設 10，最大 50） | `?limit=3` |
| `page` | 頁碼（預設 1） | `?page=2` |

回傳格式：
```json
{
  "data": [...],
  "pagination": {
    "page": 1,
    "limit": 10,
    "total": 6
  }
}
```

### 4. 建立更新書籍可借狀態路由

```
PATCH /api/books/:id/availability
```

- 接收 body `{ "available": true/false }`
- 更新指定書籍的 `available` 欄位
- 回傳更新後的書籍資料

### 5. 參數驗證

- `limit` 超過 50 時，自動限制為 50
- `page` 小於 1 時，回傳 `400`
- `id` 不是數字時，回傳明確的錯誤訊息

---

## 提示

- 使用 `parseInt(req.params.id)` 轉型，並用 `isNaN()` 驗證
- `req.query` 取得的值都是**字串型別**，數字參數需要轉型
- 動態組合 SQL 時，用陣列收集條件，再用 `WHERE` + `AND` 串接：
  ```js
  const conditions = [];
  const values = [];
  if (search) {
    conditions.push(`(title ILIKE $${values.length + 1} OR author ILIKE $${values.length + 2})`);
    values.push(`%${search}%`, `%${search}%`);
  }
  const whereClause = conditions.length ? `WHERE ${conditions.join(' AND ')}` : '';
  ```
- 分頁計算：`OFFSET = (page - 1) * limit`
- 可使用 `COUNT(*) OVER()` 在同一次查詢中取得總筆數
