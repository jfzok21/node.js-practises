# 第 5 週今日練習題：多資料表 JOIN 查詢與關聯設計

## 題目說明

本週主題是 PostgreSQL 的 JOIN 查詢與多資料表關聯。你將建立一個簡易的「部落格文章系統」，包含使用者（users）、文章（posts）、留言（comments）三張資料表，並透過 Express API 回傳關聯查詢結果。

## 技術要求

- **Express.js**：建立 RESTful API 路由，並正確使用路由參數（`:id`）
- **PostgreSQL**：使用 INNER JOIN、LEFT JOIN 查詢多資料表，並設計外鍵（FOREIGN KEY）關聯

## 具體任務

1. **建立資料表結構（Schema）**

   建立以下三張資料表，並在 `schema.sql` 中定義：

   ```sql
   -- 使用者資料表
   CREATE TABLE users (
     id SERIAL PRIMARY KEY,
     username VARCHAR(50) NOT NULL UNIQUE,
     email VARCHAR(100) NOT NULL UNIQUE,
     created_at TIMESTAMP DEFAULT NOW()
   );

   -- 文章資料表
   CREATE TABLE posts (
     id SERIAL PRIMARY KEY,
     user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
     title VARCHAR(200) NOT NULL,
     content TEXT,
     created_at TIMESTAMP DEFAULT NOW()
   );

   -- 留言資料表
   CREATE TABLE comments (
     id SERIAL PRIMARY KEY,
     post_id INTEGER NOT NULL REFERENCES posts(id) ON DELETE CASCADE,
     user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
     body TEXT NOT NULL,
     created_at TIMESTAMP DEFAULT NOW()
   );
   ```

2. **新增測試資料**

   使用 `INSERT` 插入至少 3 筆使用者、5 篇文章、8 則留言的範例資料。

3. **實作以下 API 端點**

   | 方法 | 路由 | 說明 |
   |------|------|------|
   | GET | `/posts` | 取得所有文章，並帶出作者名稱（JOIN users） |
   | GET | `/posts/:id` | 取得單篇文章詳情（含作者資訊） |
   | GET | `/posts/:id/comments` | 取得某篇文章的所有留言，並帶出留言者名稱 |
   | GET | `/users/:id/posts` | 取得某位使用者的所有文章 |

4. **每個端點的回應範例**

   `GET /posts` 回應格式：
   ```json
   [
     {
       "id": 1,
       "title": "第一篇文章",
       "author": "alice",
       "created_at": "2026-08-06T10:00:00.000Z"
     }
   ]
   ```

   `GET /posts/:id/comments` 回應格式：
   ```json
   [
     {
       "id": 1,
       "body": "很棒的文章！",
       "commenter": "bob",
       "created_at": "2026-08-06T11:00:00.000Z"
     }
   ]
   ```

## 提示

- 使用 `INNER JOIN` 來確保文章一定有對應作者：
  ```sql
  SELECT posts.id, posts.title, users.username AS author, posts.created_at
  FROM posts
  INNER JOIN users ON posts.user_id = users.id;
  ```
- 若想允許作者已被刪除的文章仍然顯示，可改用 `LEFT JOIN`
- 在 Express 中透過 `req.params.id` 取得路由參數，並以 `$1` 傳入 SQL 查詢以防 SQL Injection：
  ```js
  const result = await pool.query(
    'SELECT * FROM posts WHERE id = $1',
    [req.params.id]
  );
  ```
- 若查無資料（`result.rows.length === 0`），應回傳 404 狀態碼

## 進階挑戰（選做）

1. **留言數統計**：在 `GET /posts` 的回應中加入每篇文章的留言總數（使用 `LEFT JOIN` + `COUNT` + `GROUP BY`）

   ```sql
   SELECT posts.id, posts.title, users.username AS author,
          COUNT(comments.id) AS comment_count
   FROM posts
   INNER JOIN users ON posts.user_id = users.id
   LEFT JOIN comments ON comments.post_id = posts.id
   GROUP BY posts.id, users.username
   ORDER BY posts.created_at DESC;
   ```

2. **巢狀回應**：在 `GET /posts/:id` 中同時回傳文章資訊與所有留言（在單一 API 回應中組合兩次查詢結果）

3. **分類標籤**：新增 `tags` 資料表與 `post_tags` 關聯表，實作多對多關係，並在文章查詢中帶出標籤列表
