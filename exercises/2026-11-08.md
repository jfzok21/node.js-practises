# 第 18 週今日練習題：書籍借閱管理系統 API

## 題目說明

實作一個完整的書籍借閱管理系統後端 API，結合 Express.js 與 PostgreSQL，模擬圖書館的借書與還書流程。本題整合先前所學的路由設計、資料庫操作、JWT 驗證、資料驗證與交易處理。

---

## 技術要求

- **Express.js**：RESTful API 設計，路由模組化，錯誤處理中介層
- **PostgreSQL**：多資料表關聯（書籍、使用者、借閱記錄），交易確保資料一致性

---

## 資料庫 Schema

```sql
CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(150) UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE books (
  id SERIAL PRIMARY KEY,
  title VARCHAR(200) NOT NULL,
  author VARCHAR(100) NOT NULL,
  isbn VARCHAR(20) UNIQUE NOT NULL,
  total_copies INT NOT NULL DEFAULT 1,
  available_copies INT NOT NULL DEFAULT 1,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE borrowings (
  id SERIAL PRIMARY KEY,
  user_id INT REFERENCES users(id),
  book_id INT REFERENCES books(id),
  borrowed_at TIMESTAMP DEFAULT NOW(),
  due_date TIMESTAMP NOT NULL,
  returned_at TIMESTAMP,
  status VARCHAR(20) DEFAULT 'active' -- 'active' | 'returned' | 'overdue'
);
```

## 具體任務

### 1. 環境設定
- 建立 `.env` 管理 `DATABASE_URL`、`JWT_SECRET`、`PORT`
- 建立資料庫連線模組 `src/db.js`（使用 `pg` 套件的 Pool）
- 初始化 Schema，並插入至少 5 筆書籍測試資料

### 2. 使用者模組 `src/routes/users.js`
- `POST /api/register`：註冊（name、email、password），密碼以 `bcrypt` 雜湊後存入
- `POST /api/login`：驗證帳密，回傳 JWT（有效期 24 小時）

### 3. 書籍模組 `src/routes/books.js`（需 JWT 驗證）
- `GET /api/books`：列出所有書籍，支援 `?search=` 關鍵字搜尋書名或作者
- `GET /api/books/:id`：取得單一書籍詳情
- `GET /api/books?available=true`：只列出有庫存的書籍

### 4. 借閱模組 `src/routes/borrowings.js`（需 JWT 驗證）
- `POST /api/borrow`：借書
  - 請求 body：`{ book_id, due_days }` （due_days 預設 14 天）
  - 使用 **Transaction**：
    1. 確認書籍 `available_copies > 0`，否則回傳 409
    2. 新增 borrowings 記錄
    3. 將 `books.available_copies - 1`
  - 同一使用者不可重複借閱同一本書（返回前需檢查）
- `POST /api/return/:borrowing_id`：還書
  - 使用 **Transaction**：
    1. 確認該借閱記錄屬於當前使用者
    2. 更新 `borrowings.returned_at`、`status = 'returned'`
    3. 將 `books.available_copies + 1`
- `GET /api/my-borrowings`：查詢當前使用者的借閱清單（含書籍資訊，使用 JOIN）
- `GET /api/my-borrowings?status=active`：過濾借閱中 / 已歸還

### 5. 管理員功能（選做）
- `POST /api/books`：新增書籍（需 role = admin 的 JWT）
- `GET /api/admin/overdue`：查詢所有逾期未還的借閱（`due_date < NOW()` 且 `status = 'active'`）

## 提示

- 使用 `express-validator` 或手動驗證 request body，缺少欄位一律回傳 400
- JWT 中介層放在 `src/middleware/auth.js`，驗證失敗回傳 401
- Transaction 寫法：
  ```js
  const client = await pool.connect();
  try {
    await client.query('BEGIN');
    // ... 多個 query
    await client.query('COMMIT');
  } catch (err) {
    await client.query('ROLLBACK');
    throw err;
  } finally {
    client.release();
  }
  ```
- 錯誤處理中介層放在所有路由之後，統一格式：
  ```json
  { "error": "訊息", "code": "ERROR_CODE" }
  ```
- 借書時計算 due_date：`NOW() + INTERVAL '[due_days] days'`

## 進階挑戰（選做）

1. **逾期自動更新**：撰寫一個定時任務（`node-cron`），每小時檢查並將逾期借閱的 `status` 改為 `'overdue'`
2. **分頁**：`GET /api/books` 加入 `?page=1&limit=10` 分頁支援
3. **借閱歷史統計**：`GET /api/stats`，回傳每本書的借閱次數排行榜（使用聚合查詢 `GROUP BY` + `ORDER BY`）
4. **單元測試**：使用 `supertest + Jest` 測試借書與還書流程，包含邊界情況（庫存為 0、重複借閱）
