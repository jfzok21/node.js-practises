# 第 8 週今日練習題：使用 Multer 實作多類型檔案上傳 API

## 題目說明

建立一個支援圖片與文件上傳的 Express API 服務。使用者可以上傳個人頭像（單一圖片）與專案附件（多個檔案），並將檔案元資料（原始名稱、儲存路徑、大小、MIME 類型）存入 PostgreSQL，方便後續查詢管理。

---

## 技術要求

- **Express.js**：
  - 建立 `POST /upload/avatar` 路由（單檔上傳）
  - 建立 `POST /upload/attachments` 路由（多檔上傳，最多 5 個）
  - 建立 `GET /files` 路由（查詢所有已上傳檔案）
  - 建立 `DELETE /files/:id` 路由（刪除檔案記錄與實體檔案）
- **PostgreSQL**：
  - 建立 `uploaded_files` 資料表儲存檔案元資料
  - 以 `pg` 套件操作資料庫

---

## 具體任務

1. **建立資料庫資料表**

   執行以下 SQL 建立資料表：

   ```sql
   CREATE TABLE IF NOT EXISTS uploaded_files (
     id        SERIAL PRIMARY KEY,
     field     VARCHAR(50)  NOT NULL,
     original_name VARCHAR(255) NOT NULL,
     stored_name   VARCHAR(255) NOT NULL,
     mimetype  VARCHAR(100) NOT NULL,
     size      INTEGER      NOT NULL,
     created_at TIMESTAMPTZ DEFAULT NOW()
   );
   ```

2. **設定 Multer 儲存引擎**

   使用 `multer.diskStorage` 將檔案儲存到 `uploads/` 目錄，並以 `Date.now() + '-' + originalname` 命名，避免衝突。

   ```js
   const storage = multer.diskStorage({
     destination: (req, file, cb) => cb(null, 'uploads/'),
     filename: (req, file, cb) => cb(null, `${Date.now()}-${file.originalname}`)
   });
   ```

3. **加入副檔名過濾器**

   只允許 `image/jpeg`、`image/png`、`application/pdf` 三種 MIME 類型，其餘一律回傳 400 錯誤。

4. **實作上傳路由**

   - `POST /upload/avatar`：使用 `upload.single('avatar')`，上傳成功後將元資料 INSERT 進資料庫，回傳 `201` 及新記錄。
   - `POST /upload/attachments`：使用 `upload.array('files', 5)`，支援同時上傳多個檔案，逐一 INSERT 後回傳所有新記錄陣列。

5. **實作查詢與刪除路由**

   - `GET /files`：SELECT 所有記錄，依 `created_at DESC` 排序後回傳。
   - `DELETE /files/:id`：先查詢記錄確認存在，再用 `fs.unlink` 刪除實體檔案，最後 DELETE 資料庫記錄，回傳 `200`。

---

## 提示

- 安裝相依套件：`npm install express multer pg`
- `uploads/` 目錄須事先建立（可在程式啟動時用 `fs.mkdirSync('uploads', { recursive: true })` 自動建立）。
- Multer 的 `fileFilter` 回呼中，若 MIME 不符合，呼叫 `cb(new Error('不支援的檔案類型'))` 並傳入 `false`：
  ```js
  const fileFilter = (req, file, cb) => {
    const allowed = ['image/jpeg', 'image/png', 'application/pdf'];
    allowed.includes(file.mimetype) ? cb(null, true) : cb(new Error('不支援的檔案類型'), false);
  };
  ```
- 刪除實體檔案時，路徑為 `path.join('uploads', storedName)`。
- 在全域錯誤中介軟體攔截 Multer 錯誤（`err instanceof multer.MulterError`），統一回傳 400。

---

## 進階挑戰（選做）

1. **限制檔案大小**：在 Multer 選項加入 `limits: { fileSize: 2 * 1024 * 1024 }`（2 MB），超過時回傳 413 並附上說明訊息。
2. **產生縮圖**：安裝 `sharp`，在頭像上傳後非同步產生 200×200 像素的縮圖，存為 `uploads/thumb-<filename>`，並在回應中附上縮圖路徑。
3. **分頁查詢**：`GET /files?page=1&limit=10`，回應包含 `data`（當頁資料）、`total`（總數）、`page`、`totalPages`。
4. **靜態檔案服務**：加入 `app.use('/static', express.static('uploads'))` 讓已上傳檔案可直接透過 URL 存取，並在查詢結果中附上完整 URL。
