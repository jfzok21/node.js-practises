# 第 5 週今日練習題：JOIN 查詢與多資料表關聯

## 題目說明

建立一個「書店訂單系統」的 REST API，包含 `customers`（顧客）、`books`（書籍）、`orders`（訂單）三張資料表，並透過 JOIN 查詢實作跨資料表的資料讀取與統計。

---

## 技術要求

- **Express.js**：建立 RESTful 路由，回傳 JSON 格式資料
- **PostgreSQL**：設計關聯式資料表，使用 INNER JOIN / LEFT JOIN 進行多表查詢

---

## 具體任務

### 1. 建立資料庫結構

建立三張資料表並插入測試資料：

```sql
-- 顧客資料表
CREATE TABLE customers (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(150) UNIQUE NOT NULL,
    created_at TIMESTAMP DEFAULT NOW()
);

-- 書籍資料表
CREATE TABLE books (
    id SERIAL PRIMARY KEY,
    title VARCHAR(200) NOT NULL,
    author VARCHAR(100) NOT NULL,
    price NUMERIC(8, 2) NOT NULL,
    stock INTEGER DEFAULT 0
);

-- 訂單資料表
CREATE TABLE orders (
    id SERIAL PRIMARY KEY,
    customer_id INTEGER REFERENCES customers(id) ON DELETE SET NULL,
    book_id INTEGER REFERENCES books(id) ON DELETE SET NULL,
    quantity INTEGER NOT NULL CHECK (quantity > 0),
    total_price NUMERIC(10, 2) NOT NULL,
    ordered_at TIMESTAMP DEFAULT NOW()
);
```

插入至少 3 筆顧客、5 本書、8 筆訂單的測試資料。

---

### 2. 實作 Express API 端點

| 方法 | 路徑 | 說明 |
|------|------|------|
| GET | `/orders` | 取得所有訂單，JOIN 顯示顧客名稱與書名 |
| GET | `/orders/:id` | 取得單筆訂單完整資訊（顧客 + 書籍 + 訂單明細）|
| GET | `/customers/:id/orders` | 取得某位顧客的所有訂單紀錄 |
| GET | `/books/:id/orders` | 取得某本書的所有訂購紀錄 |
| GET | `/stats/top-customers` | 統計消費金額前 3 名的顧客 |
| GET | `/stats/top-books` | 統計銷售數量前 3 名的書籍 |

---

### 3. JOIN 查詢範例（`GET /orders`）

期望使用類似以下的 SQL：

```sql
SELECT
    o.id AS order_id,
    c.name AS customer_name,
    b.title AS book_title,
    b.author,
    o.quantity,
    o.total_price,
    o.ordered_at
FROM orders o
INNER JOIN customers c ON o.customer_id = c.id
INNER JOIN books b ON o.book_id = b.id
ORDER BY o.ordered_at DESC;
```

---

### 4. 統計查詢（`GET /stats/top-customers`）

```sql
SELECT
    c.id,
    c.name,
    c.email,
    COUNT(o.id) AS order_count,
    SUM(o.total_price) AS total_spent
FROM customers c
LEFT JOIN orders o ON c.id = o.customer_id
GROUP BY c.id, c.name, c.email
ORDER BY total_spent DESC
LIMIT 3;
```

---

## 提示

- 使用 `pg` 套件（`npm install pg`）連接 PostgreSQL
- 建議用 `pool.query()` 而非單次 `client.connect()`，可自動管理連線
- JOIN 時若欄位名稱相同（如 `id`），記得用 `AS` 別名避免覆蓋
- LEFT JOIN 可保留無訂單的顧客，INNER JOIN 則只保留有訂單的資料
- 測試時可先用 `psql` 確認 SQL 語法正確，再移植到 Node.js

---

## 進階挑戰（選做）

1. **POST `/orders`**：建立新訂單時，自動從 `books.price × quantity` 計算 `total_price`，並扣減 `books.stock`，若庫存不足則回傳 `409 Conflict`
2. **Transaction 保護**：下訂單的寫入操作（INSERT orders + UPDATE books stock）使用 `BEGIN / COMMIT / ROLLBACK` 包裝成一個 Transaction
3. **LEFT JOIN 顯示**：`GET /customers` 列出所有顧客，並在回應中附上各顧客的訂單數量（無訂單者顯示 0）
