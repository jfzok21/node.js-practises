# 第 8 週今日練習題：使用 Multer 實作圖片上傳 API

## 題目說明

建立一個支援檔案上傳功能的 Express API，使用 `multer` 套件處理 `multipart/form-data` 請求，並將上傳的圖片資訊儲存至 PostgreSQL 資料庫。

---

## 技術要求

- **Express.js**：建立 REST API 路由，接收檔案上傳請求並回傳 JSON 回應
- **PostgreSQL**：建立 `uploads` 資料表，儲存上傳檔案的元資料（檔名、路徑、大小、MIME 類型、上傳時間）
- **Multer**：設定磁碟儲存引擎（`diskStorage`），控制儲存目錄與檔名

---

## 具體任務

1. **安裝套件**
   ```bash
   npm install express multer pg
   ```

2. **建立資料庫資料表**
   ```sql
   CREATE TABLE uploads (
     id SERIAL PRIMARY KEY,
     original_name VARCHAR(255) NOT NULL,
     stored_name  VARCHAR(255) NOT NULL,
     file_path    VARCHAR(500) NOT NULL,
     mime_type    VARCHAR(100),
     size_bytes   INTEGER,
     uploaded_at  TIMESTAMP DEFAULT NOW()
   );
   ```

3. **設定 Multer 儲存引擎**
   - 儲存目錄：`./uploads/`
   - 檔名規則：`Date.now() + '-' + originalname`（避免同名覆蓋）
   - 僅允許 `image/jpeg`、`image/png`、`image/gif` 三種 MIME 類型，其他一律拒絕並回傳 `400`

4. **實作上傳路由**
   - `POST /upload`：上傳單一檔案（欄位名稱 `file`）；成功後將元資料寫入 `uploads` 資料表，並回傳：
     ```json
     {
       "message": "上傳成功",
       "file": {
         "id": 1,
         "originalName": "photo.jpg",
         "storedName": "1722230400000-photo.jpg",
         "size": 204800,
         "mimeType": "image/jpeg",
         "uploadedAt": "2026-08-29T10:00:00.000Z"
       }
     }
     ```
   - `GET /uploads`：查詢所有已上傳檔案的清單（從資料庫讀取，由新到舊排序）
   - `GET /uploads/:id`：查詢單一檔案資訊；找不到時回傳 `404`

5. **錯誤處理**
   - 未附上檔案時回傳 `400 { "error": "請選擇要上傳的檔案" }`
   - 檔案類型不符時回傳 `400 { "error": "僅支援 JPEG / PNG / GIF 圖片" }`
   - 其餘伺服器錯誤一律回傳 `500`

---

## 提示

- `multer.diskStorage` 的 `filename` 回呼需呼叫 `cb(null, 新檔名)` 才能繼續
- Multer 的 `fileFilter` 回呼：合法時呼叫 `cb(null, true)`，非法時呼叫 `cb(null, false)` 並可搭配 `req.fileValidationError` 傳遞錯誤訊息
- 使用 `upload.single('file')` 作為路由中介軟體；可在其後的 handler 內透過 `req.file` 取得檔案資訊
- 記得在 `./uploads/` 目錄不存在時先以 `fs.mkdirSync` 建立它，或直接加入 `.gitignore`

---

## 進階挑戰（選做）

- 支援多檔案同時上傳：改用 `upload.array('files', 5)`，並批次寫入資料庫（使用單一 `INSERT ... VALUES` 或 `Promise.all`）
- 新增 `DELETE /uploads/:id` 路由：從資料庫刪除記錄，並使用 `fs.unlink` 刪除磁碟上的實體檔案
- 限制單檔大小（例如 5 MB）：在 `multer({ limits: { fileSize: 5 * 1024 * 1024 } })` 設定，並捕捉 `MulterError` 回傳友善訊息
- 將檔案儲存至雲端（AWS S3 / Cloudflare R2）：改用 `multer-s3` 儲存引擎，資料庫只存 URL
