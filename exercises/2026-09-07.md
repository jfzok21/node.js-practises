# 第 9 週今日練習題：分頁與排序 API

## 題目說明

實作一個支援分頁（Pagination）與排序（Sorting）功能的 Express + PostgreSQL API。
本練習模擬真實後端開發中最常見的需求：當資料量龐大時，需要分頁取得資料，並能依據不同欄位排序。

## 技術要求

- **Express.js**：設計支援查詢字串參數的路由（`?page=`、`?limit=`、`?sort=`、`?order=`）
- **PostgreSQL**：使用 `LIMIT`、`OFFSET`、`ORDER BY` 進行資料庫層級的分頁與排序

## 具體任務

1. **建立資料表**
   使用以下 SQL 建立一張 `products`（商品）資料表，並插入至少 30 筆測試資料：
   ```sql
   CREATE TABLE products (
     id SERIAL PRIMARY KEY,
     name VARCHAR(100) NOT NULL,
     price NUMERIC(10, 2) NOT NULL,
     stock INTEGER NOT NULL DEFAULT 0,
     created_at TIMESTAMP DEFAULT NOW()
   );
   ```

2. **實作分頁 API**
   建立路由 `GET /api/products`，接受以下查詢字串參數：
   - `page`：頁碼（預設 `1`）
   - `limit`：每頁筆數（預設 `10`，最大允許 `50`）
   - `sort`：排序欄位，允許值為 `id`、`name`、`price`、`stock`、`created_at`（預設 `id`）
   - `order`：排序方向 `asc` 或 `desc`（預設 `asc`）

3. **回傳標準分頁格式**
   API 回應需包含以下結構：
   ```json
   {
     "data": [...],
     "pagination": {
       "total": 30,
       "page": 1,
       "limit": 10,
       "total_pages": 3,
       "has_next": true,
       "has_prev": false
     }
   }
   ```

4. **防止 SQL Injection**
   排序欄位與方向不能直接插入 SQL 字串，需使用白名單（allowlist）驗證後再組合查詢。

5. **錯誤處理**
   - `page` 或 `limit` 為非正整數時，回傳 `400 Bad Request`
   - `sort` 欄位不在允許清單時，回傳 `400 Bad Request`

## 提示

- 計算 `OFFSET` 的公式：`OFFSET = (page - 1) * limit`
- 計算總頁數：`total_pages = Math.ceil(total / limit)`
- 使用 `COUNT(*) OVER()` 或另一個 `SELECT COUNT(*)` 查詢取得總筆數
- 排序白名單範例：
  ```js
  const ALLOWED_SORT_FIELDS = ['id', 'name', 'price', 'stock', 'created_at'];
  const ALLOWED_ORDERS = ['asc', 'desc'];
  if (!ALLOWED_SORT_FIELDS.includes(sort)) {
    return res.status(400).json({ error: 'Invalid sort field' });
  }
  ```
- 同時取得總數與資料可用視窗函數，避免兩次查詢：
  ```sql
  SELECT *, COUNT(*) OVER() AS total_count
  FROM products
  ORDER BY id ASC
  LIMIT $1 OFFSET $2;
  ```

## 進階挑戰（選做）

1. **搜尋功能**：加入 `?search=` 參數，支援依 `name` 欄位模糊搜尋（`ILIKE`），並確保搜尋與分頁共同運作。

2. **游標分頁（Cursor-based Pagination）**：實作另一個路由 `GET /api/products/cursor`，使用 `id > :cursor` 取代 `OFFSET`，回傳下一頁的 `next_cursor`，改善大量資料時的效能。

3. **多欄位排序**：支援 `?sort=price,name&order=desc,asc` 格式，允許依多欄位組合排序。
