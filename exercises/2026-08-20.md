# 第 7 週今日練習題：JWT 身份驗證系統

## 題目說明

實作一套完整的 JWT（JSON Web Token）身份驗證機制，包含使用者註冊、登入，以及受保護路由的存取控制。這是現代 REST API 最常見的認證方式，學會後可直接應用於實際專案。

## 技術要求

- **Express.js**：建立 `/auth/register`、`/auth/login`、`/profile` 等路由；撰寫 JWT 驗證 Middleware
- **PostgreSQL**：建立 `users` 資料表，儲存帳號與雜湊後的密碼；查詢使用者並驗證密碼

## 具體任務

1. **建立資料庫結構**
   - 建立 `users` 資料表，欄位：`id`（SERIAL PRIMARY KEY）、`username`（VARCHAR, UNIQUE）、`email`（VARCHAR, UNIQUE）、`password_hash`（VARCHAR）、`created_at`（TIMESTAMP）

2. **實作註冊路由 `POST /auth/register`**
   - 接收 `username`、`email`、`password`
   - 使用 `bcrypt` 雜湊密碼後寫入資料庫
   - 回傳成功訊息（不回傳密碼）

3. **實作登入路由 `POST /auth/login`**
   - 接收 `email`、`password`
   - 查詢資料庫，用 `bcrypt.compare` 驗證密碼
   - 驗證成功後，使用 `jsonwebtoken` 簽發 JWT（包含 `userId`、`username`，有效期 1 小時）
   - 回傳 `{ token: "..." }`

4. **撰寫 `authenticateToken` Middleware**
   - 從 `Authorization: Bearer <token>` 標頭取出 JWT
   - 使用 `jwt.verify` 驗證；失敗回傳 `401`
   - 驗證成功將解碼後的使用者資訊掛載至 `req.user`

5. **建立受保護路由 `GET /profile`**
   - 套用 `authenticateToken` Middleware
   - 從資料庫查詢並回傳目前登入使用者的資料（排除 `password_hash`）

## 提示

- 安裝套件：`npm install jsonwebtoken bcrypt`
- JWT Secret 請存放於 `.env`，使用 `dotenv` 讀取，不要寫死在程式碼中
- `bcrypt.hash(password, 10)` 的第二個參數是 salt rounds，10 是常用值
- 測試時可用 `curl` 或 Postman 先打 `/auth/login` 取得 token，再帶入 header 測試 `/profile`
- 資料庫查詢可使用 `pg` 套件（`Pool` 或 `Client`）

## 進階挑戰（選做）

- **Refresh Token**：另外簽發一個有效期 7 天的 refresh token，存入資料庫的 `refresh_tokens` 資料表；新增 `POST /auth/refresh` 路由，用 refresh token 換取新的 access token
- **登出機制**：建立 token 黑名單（存於 PostgreSQL 或 Redis），讓已登出的 token 無法繼續使用
- **角色權限**：在 JWT payload 加入 `role`（`"user"` / `"admin"`），撰寫 `requireAdmin` Middleware 保護管理員路由
