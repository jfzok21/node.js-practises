# 第 3 週今日練習題：書籍查詢 API（路由參數與查詢字串）

## 題目說明

建立一個書籍查詢 REST API，讓使用者可以透過路由參數（`:id`）取得特定書籍，也可以透過查詢字串（`?search=`、`?author=`、`?page=`）進行搜尋與過濾。本題的核心是熟悉 Express 如何處理動態路由與 URL 查詢參數。

---

## 技術要求

- **Express.js**：動態路由參數（`req.params`）、查詢字串（`req.query`）、路由模組化（`express.Router`）
- **PostgreSQL**：使用參數化查詢防止 SQL Injection、`LIKE` 模糊搜尋、`LIMIT / OFFSET` 分頁

---

## 具體任務

### 1. 建立資料表

執行以下 SQL 建立 `books` 資料表並插入測試資料：

```sql
CREATE TABLE IF NOT EXISTS books (
  id SERIAL PRIMARY KEY,
  title VARCHAR(255) NOT NULL,
  author VARCHAR(100) NOT NULL,
  genre VARCHAR(50),
  published_year INT,
  created_at TIMESTAMP DEFAULT NOW()
);

```

### 2. 實作路由參數 GET `/api/books/:id`

- 路徑：`GET /api/books/:id`
- 從 `req.params.id` 取得書籍 ID
- 若找到，回傳 `{ success: true, data: { ...book } }`
- 若不存在，回傳 `404` 與 `{ success: false, message: "找不到該書籍" }`
- 若 `id` 非數字，回傳 `400` 與 `{ success: false, message: "無效的 ID 格式" }`

### 3. 實作查詢字串 GET `/api/books`

支援以下查詢字串參數（皆為選填）：

| 參數 | 說明 | 範例 |
|------|------|------|
| `search` | 搜尋書名（模糊比對） | `?search=node` |
| `author` | 依作者名稱篩選（完全比對） | `?author=王小明` |
| `genre` | 依類別篩選 | `?genre=程式設計` |
| `page` | 頁數（預設第 1 頁） | `?page=2` |
| `limit` | 每頁筆數（預設 3，最大 10） | `?limit=5` |

回傳格式：
```json
{
  "success": true,
  "data": [...],
  "pagination": {
    "page": 1,
    "limit": 3,
    "total": 6,
    "totalPages": 2
  }
}
```

### 4. 實作路由模組化

將書籍路由獨立到 `routes/books.js`，在 `app.js` 中以 `app.use('/api/books', booksRouter)` 掛載。

### 5. 驗收測試（使用 curl 或 Postman）

```bash
# 取得 ID 為 1 的書籍
curl http://localhost:3000/api/books/1

# 測試 ID 不存在
curl http://localhost:3000/api/books/999

# 測試非數字 ID
curl http://localhost:3000/api/books/abc

# 搜尋書名含 "Node" 的書
curl "http://localhost:3000/api/books?search=Node"

# 篩選程式設計類別，取第 1 頁每頁 2 筆
curl "http://localhost:3000/api/books?genre=程式設計&page=1&limit=2"

# 依作者篩選
curl "http://localhost:3000/api/books?author=王小明"
```

## 提示

- `req.params.id` 取到的值是**字串**，記得用 `parseInt()` 轉換，並用 `isNaN()` 驗證格式
- `req.query` 的所有值也都是字串，`page` 和 `limit` 需轉為整數
- PostgreSQL 模糊搜尋語法：`WHERE title ILIKE $1` 搭配 `'%' + search + '%'`（`ILIKE` 不分大小寫）
- 動態組合多條件 SQL 時，可用陣列累積條件與參數，例如：
  ```js
  const conditions = [];
  const params = [];
  if (search) {
    params.push(`%${search}%`);
    conditions.push(`title ILIKE $${params.length}`);
  }
  const whereClause = conditions.length ? `WHERE ${conditions.join(' AND ')}` : '';
  ```
- `LIMIT` 與 `OFFSET` 公式：`OFFSET = (page - 1) * limit`

## 進階挑戰（選做）

1. **排序功能**：新增 `?sort=published_year&order=desc` 支援，讓使用者可以自訂排序欄位與方向。在接受 `sort` 參數前，先用白名單驗證欄位名稱（防止 SQL Injection）。

2. **多值篩選**：支援 `?genre=程式設計,資料庫`（逗號分隔多個類別），使用 `WHERE genre = ANY($1)` 語法。

3. **欄位選取**：新增 `?fields=id,title,author` 參數，讓 API 只回傳指定欄位（同樣需白名單驗證）。
