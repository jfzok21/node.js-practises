# 第 16 週今日練習題：RESTful 部落格 API 實戰專案（含留言與標籤功能）

## 題目說明

建立一個具備完整功能的部落格後端 API，支援文章的 CRUD 操作、留言系統、標籤分類，並整合身份驗證與分頁查詢。本練習綜合前 15 週所學，模擬真實專案開發流程。

## 技術要求

- **Express.js**：RESTful API 設計、路由模組化、Middleware 組合、JWT 驗證、全域錯誤處理
- **PostgreSQL**：多資料表關聯（posts / comments / tags / post_tags / users）、JOIN 查詢、交易處理（Transaction）、分頁與排序

## 資料庫結構

```sql
CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  username VARCHAR(50) UNIQUE NOT NULL,
  email VARCHAR(100) UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE posts (
  id SERIAL PRIMARY KEY,
  title VARCHAR(200) NOT NULL,
  content TEXT NOT NULL,
  author_id INTEGER REFERENCES users(id) ON DELETE CASCADE,
  published BOOLEAN DEFAULT false,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE comments (
  id SERIAL PRIMARY KEY,
  post_id INTEGER REFERENCES posts(id) ON DELETE CASCADE,
  author_id INTEGER REFERENCES users(id) ON DELETE CASCADE,
  content TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE tags (
  id SERIAL PRIMARY KEY,
  name VARCHAR(50) UNIQUE NOT NULL
);

CREATE TABLE post_tags (
  post_id INTEGER REFERENCES posts(id) ON DELETE CASCADE,
  tag_id INTEGER REFERENCES tags(id) ON DELETE CASCADE,
  PRIMARY KEY (post_id, tag_id)
);
```

## 具體任務

### 任務一：專案初始化與資料庫建立

1. 建立 Express 專案，安裝必要套件：
   ```
   express pg jsonwebtoken bcryptjs multer joi dotenv
   ```
2. 建立上述資料庫結構，並在 PostgreSQL 中建立對應的 table
3. 設定 `db.js` 連線池（使用 `pg.Pool`），從 `.env` 讀取連線資訊

### 任務二：使用者認證模組

4. `POST /api/auth/register`：使用 bcryptjs 雜湊密碼後存入 users 表
5. `POST /api/auth/login`：驗證密碼，成功後回傳 JWT（有效期 24 小時）
6. 實作 `authMiddleware`：從 `Authorization: Bearer <token>` 驗證 JWT，將 `req.user` 設為解碼後的使用者資料

### 任務三：文章 CRUD

7. `GET /api/posts`：取得已發布文章列表，支援：
   - 分頁：`?page=1&limit=10`
   - 標籤篩選：`?tag=nodejs`
   - 搜尋標題：`?search=express`
   - 排序：`?sort=created_at&order=desc`
8. `GET /api/posts/:id`：取得單篇文章（含留言數量與標籤清單，用 JOIN 一次查詢）
9. `POST /api/posts`：建立文章（需登入），同時在 `post_tags` 新增標籤關聯（使用 Transaction）
10. `PUT /api/posts/:id`：更新文章（僅作者本人）
11. `DELETE /api/posts/:id`：刪除文章（僅作者本人）

### 任務四：留言功能

12. `GET /api/posts/:id/comments`：取得某篇文章的所有留言（含作者 username）
13. `POST /api/posts/:id/comments`：新增留言（需登入）
14. `DELETE /api/comments/:id`：刪除留言（僅留言作者或文章作者可刪）

### 任務五：標籤管理

15. `GET /api/tags`：列出所有標籤及其文章數量
16. `POST /api/tags`：新增標籤（需登入）

### 任務六：全域錯誤處理與資料驗證

17. 使用 `joi` 驗證 request body（例如 title 必填、content 最少 10 字）
18. 統一錯誤回應格式：`{ "error": "訊息", "code": "ERROR_CODE" }`
19. 實作 404 路由捕捉與未預期錯誤的 500 處理 middleware

## 提示

- 使用 `pg.Pool` 的 `client = await pool.connect()` 搭配 `try/finally` 確保 Transaction 的連線一定被釋放
- JWT payload 中只存 `{ id, username }`，不放密碼或敏感資料
- 分頁查詢中，`LIMIT $1 OFFSET $2` 的 offset 計算：`(page - 1) * limit`
- 多 JOIN 查詢時，善用 `json_agg()` 聚合標籤成陣列，避免多次查詢
- 驗證「僅作者本人」時，先查詢資源確認存在，再比對 `author_id === req.user.id`
- 路由模組化建議：`routes/auth.js`、`routes/posts.js`、`routes/comments.js`、`routes/tags.js`

## 進階挑戰（選做）

1. **文章草稿功能**：`published: false` 的文章只有作者本人可以看到
2. **圖片上傳**：`POST /api/posts/:id/cover` 使用 multer 上傳封面圖片，儲存路徑至資料庫
3. **API 測試**：使用 Jest + supertest 為任務三的 `/api/posts` 撰寫至少 5 個測試案例（含分頁、搜尋、標籤篩選）
4. **Rate Limiting**：使用 `express-rate-limit` 限制登入 API 每分鐘最多嘗試 5 次
5. **軟刪除**：為 posts 加入 `deleted_at` 欄位，刪除時只更新此欄位而非真正移除
