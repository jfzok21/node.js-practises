# 第 12 週今日練習題：任務管理 REST API 實戰專案

## 題目說明

建立一個完整的「任務管理系統」REST API，整合你這 12 週以來學到的所有技術：Express 路由、PostgreSQL CRUD、Middleware、JWT 驗證、資料驗證、分頁排序、交易處理，以及 API 測試。這是一個接近真實生產環境的完整後端服務。

---

## 技術要求

- **Express.js**：路由模組化、自訂 Middleware、錯誤處理、JWT 驗證保護路由
- **PostgreSQL**：多資料表設計（users、projects、tasks）、JOIN 查詢、Transaction、索引最佳化
- **套件**：`express`、`pg`、`bcrypt`、`jsonwebtoken`、`joi`（或 `express-validator`）、`multer`（選做）、`jest`＋`supertest`

## 資料庫結構

請先建立以下三張資料表：

```sql
-- 使用者表
CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  username VARCHAR(50) UNIQUE NOT NULL,
  email VARCHAR(100) UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 專案表
CREATE TABLE projects (
  id SERIAL PRIMARY KEY,
  owner_id INTEGER REFERENCES users(id) ON DELETE CASCADE,
  name VARCHAR(100) NOT NULL,
  description TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 任務表
CREATE TABLE tasks (
  id SERIAL PRIMARY KEY,
  project_id INTEGER REFERENCES projects(id) ON DELETE CASCADE,
  assignee_id INTEGER REFERENCES users(id) ON DELETE SET NULL,
  title VARCHAR(200) NOT NULL,
  description TEXT,
  status VARCHAR(20) DEFAULT 'todo' CHECK (status IN ('todo', 'in_progress', 'done')),
  priority INTEGER DEFAULT 3 CHECK (priority BETWEEN 1 AND 5),
  due_date DATE,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

## 具體任務

### 1. 專案架構（請依此結構組織程式碼）

```
src/
  routes/
    auth.js       ← 登入 / 註冊
    projects.js   ← 專案 CRUD
    tasks.js      ← 任務 CRUD
  middleware/
    auth.js       ← JWT 驗證
    validate.js   ← 資料驗證
    errorHandler.js
  db/
    pool.js       ← pg Pool 設定
  tests/
    auth.test.js
    tasks.test.js
  app.js
  server.js
```

### 2. 驗證 API

| 方法 | 路徑 | 說明 |
|------|------|------|
| POST | `/api/auth/register` | 註冊（bcrypt 加密密碼） |
| POST | `/api/auth/login` | 登入（回傳 JWT） |

- 密碼長度至少 8 碼，需含大小寫字母及數字
- JWT 有效期限 24 小時

### 3. 專案 API（需 JWT）

| 方法 | 路徑 | 說明 |
|------|------|------|
| GET | `/api/projects` | 取得自己的所有專案 |
| POST | `/api/projects` | 建立專案 |
| PUT | `/api/projects/:id` | 更新專案（只有 owner 可以） |
| DELETE | `/api/projects/:id` | 刪除專案（含底下所有任務，用 Transaction） |

### 4. 任務 API（需 JWT）

| 方法 | 路徑 | 說明 |
|------|------|------|
| GET | `/api/projects/:projectId/tasks` | 取得專案任務（支援分頁、排序、狀態篩選） |
| POST | `/api/projects/:projectId/tasks` | 新增任務 |
| PUT | `/api/tasks/:id` | 更新任務（含狀態變更） |
| DELETE | `/api/tasks/:id` | 刪除任務 |
| GET | `/api/tasks/summary` | 取得所有任務的統計摘要（依狀態分組計數） |

### 5. 任務列表 API 查詢參數

```
GET /api/projects/1/tasks?status=todo&priority=1&page=1&limit=10&sort=due_date&order=asc
```

- `status`：篩選狀態（todo / in_progress / done）
- `priority`：篩選優先級（1–5）
- `page` + `limit`：分頁（預設 page=1, limit=10）
- `sort`：排序欄位（due_date / priority / created_at）
- `order`：asc / desc

### 6. 統計摘要 SQL（任務 5 的核心）

用一條 SQL 搭配 JOIN 查出：每個專案、每個狀態的任務數量及平均優先級：

```sql
SELECT
  p.name AS project_name,
  t.status,
  COUNT(*) AS task_count,
  ROUND(AVG(t.priority), 2) AS avg_priority
FROM tasks t
JOIN projects p ON t.project_id = p.id
WHERE p.owner_id = $1
GROUP BY p.name, t.status
ORDER BY p.name, t.status;
```

### 7. Transaction 範例（刪除專案）

```js
// routes/projects.js
const client = await pool.connect();
try {
  await client.query('BEGIN');
```

### 8. API 測試（選擇至少 3 個端點）

用 `supertest` + `jest` 撰寫測試，至少涵蓋：
- `POST /api/auth/register`：成功註冊、重複 email 應回 409
- `POST /api/auth/login`：正確密碼回 200 含 token，錯誤密碼回 401
- `GET /api/projects/:projectId/tasks`：未帶 token 應回 401，帶 token 回任務列表

## 提示

- 使用 `pg` 的 `Pool` 管理連線，不要每次 `new Client()`
- JWT secret 存在 `.env`，用 `dotenv` 載入，不要 hard-code
- 所有 Middleware 的錯誤統一拋給 `errorHandler.js` 處理，不要在每個 route 重複 `try/catch` 回應
- 資料驗證失敗統一回傳 `{ error: "...", details: [...] }` 結構
- 為 `tasks.project_id`、`tasks.assignee_id`、`tasks.status` 加上索引，加速查詢

## 進階挑戰（選做）

1. **任務附件上傳**：用 `multer` 支援 `POST /api/tasks/:id/attachment`，將檔案儲存到 `uploads/` 目錄，並在 tasks 表新增 `attachment_url` 欄位
2. **軟刪除**：在 tasks 表加 `deleted_at TIMESTAMPTZ`，刪除時只更新此欄位，查詢時加上 `WHERE deleted_at IS NULL`
3. **Rate Limiting**：用 `express-rate-limit` 限制登入端點每分鐘最多 5 次請求，防止暴力破解
4. **Swagger 文件**：用 `swagger-jsdoc` + `swagger-ui-express` 自動產生 API 文件頁面（`/api/docs`）
