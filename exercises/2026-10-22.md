# 第 16 週今日練習題：書籍管理 REST API 實戰專案

## 題目說明

建立一個完整的書籍管理 REST API，整合 Express.js 與 PostgreSQL，實作完整的 CRUD 功能、JWT 身份驗證、資料驗證、分頁查詢及錯誤處理。這是一個綜合性的實戰專案，涵蓋前幾週學過的所有核心技術。

## 技術要求

- **Express.js**：RESTful 路由設計、Middleware 鏈、統一錯誤處理
- **PostgreSQL**：多資料表關聯（書籍、作者、分類）、JOIN 查詢、Transaction
- **JWT**：使用者登入驗證、受保護路由
- **資料驗證**：請求參數與 body 驗證
- **分頁**：支援 `?page=` 與 `?limit=` 查詢參數

## 具體任務

1. **資料庫設計**：建立以下資料表：
   ```sql
   -- 使用者
   CREATE TABLE users (
     id SERIAL PRIMARY KEY,
     username VARCHAR(50) UNIQUE NOT NULL,
     password_hash VARCHAR(255) NOT NULL,
     created_at TIMESTAMP DEFAULT NOW()
   );

   -- 分類
   CREATE TABLE categories (
     id SERIAL PRIMARY KEY,
     name VARCHAR(100) NOT NULL
   );

   -- 作者
   CREATE TABLE authors (
     id SERIAL PRIMARY KEY,
     name VARCHAR(100) NOT NULL,
     bio TEXT
   );

   -- 書籍
   CREATE TABLE books (
     id SERIAL PRIMARY KEY,
     title VARCHAR(255) NOT NULL,
     author_id INTEGER REFERENCES authors(id),
     category_id INTEGER REFERENCES categories(id),
     published_year INTEGER,
     stock INTEGER DEFAULT 0,
     created_at TIMESTAMP DEFAULT NOW()
   );
   ```

2. **身份驗證路由**（不需 JWT）：
   - `POST /api/auth/register`：註冊使用者（username、password）
   - `POST /api/auth/login`：登入，回傳 JWT token

3. **書籍 CRUD**（需 JWT 驗證）：
   - `GET /api/books`：取得書籍列表，支援分頁（`?page=1&limit=10`）與搜尋（`?search=關鍵字`）
   - `GET /api/books/:id`：取得單本書籍詳情（JOIN 作者與分類名稱）
   - `POST /api/books`：新增書籍
   - `PUT /api/books/:id`：更新書籍資訊
   - `DELETE /api/books/:id`：刪除書籍

4. **Transaction 操作**：新增書籍時，若 `author_id` 不存在則自動建立作者，並在同一交易中完成，確保資料一致性。

5. **統一錯誤回應格式**：
   ```json
   { "error": "錯誤訊息", "code": "ERROR_CODE" }
   ```

6. **寫一支測試腳本** `tests/books.test.js`，使用 `supertest` + `Jest` 測試至少三個 API 端點。

## 提示

- 使用 `bcryptjs` 加密密碼，不要明文儲存
- JWT 建議設定 `expiresIn: '7d'`
- 分頁查詢可用 `LIMIT $1 OFFSET $2`，offset = (page - 1) * limit
- 記得在 JWT middleware 中處理 `TokenExpiredError` 與 `JsonWebTokenError`
- 使用 `pg` 套件的 `Pool` 管理資料庫連線池
- Transaction 範例：
  ```js
  const client = await pool.connect();
  try {
    await client.query('BEGIN');
    // ... 多個操作
    await client.query('COMMIT');
  } catch (err) {
    await client.query('ROLLBACK');
    throw err;
  } finally {
    client.release();
  }
  ```
