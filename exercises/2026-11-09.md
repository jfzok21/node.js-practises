# 第 18 週今日練習題：書籍管理 REST API 實戰專案

## 題目說明

實作一個完整的書籍管理系統 REST API，整合前幾週所學的所有技術：路由設計、PostgreSQL CRUD、Middleware、JWT 身份驗證、資料驗證、分頁排序，以及完整的錯誤處理機制。

## 技術要求

- **Express.js**：模組化路由結構（`routes/`、`controllers/`、`middleware/`），統一錯誤處理 Middleware
- **PostgreSQL**：多資料表關聯（books、authors、categories），JOIN 查詢，Transaction 處理
- **JWT**：受保護的 API 端點（新增、修改、刪除需驗證；查詢公開）
- **資料驗證**：使用 `joi` 或 `express-validator` 驗證請求 body
- **分頁與排序**：列表端點支援 `?page=&limit=&sort=&order=`

## 資料庫 Schema

```sql
CREATE TABLE authors (
  id SERIAL PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  bio TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE categories (
  id SERIAL PRIMARY KEY,
  name VARCHAR(50) NOT NULL UNIQUE
);

CREATE TABLE books (
  id SERIAL PRIMARY KEY,
  title VARCHAR(200) NOT NULL,
  author_id INTEGER REFERENCES authors(id) ON DELETE SET NULL,
  category_id INTEGER REFERENCES categories(id) ON DELETE SET NULL,
  isbn VARCHAR(20) UNIQUE,
  price NUMERIC(10,2),
  stock INTEGER DEFAULT 0,
  published_at DATE,
  created_at TIMESTAMP DEFAULT NOW()
);
```

## 具體任務

1. **建立專案結構**
   ```
   src/
   ├── routes/
   │   ├── auth.js
   │   ├── books.js
   │   └── authors.js
   ├── controllers/
   │   ├── bookController.js
   │   └── authorController.js
   ├── middleware/
   │   ├── auth.js       (JWT 驗證)
   │   └── validate.js   (資料驗證)
   ├── db.js
   └── app.js
   ```

2. **實作認證端點**
   - `POST /api/auth/login`：回傳 JWT（帳號密碼寫死即可，重點在 token 生成）
   - Token 有效期 1 小時

3. **實作書籍 CRUD API**
   - `GET /api/books`：列出所有書籍（JOIN author 和 category），支援分頁與排序
   - `GET /api/books/:id`：取得單本書籍詳細資訊
   - `GET /api/books?search=關鍵字`：搜尋書名或作者名
   - `POST /api/books`（需 JWT）：新增書籍，驗證必填欄位
   - `PUT /api/books/:id`（需 JWT）：更新書籍資訊
   - `DELETE /api/books/:id`（需 JWT）：刪除書籍

4. **實作作者 API**
   - `GET /api/authors`：列出所有作者及其書籍數量
   - `GET /api/authors/:id/books`：取得特定作者的所有書籍
   - `POST /api/authors`（需 JWT）：新增作者

5. **實作進貨 Transaction**
   - `POST /api/books/:id/restock`（需 JWT）
   - Request body: `{ "quantity": 50 }`
   - 在 Transaction 中更新 stock，並寫入 restock_logs 資料表（需自行建立）
   - 若 quantity <= 0 則 rollback 並回傳 400

6. **統一錯誤格式**
   所有錯誤回應統一格式：
   ```json
   {
     "error": {
       "code": "VALIDATION_ERROR",
       "message": "書名不能為空",
       "details": [...]
     }
   }
   ```

## 提示

- 使用 `pg` 套件連線 PostgreSQL，建議封裝成 pool
- JWT 驗證 Middleware 從 `Authorization: Bearer <token>` header 取得 token
- 分頁查詢：`LIMIT $1 OFFSET $2`，offset = (page - 1) * limit
- JOIN 查詢範例：
  ```sql
  SELECT b.*, a.name AS author_name, c.name AS category_name
  FROM books b
  LEFT JOIN authors a ON b.author_id = a.id
  LEFT JOIN categories c ON b.category_id = c.id
  WHERE b.title ILIKE $1
  ORDER BY b.created_at DESC
  LIMIT $2 OFFSET $3
  ```
- Transaction 寫法：
  ```js
  const client = await pool.connect();
  try {
    await client.query('BEGIN');
    // ... queries
    await client.query('COMMIT');
  } catch (e) {
    await client.query('ROLLBACK');
    throw e;
  } finally {
    client.release();
  }
  ```
