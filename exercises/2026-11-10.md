# 第 18 週今日練習題：書籍借閱管理系統 REST API

## 題目說明

建立一個完整的書籍借閱管理系統後端 API，模擬圖書館的借閱流程。系統需管理書籍庫存、會員資料，以及借閱記錄，並整合先前學過的 JWT 驗證、資料驗證、分頁、Transaction 等技術。

---

## 技術要求

- **Express.js**：路由分層（`/api/books`、`/api/members`、`/api/loans`）、自訂 Middleware、JWT 守衛
- **PostgreSQL**：三張資料表（books、members、loans）、JOIN 查詢、Transaction 確保借還書一致性

---

## 資料庫設計

```sql
CREATE TABLE books (
  id SERIAL PRIMARY KEY,
  title VARCHAR(200) NOT NULL,
  author VARCHAR(100) NOT NULL,
  isbn VARCHAR(20) UNIQUE NOT NULL,
  total_copies INT NOT NULL DEFAULT 1,
  available_copies INT NOT NULL DEFAULT 1,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE members (
  id SERIAL PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(150) UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,
  max_borrow_limit INT NOT NULL DEFAULT 3,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE loans (
  id SERIAL PRIMARY KEY,
  book_id INT REFERENCES books(id),
  member_id INT REFERENCES members(id),
  borrowed_at TIMESTAMPTZ DEFAULT NOW(),
  due_date TIMESTAMPTZ NOT NULL,
  returned_at TIMESTAMPTZ,
  status VARCHAR(20) NOT NULL DEFAULT 'active' -- active | returned | overdue
);
```

---

## 具體任務

1. **會員系統**
   - `POST /api/auth/register`：註冊新會員（bcrypt 雜湊密碼）
   - `POST /api/auth/login`：登入，回傳 JWT Token

2. **書籍管理**（需 JWT）
   - `GET /api/books`：列出所有書籍，支援 `?search=關鍵字` 及分頁（`?page=1&limit=10`）
   - `POST /api/books`：新增書籍（管理員用）
   - `GET /api/books/:id`：取得單本書籍詳情，包含目前可借數量

3. **借閱操作**（需 JWT）
   - `POST /api/loans`：借書
     - 以 Transaction 確保：`available_copies` 扣減與 `loans` 建立同時成功或同時失敗
     - 若 `available_copies = 0`，回傳 `409 Conflict`
     - 若會員已借冊數達 `max_borrow_limit`，回傳 `403 Forbidden`
     - `due_date` 預設為借閱日起 14 天後
   - `PATCH /api/loans/:id/return`：還書
     - 以 Transaction 確保：`available_copies` 加回與 `loans.returned_at` 更新同時成功或失敗
     - 若已還書（`returned_at` 不為 null），回傳 `400 Bad Request`
   - `GET /api/loans/my`：查詢自己目前所有借閱記錄（JOIN books 顯示書名）

4. **逾期處理**
   - 建立一個 `PATCH /api/loans/mark-overdue` 端點（或排程腳本），將 `due_date < NOW()` 且 `status = 'active'` 的記錄批次更新為 `'overdue'`

---

## 提示

- 使用 `pg` 的 `client.query('BEGIN') / COMMIT / ROLLBACK` 實作 Transaction，記得在 `catch` 區塊執行 `ROLLBACK`
- JWT Middleware 可從 `Authorization: Bearer <token>` 標頭取出 token 並驗證，將 `req.user` 設為解碼後的 payload
- 分頁查詢可用 `LIMIT $1 OFFSET $2`，offset = (page - 1) * limit
- 資料驗證建議使用 `joi` 或 `zod`，在路由層進行
