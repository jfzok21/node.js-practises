# 第 9 週今日練習題：文章列表分頁與排序 API

## 題目說明

建立一個支援**分頁（Pagination）**與**排序（Sorting）**的文章列表 REST API。
前端常需要以「每頁幾筆、第幾頁、依哪個欄位排序」的方式取得資料，本題將練習如何在 Express + PostgreSQL 中正確實作這個功能。

## 技術要求

- **Express.js**：接收查詢字串參數（`page`、`limit`、`sort`、`order`），並回傳結構化 JSON 回應
- **PostgreSQL**：使用 `LIMIT`、`OFFSET`、`ORDER BY` 實作資料庫層分頁與排序，並計算總筆數

## 具體任務

1. **建立資料表**

   在 PostgreSQL 建立 `articles` 資料表：

   ```sql
   CREATE TABLE articles (
     id SERIAL PRIMARY KEY,
     title VARCHAR(200) NOT NULL,
     author VARCHAR(100) NOT NULL,
     views INTEGER DEFAULT 0,
     created_at TIMESTAMP DEFAULT NOW()
   );
   ```

   並插入至少 20 筆測試資料。

2. **實作 `GET /articles` 路由**

   接受以下查詢字串：

   | 參數    | 型別   | 預設值       | 說明                                      |
   |---------|--------|--------------|-------------------------------------------|
   | `page`  | number | `1`          | 目前頁碼（從 1 開始）                      |
   | `limit` | number | `10`         | 每頁筆數（最大不超過 100）                 |
   | `sort`  | string | `created_at` | 排序欄位（允許：`id`、`views`、`created_at`）|
   | `order` | string | `desc`       | 排序方向（`asc` 或 `desc`）               |

3. **回傳格式**

   ```json
   {
     "data": [ ... ],
     "pagination": {
       "total": 20,
       "page": 1,
       "limit": 10,
       "totalPages": 2,
       "hasNextPage": true,
       "hasPrevPage": false
     }
   }
   ```

4. **防止 SQL Injection**

   `sort` 欄位名稱不可直接帶入 SQL 字串插值，需用白名單驗證後再組合查詢。

5. **參數驗證與錯誤處理**

   - `page` / `limit` 必須是正整數，否則回傳 `400 Bad Request`
   - `sort` 不在白名單時回傳 `400 Bad Request`
   - `order` 非 `asc` / `desc` 時回傳 `400 Bad Request`

## 提示

- 計算 `OFFSET` 的公式：`(page - 1) * limit`
- 同一次請求需執行兩個 SQL：一個取資料（`SELECT ... LIMIT ... OFFSET ...`），一個計算總數（`SELECT COUNT(*)`）；可用 `Promise.all()` 平行執行以節省時間
- 排序欄位白名單範例：
  ```js
  const ALLOWED_SORT = ['id', 'views', 'created_at'];
  if (!ALLOWED_SORT.includes(sort)) {
    return res.status(400).json({ error: 'Invalid sort field' });
  }
  ```
- `ORDER BY` 的方向建議也用白名單：`['asc', 'desc']`

## 進階挑戰（選做）

- 加入 `search` 查詢字串，支援以 `ILIKE` 模糊搜尋 `title`（注意：搜尋與分頁、排序可同時使用）
- 在回應 Header 加入 `X-Total-Count` 與 `Link`（RFC 5988 Pagination）標頭，方便前端讀取分頁資訊
- 將分頁邏輯抽成可重用的 middleware，讓其他路由也能套用
