# 第 12 週今日練習題：電商商品購物車 REST API 實戰專案

## 題目說明

綜合運用前 11 週所學技術，建立一個完整的「電商商品與購物車系統」REST API。系統支援使用者瀏覽商品目錄、管理個人購物車並結帳下單，同時支援分頁、排序、商品搜尋與庫存交易控制。

---

## 技術要求

- **Express.js**：模組化路由（Router）、JWT 身份驗證 Middleware、全域錯誤處理 Middleware、商品圖片上傳（multer）
- **PostgreSQL**：多資料表關聯（users / products / categories / cart_items / orders / order_items）、JOIN 查詢、Transaction 庫存扣減、資料驗證

---

## 資料庫結構

```sql
-- 使用者
CREATE TABLE users (
  id         SERIAL PRIMARY KEY,
  email      VARCHAR(255) UNIQUE NOT NULL,
  password   VARCHAR(255) NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 商品分類
CREATE TABLE categories (
  id   SERIAL PRIMARY KEY,
  name VARCHAR(100) UNIQUE NOT NULL
);

-- 商品
CREATE TABLE products (
  id          SERIAL PRIMARY KEY,
  category_id INTEGER REFERENCES categories(id),
  name        VARCHAR(255) NOT NULL,
  description TEXT,
  price       NUMERIC(10,2) NOT NULL CHECK (price >= 0),
  stock       INTEGER NOT NULL DEFAULT 0 CHECK (stock >= 0),
  image_url   VARCHAR(500),
  created_at  TIMESTAMPTZ DEFAULT NOW()
);

-- 購物車項目
CREATE TABLE cart_items (
  id         SERIAL PRIMARY KEY,
  user_id    INTEGER REFERENCES users(id) ON DELETE CASCADE,
  product_id INTEGER REFERENCES products(id) ON DELETE CASCADE,
  quantity   INTEGER NOT NULL CHECK (quantity > 0),
  UNIQUE (user_id, product_id)
);

-- 訂單
CREATE TABLE orders (
  id          SERIAL PRIMARY KEY,
  user_id     INTEGER REFERENCES users(id),
  total_price NUMERIC(10,2) NOT NULL,
  status      VARCHAR(20) CHECK (status IN ('pending','paid','shipped','cancelled')) DEFAULT 'pending',
  created_at  TIMESTAMPTZ DEFAULT NOW()
);

-- 訂單項目
CREATE TABLE order_items (
  id         SERIAL PRIMARY KEY,
  order_id   INTEGER REFERENCES orders(id) ON DELETE CASCADE,
  product_id INTEGER REFERENCES products(id),
  quantity   INTEGER NOT NULL,
  unit_price NUMERIC(10,2) NOT NULL
);
```

## 具體任務

### 1. 使用者驗證模組（`routes/auth.js`）

| 路由 | 說明 |
|------|------|
| `POST /api/auth/register` | 註冊（bcrypt 加密密碼） |
| `POST /api/auth/login` | 登入，回傳 JWT |

### 2. 商品目錄模組（`routes/products.js`）—— 公開端點

| 路由 | 說明 |
|------|------|
| `GET /api/products` | 取得商品列表（分頁、排序、關鍵字搜尋、依分類過濾） |
| `GET /api/products/:id` | 取得單一商品（含分類名稱，JOIN 查詢） |

Query string 參數：
```
page=1&limit=12&sort=price&order=asc&category_id=2&search=筆電
```

### 3. 購物車模組（`routes/cart.js`）—— 需 JWT 驗證

| 路由 | 說明 |
|------|------|
| `GET /api/cart` | 取得購物車內容（JOIN products 取得商品資訊及小計） |
| `POST /api/cart` | 加入商品（若已存在則累加數量；驗證庫存是否足夠） |
| `PUT /api/cart/:product_id` | 更新某商品數量（0 表示移除） |
| `DELETE /api/cart/:product_id` | 移除單一商品 |
| `DELETE /api/cart` | 清空購物車 |

### 4. 結帳下單模組（`routes/orders.js`）—— 需 JWT 驗證

| 路由 | 說明 |
|------|------|
| `POST /api/orders/checkout` | 結帳（Transaction：建立 order → 寫入 order_items → 扣減庫存 → 清空購物車） |
| `GET /api/orders` | 取得登入者歷史訂單（含各訂單總金額） |
| `GET /api/orders/:id` | 取得單一訂單詳情（含所有 order_items 及商品名稱） |

### 5. 全域 Middleware

- `middleware/auth.js`：驗證 JWT，將 `req.user` 注入
- `middleware/errorHandler.js`：統一錯誤格式 `{ error: string, code: number }`
- 所有寫入端點加入輸入驗證（必填欄位、數字範圍、白名單狀態值）

## 提示

- 用 `pg` 套件連線 PostgreSQL，封裝成 `db/pool.js`
- 結帳 Transaction 範例（確保庫存不會超賣）：
  ```js
  const client = await pool.connect();
  try {
    await client.query('BEGIN');
    // 1. 鎖定商品列（FOR UPDATE 防止並發扣減）
    const { rows: items } = await client.query(
      `SELECT p.id, p.price, p.stock, ci.quantity
         FROM cart_items ci
         JOIN products p ON p.id = ci.product_id
        WHERE ci.user_id = $1
        FOR UPDATE OF p`,
      [userId]
    );
    // 2. 檢查庫存
    for (const item of items) {
      if (item.stock < item.quantity)
        throw Object.assign(new Error(`${item.id} 庫存不足`), { status: 409 });
    }
    // 3. 建立訂單、寫入 order_items、扣減庫存、清空購物車
    // ...
    await client.query('COMMIT');
  } catch (e) {
    await client.query('ROLLBACK');
    throw e;
  } finally {
    client.release();
  }
  ```
- 商品圖片：使用 `multer` 實作 `POST /api/products/:id/image`（管理員用），將路徑存回 `products.image_url`
- JWT 驗證：`Authorization: Bearer <token>`，使用 `jsonwebtoken` 套件
- 購物車回應格式範例：
  ```json
  {
    "items": [
      { "product_id": 1, "name": "機械鍵盤", "quantity": 2, "unit_price": 1500, "subtotal": 3000 }
    ],
    "total": 3000
  }
  ```

## 進階挑戰（選做）

1. **庫存預警**：`GET /api/products/low-stock?threshold=5` 回傳庫存低於門檻的商品清單
2. **訂單取消**：`PATCH /api/orders/:id/cancel`，只有 `pending` 狀態可取消，並回滾庫存（Transaction）
3. **銷售統計**：`GET /api/products/:id/stats` 回傳該商品總銷售量與總銷售額
4. **API 測試**：用 Jest + supertest 覆蓋 register → login → 加購物車 → 結帳 → 查訂單 完整流程
5. **速率限制**：使用 `express-rate-limit` 限制 `/api/orders/checkout` 每分鐘最多 5 次，防止機器人刷單
