# 第 12 週今日練習題：書籍管理 REST API 實戰專案

## 題目說明

綜合前 11 週所學，從零到一打造一個完整的**書籍管理系統 REST API**。本專案涵蓋路由設計、資料庫操作、身份驗證、分頁查詢、資料驗證與錯誤處理，模擬真實後端開發流程。

---

## 技術要求

- **Express.js**：路由模組化（Router）、Middleware 鏈、統一錯誤處理
- **PostgreSQL**：多資料表設計（users、books、categories）、JOIN 查詢、Transaction
- **JWT**：受保護路由需附帶 Bearer Token
- **資料驗證**：Joi 或手動驗證，回傳標準化錯誤格式
- **分頁 & 排序**：支援 `?page=`、`?limit=`、`?sort=`、`?order=`

---

## 具體任務

### 1. 資料庫設計

建立以下三張資料表：

```sql
-- 使用者表
CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  email VARCHAR(255) UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 分類表
CREATE TABLE categories (
  id SERIAL PRIMARY KEY,
  name VARCHAR(100) UNIQUE NOT NULL
);

-- 書籍表
CREATE TABLE books (
  id SERIAL PRIMARY KEY,
  title VARCHAR(255) NOT NULL,
  author VARCHAR(255) NOT NULL,
  category_id INT REFERENCES categories(id) ON DELETE SET NULL,
  price NUMERIC(10, 2) NOT NULL,
  stock INT DEFAULT 0,
  created_by INT REFERENCES users(id),
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

### 2. 身份驗證 API

| 方法 | 路徑 | 說明 |
|------|------|------|
| POST | `/api/auth/register` | 註冊（bcrypt 加密密碼） |
| POST | `/api/auth/login` | 登入，回傳 JWT |

### 3. 書籍 CRUD API（需登入）

| 方法 | 路徑 | 說明 |
|------|------|------|
| GET | `/api/books` | 取得書籍列表（含分頁、排序） |
| GET | `/api/books/:id` | 取得單本書籍（JOIN category） |
| POST | `/api/books` | 新增書籍 |
| PUT | `/api/books/:id` | 更新書籍（只有建立者可修改） |
| DELETE | `/api/books/:id` | 刪除書籍（Transaction 確保一致性） |

### 4. 分頁查詢

GET `/api/books` 支援以下 Query String：

```
?page=1&limit=10&sort=price&order=asc&search=JavaScript
```

回應格式：
```json
{
  "data": [...],
  "pagination": {
    "page": 1,
    "limit": 10,
    "total": 42,
    "totalPages": 5
  }
}
```

### 5. 統一錯誤回應格式

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "price 必須為正數"
  }
}
```

## 提示

- 使用 `bcryptjs` 雜湊密碼，`jsonwebtoken` 簽發 Token
- JWT Middleware 從 `Authorization: Bearer <token>` 解析並將 `req.user` 注入後續路由
- DELETE 操作建議用 Transaction：先刪關聯資料，再刪書籍主記錄
- 分頁計算：`OFFSET = (page - 1) * limit`，搭配 `COUNT(*) OVER()` 取總筆數
- 排序欄位需白名單驗證，防止 SQL Injection：`const ALLOWED_SORT = ['title','price','created_at']`
- 使用 `pool.connect()` 取得 client 進行 Transaction，記得在 finally 中 `client.release()`

## 進階挑戰（選做）

1. **軟刪除**：books 表加 `deleted_at`，DELETE 僅標記時間戳，查詢自動過濾
2. **角色權限**：users 加 `role` 欄位（`admin` / `user`），admin 可刪除任何書籍
3. **Rate Limiting**：使用 `express-rate-limit`，登入 API 每分鐘最多 5 次
4. **API 測試**：用 Jest + supertest 撰寫完整 Integration Test，涵蓋所有 API 路徑
5. **Docker Compose**：建立 `docker-compose.yml`，一鍵啟動 Node.js + PostgreSQL 環境
