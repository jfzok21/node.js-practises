# 第 21 週今日練習題：書籍借閱管理系統 API

## 題目說明

建立一個完整的書籍借閱管理系統後端 API，支援圖書館管理員與借閱者兩種角色。系統需涵蓋書籍管理、會員管理、借閱記錄、逾期通知等核心功能，整合先前各週所學的 Express、PostgreSQL、JWT 驗證、資料驗證、分頁、Transaction 等技術。

## 技術要求
- **Express.js**：RESTful 路由設計，Role-based 存取控制，全域錯誤處理 Middleware
- **PostgreSQL**：多資料表關聯（books、members、loans），JOIN 查詢，Transaction 確保借閱一致性
- **認證**：JWT（管理員 / 一般會員 兩種角色）
- **驗證**：joi 或 express-validator 驗證請求欄位
- **查詢**：分頁、依到期日排序、全文搜尋書名／作者
- **交易**：借書 & 還書流程使用 PostgreSQL Transaction

## 資料庫 Schema

```sql
-- 書籍
CREATE TABLE books (
  id         SERIAL PRIMARY KEY,
  title      VARCHAR(200) NOT NULL,
  author     VARCHAR(100) NOT NULL,
  isbn       VARCHAR(20) UNIQUE NOT NULL,
  total_qty  INT NOT NULL DEFAULT 1,
  avail_qty  INT NOT NULL DEFAULT 1,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 會員
CREATE TABLE members (
  id         SERIAL PRIMARY KEY,
  name       VARCHAR(100) NOT NULL,
  email      VARCHAR(150) UNIQUE NOT NULL,
  password   VARCHAR(255) NOT NULL,
  role       VARCHAR(20) NOT NULL DEFAULT 'member', -- 'admin' | 'member'
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 借閱記錄
CREATE TABLE loans (
  id          SERIAL PRIMARY KEY,
  book_id     INT NOT NULL REFERENCES books(id),
  member_id   INT NOT NULL REFERENCES members(id),
  loaned_at   TIMESTAMPTZ DEFAULT NOW(),
  due_at      TIMESTAMPTZ NOT NULL,
  returned_at TIMESTAMPTZ
);
```

## 具體任務

1. **認證端點**
   - `POST /api/auth/register` — 會員註冊（預設 role = 'member'）
   - `POST /api/auth/login` — 登入，回傳 JWT（payload 含 id、role）

2. **書籍管理（管理員限定）**
   - `GET  /api/books` — 列出書籍，支援 `?search=關鍵字&page=1&limit=10`
   - `POST /api/books` — 新增書籍
   - `PUT  /api/books/:id` — 更新書籍資料
   - `DELETE /api/books/:id` — 刪除書籍（若有未還借閱則拒絕）

3. **借閱流程（需 JWT）**
   - `POST /api/loans` — 借書
     - 請求體：`{ book_id, due_days }` （due_days 預設 14）
     - 以 Transaction 確認 `avail_qty > 0` 後扣減並建立 loan 記錄
     - 若庫存不足回傳 `409 Conflict`
   - `PATCH /api/loans/:id/return` — 還書
     - 以 Transaction 更新 `returned_at` 並增加 `avail_qty`

4. **借閱查詢**
   - `GET /api/loans/my` — 目前使用者的借閱清單（含書名、到期日、是否逾期）
   - `GET /api/loans/overdue` — 管理員查看所有逾期未還記錄（JOIN books + members）

5. **全域 Middleware**
   - `authenticate` — 驗證 JWT，將 `req.user` 注入
   - `authorize(roles)` — 角色守衛，不符合角色回傳 `403 Forbidden`
   - 錯誤處理 Middleware 統一回傳 `{ error: message }` 格式

## 提示

- `avail_qty` 的更新務必在 Transaction 內進行，避免超借 Race Condition
- 逾期判斷：`due_at < NOW() AND returned_at IS NULL`
- 借閱清單可加入計算欄位：`due_at < NOW() AS is_overdue`
- 密碼使用 `bcrypt` 雜湊，不可明文儲存
- 刪除書籍前先 `SELECT COUNT(*) FROM loans WHERE book_id = $1 AND returned_at IS NULL`

## 進階挑戰（選做）

- **逾期費計算**：還書時若已逾期，計算逾期天數 × 每日罰款（例如 NT$5），回傳應繳金額
- **電子郵件通知**：整合 nodemailer，借書成功時寄送到期提醒 Email
- **API 限流**：使用 `express-rate-limit` 限制登入端點（每 15 分鐘最多 10 次）
- **超時自動歸還**：以 `node-cron` 每日執行，標記已逾期 7 天的借閱為「強制歸還」
- **整合測試**：用 supertest + Jest 撰寫借書 & 還書流程的端對端測試
