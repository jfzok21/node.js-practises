# 第 5 週今日練習題：書店訂單系統 — JOIN 查詢與多資料表關聯

## 題目說明

建立一個書店後端 API，資料庫包含三張相互關聯的資料表：`customers`（顧客）、`books`（書籍）、`orders`（訂單）。你需要撰寫結合 JOIN 的查詢來取得跨資料表的複合資訊，例如「哪位顧客訂了哪本書」、「每位顧客的總消費金額」等。

---

## 技術要求

- **Express.js**：建立 RESTful 路由，回傳 JSON
- **PostgreSQL**：使用 `INNER JOIN`、`LEFT JOIN`、`GROUP BY`、聚合函數（`SUM`、`COUNT`）

---

## 資料庫結構

請先建立以下資料表（可貼入 `psql` 執行）：

```sql
CREATE TABLE customers (
  id SERIAL PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(150) UNIQUE NOT NULL
);

CREATE TABLE books (
  id SERIAL PRIMARY KEY,
  title VARCHAR(200) NOT NULL,
  author VARCHAR(100) NOT NULL,
  price NUMERIC(10, 2) NOT NULL
);

CREATE TABLE orders (
  id SERIAL PRIMARY KEY,
  customer_id INTEGER REFERENCES customers(id) ON DELETE CASCADE,
  book_id INTEGER REFERENCES books(id) ON DELETE CASCADE,
  quantity INTEGER NOT NULL DEFAULT 1,
  ordered_at TIMESTAMP DEFAULT NOW()
);
```

並插入幾筆測試資料：

```sql
INSERT INTO customers (name, email) VALUES
  ('Alice', 'alice@example.com'),
  ('Bob', 'bob@example.com'),
  ('Carol', 'carol@example.com');

INSERT INTO books (title, author, price) VALUES
  ('Node.js 實戰', '張小明', 450),
  ('PostgreSQL 入門', '李大華', 380),
  ('Express 速成', '王美玲', 320);

INSERT INTO orders (customer_id, book_id, quantity) VALUES
  (1, 1, 2),
  (1, 3, 1),
  (2, 2, 1),
  (3, 1, 1),
  (3, 2, 3);
```

## 具體任務

1. **取得所有訂單明細**
   - `GET /orders`
   - 回傳每筆訂單，包含：顧客姓名、書名、單價、數量、小計（`price * quantity`）
   - 使用 `INNER JOIN` 連結三張資料表

2. **取得單一顧客的所有訂單**
   - `GET /customers/:id/orders`
   - 回傳該顧客的姓名與其訂購的所有書籍清單（書名、數量、小計）
   - 若顧客不存在，回傳 `404 { error: "顧客不存在" }`

3. **統計每位顧客的總消費金額與訂單數**
   - `GET /customers/stats`
   - 使用 `LEFT JOIN` + `GROUP BY` + `SUM` + `COUNT`
   - 回傳格式範例：
     ```json
     [
       { "name": "Alice", "total_spent": "1220.00", "order_count": "2" },
       { "name": "Bob",   "total_spent": "380.00",  "order_count": "1" },
       { "name": "Carol", "total_spent": "1590.00", "order_count": "2" }
     ]
     ```
   - 沒有訂單的顧客也要出現（`total_spent` 為 `null` 或 `"0.00"`）

4. **查詢最暢銷書籍（依總銷售數量排序）**
   - `GET /books/bestsellers`
   - 回傳書籍清單，包含 `title`、`author`、`total_sold`（總銷售數量）
   - 由高到低排序，使用 `ORDER BY total_sold DESC`

## 提示

- 連接 PostgreSQL 可使用 `pg` 套件（`npm install pg`）
- 查詢範例（任務一）：
  ```sql
  SELECT
    c.name AS customer_name,
    b.title AS book_title,
    b.price,
    o.quantity,
    (b.price * o.quantity) AS subtotal
  FROM orders o
  INNER JOIN customers c ON o.customer_id = c.id
  INNER JOIN books b ON o.book_id = b.id;
  ```
- 注意路由順序：`GET /customers/stats` 必須定義在 `GET /customers/:id/orders` **之前**，否則 Express 會把 `stats` 當成 `:id`
- `LEFT JOIN` 確保即使顧客沒有訂單也會出現在結果中
