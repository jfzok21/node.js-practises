# 第 20 週今日練習題：部落格 API 實戰專案（綜合整合）

## 題目說明

建立一個完整的部落格後端 REST API，整合前幾週所學的所有技術。這個專案包含使用者管理、文章 CRUD、留言系統、身份驗證、分頁查詢與完整測試覆蓋。

## 技術要求
- **Express.js**：路由分層、自訂 Middleware、統一錯誤處理、JWT 驗證保護路由
- **PostgreSQL**：多資料表設計（users、posts、comments）、JOIN 查詢、Transaction、分頁與排序

## 資料庫 Schema

```sql
CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  username VARCHAR(50) UNIQUE NOT NULL,
  email VARCHAR(100) UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE posts (
  id SERIAL PRIMARY KEY,
  title VARCHAR(200) NOT NULL,
  content TEXT NOT NULL,
  author_id INTEGER REFERENCES users(id) ON DELETE CASCADE,
  published BOOLEAN DEFAULT false,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE comments (
  id SERIAL PRIMARY KEY,
  post_id INTEGER REFERENCES posts(id) ON DELETE CASCADE,
  author_id INTEGER REFERENCES users(id) ON DELETE CASCADE,
  content TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);
```

## 具體任務

1. **使用者模組** (`/api/auth`)
   - `POST /api/auth/register`：註冊新使用者（bcrypt 雜湊密碼）
   - `POST /api/auth/login`：登入並回傳 JWT token

2. **文章模組** (`/api/posts`)
   - `GET /api/posts`：取得所有已發布文章（支援 `?page=1&limit=10&sort=created_at&order=desc`）
   - `GET /api/posts/:id`：取得單篇文章（含作者資訊與留言數）
   - `POST /api/posts`：建立新文章（需 JWT 驗證）
   - `PUT /api/posts/:id`：更新文章（僅作者本人可操作，使用 Transaction）
   - `DELETE /api/posts/:id`：刪除文章（僅作者本人可操作）

3. **留言模組** (`/api/posts/:postId/comments`)
   - `GET /api/posts/:postId/comments`：取得某篇文章所有留言（含作者 username）
   - `POST /api/posts/:postId/comments`：新增留言（需 JWT 驗證）
   - `DELETE /api/posts/:postId/comments/:id`：刪除留言（僅留言作者可操作）

4. **統計端點**
   - `GET /api/stats`：回傳 `{ total_users, total_posts, total_comments }`（使用單一 SQL 查詢完成）

5. **整合測試**（使用 supertest + Jest）
   - 為以上至少 5 個端點撰寫測試（含成功與失敗情境）
   - 測試前建立測試資料庫，測試後清除

## 提示

- 使用 `express-validator` 或自訂 middleware 進行請求資料驗證
- JWT 驗證邏輯抽成 `authMiddleware`，掛在需要保護的路由上
- 更新文章時，先查詢 `author_id` 再比對 JWT 的 `userId`，不符則回傳 403
- 刪除文章時，使用 Transaction 確保相關留言也一併刪除（或依賴 `ON DELETE CASCADE`）
- 分頁查詢範例：
  ```sql
  SELECT p.*, u.username AS author_name,
         COUNT(c.id) AS comment_count
  FROM posts p
  JOIN users u ON p.author_id = u.id
  LEFT JOIN comments c ON c.post_id = p.id
  WHERE p.published = true
  GROUP BY p.id, u.username
  ORDER BY p.created_at DESC
  LIMIT $1 OFFSET $2;
  ```
- 統一錯誤格式：`{ "error": "訊息", "code": "ERROR_CODE" }`

## 進階挑戰（選做）

- **標籤系統**：新增 `tags` 資料表與多對多關聯（`post_tags`），支援 `GET /api/posts?tag=nodejs`
- **全文搜尋**：在 `GET /api/posts?search=keyword` 中使用 PostgreSQL `tsvector` 全文搜尋
- **圖片上傳**：整合 `multer`，讓文章可以附帶封面圖片，儲存路徑記錄於 posts 表
- **速率限制**：使用 `express-rate-limit` 保護登入端點，防止暴力破解
- **API 文件**：使用 `swagger-jsdoc` 為所有端點自動產生 OpenAPI 文件
