# 第 20 週今日練習題：即時任務看板 API（WebSocket + Redis Pub/Sub）

## 題目說明

實作一個輕量版「即時任務看板」後端系統，讓多位使用者能即時看到任務狀態的更新。當任何使用者新增、移動或刪除任務卡片時，所有連線中的使用者都會立即收到通知。本題整合 Express REST API（持久化）與 WebSocket（即時推播），並以 Redis Pub/Sub 作為廣播層，模擬生產環境常見的「多 instance 廣播」架構。

## 技術要求

- **Express.js**：REST API 負責任務的 CRUD 操作與 JWT 驗證
- **PostgreSQL**：持久化儲存任務與看板資料
- **ws（WebSocket library）**：伺服器端 WebSocket，負責將事件推播給所有已連線用戶端
- **ioredis**：Redis Pub/Sub，讓多個 Node.js process 能互相廣播事件（本練習可用單 process，模擬架構即可）
- **JWT**：WebSocket 連線時以 query string 傳遞 token 完成身份驗證

## 資料庫 Schema

```sql
CREATE TABLE boards (
  id SERIAL PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  owner_id INTEGER NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE columns (
  id SERIAL PRIMARY KEY,
  board_id INTEGER REFERENCES boards(id) ON DELETE CASCADE,
  name VARCHAR(100) NOT NULL,
  position INTEGER NOT NULL DEFAULT 0
);

CREATE TABLE tasks (
  id SERIAL PRIMARY KEY,
  column_id INTEGER REFERENCES columns(id) ON DELETE CASCADE,
  board_id INTEGER REFERENCES boards(id) ON DELETE CASCADE,
  title VARCHAR(200) NOT NULL,
  description TEXT,
  assignee_id INTEGER,
  position INTEGER NOT NULL DEFAULT 0,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_tasks_board_id ON tasks(board_id);
CREATE INDEX idx_tasks_column_id ON tasks(column_id);
```

## 具體任務

1. **建立專案結構**
   ```
   src/
   ├── routes/
   │   ├── auth.js
   │   ├── boards.js
   │   └── tasks.js
   ├── controllers/
   │   ├── boardController.js
   │   └── taskController.js
   ├── middleware/
   │   └── auth.js
   ├── websocket/
   │   ├── server.js       ← WebSocket 伺服器與連線管理
   │   └── broadcaster.js  ← Redis subscriber 收到訊息後廣播給 ws clients
   ├── redis/
   │   └── client.js       ← ioredis publish / subscribe 實例
   ├── db.js
   └── app.js
   ```

2. **實作 REST API**
   - `POST /api/auth/register` / `POST /api/auth/login`：同前幾週，回傳 JWT
   - `POST /api/boards`：建立看板（需 JWT）
   - `GET /api/boards/:id`：取得看板完整結構（含欄位與任務，以 JOIN 查詢）
   - `POST /api/boards/:id/tasks`：在指定欄位新增任務（需 JWT）
   - `PATCH /api/tasks/:id`：更新任務（標題、描述、assignee、移動到其他欄位）
   - `DELETE /api/tasks/:id`：刪除任務（需 JWT，僅限任務建立者或看板擁有者）

3. **實作事件廣播流程**

   每當 REST API 完成任務的 CREATE / UPDATE / DELETE 後，publish 一個事件到 Redis channel：
   ```js
   // redis/client.js
   const Redis = require('ioredis');
   const publisher = new Redis(process.env.REDIS_URL);
   const subscriber = new Redis(process.env.REDIS_URL);

   module.exports = { publisher, subscriber };
   ```

   Publish 範例（taskController.js）：
   ```js
   const { publisher } = require('../redis/client');

   async function createTask(req, res) {
     // ... INSERT INTO tasks ...
     const task = rows[0];
     await publisher.publish(
       `board:${task.board_id}`,
       JSON.stringify({ event: 'task_created', payload: task })
     );
     res.status(201).json(task);
   }
   ```

   支援的事件類型：
   | event | 觸發時機 |
   |---|---|
   | `task_created` | 新增任務 |
   | `task_updated` | 更新任務（含移欄） |
   | `task_deleted` | 刪除任務 |

4. **實作 WebSocket 伺服器**

   ```js
   // websocket/server.js
   const WebSocket = require('ws');
   const jwt = require('jsonwebtoken');

   // boardClients: Map<boardId, Set<ws>>
   const boardClients = new Map();

   function setupWebSocket(server) {
     const wss = new WebSocket.Server({ server });

     wss.on('connection', (ws, req) => {
       // 從 query string 取得 token 與 boardId
       const params = new URLSearchParams(req.url.split('?')[1]);
       const token = params.get('token');
       const boardId = params.get('boardId');

       // 驗證 JWT
       let user;
       try {
         user = jwt.verify(token, process.env.JWT_SECRET);
       } catch {
         ws.close(1008, 'Unauthorized');
         return;
       }

       // 訂閱對應看板頻道
       if (!boardClients.has(boardId)) boardClients.set(boardId, new Set());
       boardClients.get(boardId).add(ws);

       ws.on('close', () => {
         boardClients.get(boardId)?.delete(ws);
       });
     });

     return boardClients;
   }

   module.exports = { setupWebSocket, boardClients };
   ```

5. **實作 Redis Subscriber 廣播**

   ```js
   // websocket/broadcaster.js
   const { subscriber } = require('../redis/client');
   const { boardClients } = require('./server');

   function startBroadcaster() {
     subscriber.psubscribe('board:*');
     subscriber.on('pmessage', (pattern, channel, message) => {
       const boardId = channel.split(':')[1];
       const clients = boardClients.get(boardId);
       if (!clients) return;
       clients.forEach(ws => {
         if (ws.readyState === 1) ws.send(message);
       });
     });
   }

   module.exports = { startBroadcaster };
   ```

   在 `app.js` 啟動時呼叫 `startBroadcaster()`。

6. **整合到 HTTP Server**

   ```js
   // app.js（啟動部分）
   const http = require('http');
   const { setupWebSocket } = require('./websocket/server');
   const { startBroadcaster } = require('./websocket/broadcaster');

   const server = http.createServer(app);
   setupWebSocket(server);
   startBroadcaster();

   server.listen(3000, () => console.log('Server running on port 3000'));
   ```

7. **驗證功能**

   用兩個終端機模擬兩位使用者：
   ```bash
   # 終端機 1：連線 WebSocket（用 wscat 或 websocat）
   wscat -c "ws://localhost:3000?token=<JWT>&boardId=1"

   # 終端機 2：呼叫 REST API 新增任務
   curl -X POST http://localhost:3000/api/boards/1/tasks \
     -H "Authorization: Bearer <JWT>" \
     -H "Content-Type: application/json" \
     -d '{"column_id": 1, "title": "修復登入 Bug"}'
   ```
   終端機 1 應立即收到 `{"event":"task_created","payload":{...}}` 訊息。

## 提示

- `ws` package 安裝：`npm install ws ioredis`
- WebSocket 連線 URL 格式：`ws://localhost:3000?token=JWT_TOKEN&boardId=BOARD_ID`
- `ioredis` 的 `psubscribe` 支援 wildcard（`board:*`），可用單一 subscriber 監聽所有看板頻道
- 連線斷開時務必從 `boardClients` 中移除，避免記憶體洩漏
- 生產環境中 publisher 與 subscriber 需要獨立的 Redis 連線（不能共用同一個 ioredis instance）
- 本地測試可用 Docker 啟動 Redis：`docker run -d -p 6379:6379 redis:alpine`

## 進階挑戰（選做）

- 在 WebSocket 連線層加入 **心跳機制（heartbeat）**：伺服器每 30 秒 ping 一次，未回應的 client 強制斷線
  ```js
  wss.on('connection', (ws) => {
    ws.isAlive = true;
    ws.on('pong', () => { ws.isAlive = true; });
  });
  const heartbeat = setInterval(() => {
    wss.clients.forEach(ws => {
      if (!ws.isAlive) return ws.terminate();
      ws.isAlive = false;
      ws.ping();
    });
  }, 30000);
  wss.on('close', () => clearInterval(heartbeat));
  ```
- 加入「使用者上線/下線」通知：有人連線或斷線時廣播 `{"event":"user_joined","userId":X}` 給同看板的其他使用者
- 為廣播邏輯撰寫 `supertest + Jest` 整合測試，驗證 REST API 呼叫後 Redis publisher 確實發送正確的 channel 與 payload（使用 mock `ioredis`）
- 在 REST API 加入 **樂觀鎖（Optimistic Locking）**：tasks 表增加 `version INTEGER DEFAULT 1`，PATCH 時需傳入當前 version，若不符則回傳 `409 CONFLICT`，避免多人同時編輯同一任務覆蓋彼此的修改
