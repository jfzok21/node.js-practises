# 第 5 週今日練習題：書籍與作者資料庫 JOIN 查詢 API

## 題目說明

建立一個書籍管理系統，包含兩張資料表：`authors`（作者）與 `books`（書籍）。透過 JOIN 查詢實作多資料表的關聯 API，讓前端能夠一次取得完整的書籍與作者資訊。

## 技術要求
- **Express.js**：建立 RESTful API，回傳 JSON 格式資料
- **PostgreSQL**：設計兩張關聯資料表，使用 INNER JOIN、LEFT JOIN 進行查詢

## 具體任務

### 1. 建立資料表

執行以下 SQL 建立資料表：

```sql
CREATE TABLE authors (
  id SERIAL PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  nationality VARCHAR(50)
);

CREATE TABLE books (
  id SERIAL PRIMARY KEY,
  title VARCHAR(200) NOT NULL,
  published_year INT,
  author_id INT REFERENCES authors(id) ON DELETE SET NULL
);
```

插入範例資料：

```sql
INSERT INTO authors (name, nationality) VALUES
  ('村上春樹', '日本'),
  ('余華', '中國'),
  ('J.K. 羅琳', '英國');

INSERT INTO books (title, published_year, author_id) VALUES
  ('挪威的森林', 1987, 1),
  ('1Q84', 2009, 1),
  ('活著', 1993, 2),
  ('哈利波特：神秘的魔法石', 1997, 3),
  ('孤兒書（無作者）', 2020, NULL);
```

### 2. 實作 API 端點

| 方法 | 路徑 | 說明 |
|------|------|------|
| GET | `/books` | 取得所有書籍（含作者資訊，用 LEFT JOIN） |
| GET | `/books/:id` | 取得單一書籍詳情（含作者） |
| GET | `/authors/:id/books` | 取得特定作者的所有書籍 |
| GET | `/authors` | 取得所有作者（含其書籍數量） |

### 3. `/books` 回傳格式範例

```json
[
  {
    "book_id": 1,
    "title": "挪威的森林",
    "published_year": 1987,
    "author_id": 1,
    "author_name": "村上春樹",
    "nationality": "日本"
  },
  {
    "book_id": 5,
    "title": "孤兒書（無作者）",
    "published_year": 2020,
    "author_id": null,
    "author_name": null,
    "nationality": null
  }
]
```

### 4. `/authors` 回傳格式範例（含書籍數量）

```json
[
  {
    "author_id": 1,
    "name": "村上春樹",
    "nationality": "日本",
    "book_count": 2
  }
]
```

### 5. 錯誤處理

- 若 `id` 對應的書籍或作者不存在，回傳 `404 { "error": "找不到資源" }`
- 若資料庫連線失敗，回傳 `500 { "error": "伺服器錯誤" }`

## 提示

- 使用 `LEFT JOIN` 而非 `INNER JOIN` 於 `/books`，確保無作者的書籍也能被列出
- PostgreSQL 中 `COUNT(*)` 會計算包含 NULL 的行；若只想算有書的，改用 `COUNT(books.id)`
- 推薦使用 `pg` 套件（node-postgres）連接 PostgreSQL：
  ```js
  const { Pool } = require('pg');
  const pool = new Pool({ connectionString: process.env.DATABASE_URL });
  ```
- 查詢語法範例：
  ```sql
  SELECT books.id AS book_id, books.title, books.published_year,
         authors.id AS author_id, authors.name AS author_name, authors.nationality
  FROM books
  LEFT JOIN authors ON books.author_id = authors.id;
  ```

## 進階挑戰（選做）

1. **搜尋功能**：在 `/books?search=村上` 加入模糊搜尋，依書名或作者名過濾
2. **多層 JOIN**：新增 `genres`（書籍類型）資料表，讓 `/books` 也回傳類型名稱
3. **統計端點**：實作 `GET /stats`，回傳各國籍作者的書籍數量統計
   ```sql
   SELECT authors.nationality, COUNT(books.id) AS total_books
   FROM authors
   LEFT JOIN books ON books.author_id = authors.id
   GROUP BY authors.nationality
   ORDER BY total_books DESC;
   ```
