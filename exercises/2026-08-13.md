# 第 6 週今日練習題：使用者資料驗證與統一錯誤回應

## 題目說明

你正在開發一個使用者管理 API。在接收前端傳入的資料時，必須先進行嚴格的格式與業務邏輯驗證，並在發生錯誤時回傳統一、易讀的 JSON 錯誤格式，讓前端能清楚知道哪個欄位出了什麼問題。

---

## 技術要求

- **Express.js**：建立 POST `/api/users` 與 PUT `/api/users/:id` 路由，搭配集中式錯誤處理 Middleware
- **PostgreSQL**：`users` 資料表，欄位包含 `id`、`username`、`email`、`age`、`created_at`

---

## 具體任務

1. **建立資料表**

   在 PostgreSQL 中執行以下 SQL：

   ```sql
   CREATE TABLE IF NOT EXISTS users (
     id SERIAL PRIMARY KEY,
     username VARCHAR(50) NOT NULL UNIQUE,
     email VARCHAR(100) NOT NULL UNIQUE,
     age INTEGER,
     created_at TIMESTAMP DEFAULT NOW()
   );
   ```

2. **實作輸入驗證邏輯**（可寫成獨立的 `validators/user.js`）

   驗證規則：
   - `username`：必填，長度 3–50 字元，只允許英數字與底線
   - `email`：必填，需符合標準 Email 格式
   - `age`：選填，若存在則必須是 0–120 的整數

3. **實作 POST `/api/users`**

   - 驗證通過後將使用者新增至資料庫
   - 若 `username` 或 `email` 已存在，回傳 409 衝突錯誤
   - 成功回傳 201 狀態碼與新建使用者資料

4. **實作 PUT `/api/users/:id`**

   - 先確認該使用者存在（不存在則回傳 404）
   - 允許部分更新（只傳入要修改的欄位）
   - 同樣套用驗證規則並回傳更新後的資料

5. **集中式錯誤 Middleware**

   在 `app.js` 最後掛載一個錯誤處理中介層，統一將錯誤轉換為以下格式：

   ```json
   {
     "success": false,
     "error": {
       "code": "VALIDATION_ERROR",
       "message": "輸入資料有誤",
       "details": [
         { "field": "email", "message": "Email 格式不正確" },
         { "field": "age",   "message": "年齡必須為 0 到 120 之間的整數" }
       ]
     }
   }
   ```

   常用 error code 建議：
   | 情境 | HTTP 狀態 | code |
   |---|---|---|
   | 欄位驗證失敗 | 400 | `VALIDATION_ERROR` |
   | 資源不存在 | 404 | `NOT_FOUND` |
   | 唯一鍵衝突 | 409 | `CONFLICT` |
   | 伺服器內部錯誤 | 500 | `INTERNAL_ERROR` |

---

## 提示

- 使用 `next(err)` 將錯誤傳遞給集中式 Middleware，而非在每個路由裡各自 `res.json()`
- 建立自訂 Error 類別（例如 `class AppError extends Error`）來夾帶 `statusCode` 與 `code` 屬性，讓 Middleware 更容易判斷
- PostgreSQL 唯一鍵衝突會拋出 `error.code === '23505'`，可在 catch 區塊攔截並轉換為 409
- `express-validator` 套件可大幅簡化驗證邏輯（選用）

---

## 進階挑戰（選做）

- 使用 `express-validator` 的 `validationResult()` 重構驗證邏輯，讓每個路由更簡潔
- 新增 GET `/api/users/:id`，若 `id` 非正整數則回傳 `INVALID_PARAM` 錯誤
- 替所有路由撰寫 Jest + supertest 測試，覆蓋正常路徑與各種錯誤情境
- 記錄所有 5xx 錯誤至 log 檔（使用 `morgan` 或 `winston`）
