# 第 13 週今日練習題：部落格 API 實戰專案（完整功能整合）

## 題目說明

建立一個具備完整功能的部落格後端 API，整合前幾週所學的所有技術：路由、PostgreSQL CRUD、Middleware、JWT 驗證、分頁、資料驗證與交易處理。這個專案將模擬真實開發場景，讓你練習如何將多個技術模組組合成一個可用的系統。

## 技術要求
- **Express.js**：RESTful 路由設計、自訂 Middleware、錯誤處理中介層
- **PostgreSQL**：多資料表關聯（users、posts、comments）、JOIN 查詢、Transaction
- **JWT**：使用者身份驗證與授權保護路由
- **資料驗證**：請求參數與 body 驗證
- **分頁**：文章列表與留言列表支援分頁與排序

## 具體任務

1. **資料庫設計**：建立以下三張資料表：
   ```sql
   -- 使用者
   CREATE TABLE users (
     id SERIAL PRIMARY KEY,
     username VARCHAR(50) UNIQUE NOT NULL,
     email VARCHAR(100) UNIQUE NOT NULL,
     password_hash TEXT NOT NULL,
     created_at TIMESTAMP DEFAULT NOW()
   );

   -- 文章
   CREATE TABLE posts (
     id SERIAL PRIMARY KEY,
     user_id INTEGER REFERENCES users(id) ON DELETE CASCADE,
     title VARCHAR(200) NOT NULL,
     content TEXT NOT NULL,
     published BOOLEAN DEFAULT FALSE,
     created_at TIMESTAMP DEFAULT NOW(),
     updated_at TIMESTAMP DEFAULT NOW()
   );

   -- 留言
   CREATE TABLE comments (
     id SERIAL PRIMARY KEY,
     post_id INTEGER REFERENCES posts(id) ON DELETE CASCADE,
     user_id INTEGER REFERENCES users(id) ON DELETE CASCADE,
     content TEXT NOT NULL,
     created_at TIMESTAMP DEFAULT NOW()
   );
   ```

2. **使用者 API**（不需驗證）：
   - `POST /api/auth/register`：註冊（bcrypt 加密密碼）
   - `POST /api/auth/login`：登入（回傳 JWT token）

3. **文章 API**（部分需 JWT 驗證）：
   - `GET /api/posts`：取得已發佈文章列表（支援分頁 `?page=1&limit=10`、排序 `?sort=created_at&order=desc`）
   - `GET /api/posts/:id`：取得單篇文章（含作者資訊與留言數）
   - `POST /api/posts`：建立文章（需登入）
   - `PUT /api/posts/:id`：更新文章（需登入，且只能更新自己的文章）
   - `DELETE /api/posts/:id`：刪除文章（需登入，且只能刪除自己的文章）

4. **留言 API**（需 JWT 驗證）：
   - `GET /api/posts/:id/comments`：取得文章留言（支援分頁）
   - `POST /api/posts/:id/comments`：新增留言
   - `DELETE /api/posts/:postId/comments/:commentId`：刪除留言（只能刪除自己的留言）

5. **交易處理**：刪除文章時，使用 Transaction 確保同時刪除該文章的所有留言，若任一步驟失敗則全部 rollback。

6. **錯誤處理中介層**：統一的錯誤回應格式：
   ```json
   {
     "success": false,
     "error": {
       "code": "NOT_FOUND",
       "message": "文章不存在"
     }
   }
   ```

## 提示

- 使用 `bcrypt` 套件加密密碼：`npm install bcrypt jsonwebtoken`
- JWT 驗證 Middleware 範例：
  ```js
  const authenticate = (req, res, next) => {
    const token = req.headers.authorization?.split(' ')[1];
    if (!token) return res.status(401).json({ error: '未提供 token' });
    try {
      req.user = jwt.verify(token, process.env.JWT_SECRET);
      next();
    } catch {
      res.status(401).json({ error: 'token 無效或已過期' });
    }
  };
  ```
- 分頁查詢使用 `LIMIT` 與 `OFFSET`：`OFFSET = (page - 1) * limit`
- 回傳分頁資訊時，也一併回傳 `total`、`page`、`totalPages`
