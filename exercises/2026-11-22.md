# 第 20 週今日練習題：書籍借閱管理系統 API

## 題目說明

建立一個完整的書籍借閱管理系統後端 API，模擬圖書館的核心功能。系統需要管理書籍、會員與借閱紀錄，並支援搜尋、分頁、身份驗證與統計功能。

## 技術要求

- **Express.js**：RESTful API 設計、路由分層、中介層（auth、validation、error handling）
- **PostgreSQL**：多資料表關聯、JOIN 查詢、交易處理（Transaction）、聚合函式

## 資料庫結構

```sql
-- 書籍資料表
CREATE TABLE books (
  id SERIAL PRIMARY KEY,
  isbn VARCHAR(13) UNIQUE NOT NULL,
  title VARCHAR(255) NOT NULL,
  author VARCHAR(255) NOT NULL,
  category VARCHAR(100),
  total_copies INT NOT NULL DEFAULT 1,
  available_copies INT NOT NULL DEFAULT 1,
  created_at TIMESTAMP DEFAULT NOW()
);

-- 會員資料表
CREATE TABLE members (
  id SERIAL PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(255) UNIQUE NOT NULL,
  password_hash VARCHAR(255) NOT NULL,
  membership_type VARCHAR(20) DEFAULT 'standard', -- standard / premium
  borrow_limit INT DEFAULT 3,
  created_at TIMESTAMP DEFAULT NOW()
);

-- 借閱紀錄資料表
CREATE TABLE borrowings (
  id SERIAL PRIMARY KEY,
  book_id INT REFERENCES books(id),
  member_id INT REFERENCES members(id),
  borrowed_at TIMESTAMP DEFAULT NOW(),
  due_date TIMESTAMP NOT NULL,
  returned_at TIMESTAMP,
  status VARCHAR(20) DEFAULT 'active' -- active / returned / overdue
);
```

## 具體任務

1. **會員系統**
   - `POST /api/auth/register` — 註冊新會員（密碼需 bcrypt 雜湊）
   - `POST /api/auth/login` — 登入，回傳 JWT token
   - `GET /api/members/me` — 取得目前登入會員資料（需 JWT 驗證）

2. **書籍管理**
   - `GET /api/books` — 取得書籍列表，支援以下參數：
     - `?search=關鍵字`（搜尋書名或作者）
     - `?category=分類`
     - `?page=1&limit=10`（分頁）
   - `GET /api/books/:id` — 取得單本書籍詳細資訊
   - `POST /api/books` — 新增書籍（需 JWT 驗證）
   - `PUT /api/books/:id` — 更新書籍資訊（需 JWT 驗證）

3. **借閱功能**
   - `POST /api/borrowings` — 借書（需 JWT 驗證）
     - 驗證：書籍是否有庫存、會員是否超過借閱上限
     - 使用 **Transaction** 同時更新 `borrowings` 與 `books.available_copies`
     - `due_date` 預設為 14 天後
   - `PUT /api/borrowings/:id/return` — 還書（需 JWT 驗證）
     - 使用 **Transaction** 更新還書時間與庫存
   - `GET /api/members/me/borrowings` — 查看個人借閱紀錄（含書籍資訊，需 JOIN）

4. **統計資訊**
   - `GET /api/stats` — 回傳以下統計資料：
     - 書籍總數、可借閱書籍總數
     - 目前借出中的數量、逾期未還數量
     - 借閱次數前 5 名的書籍（需 GROUP BY + ORDER BY）

## 提示

- 使用 `express-validator` 或自訂 middleware 進行請求資料驗證
- JWT 驗證邏輯抽取為共用 `authMiddleware`，掛載於需要保護的路由
- Transaction 範例：
  ```js
  const client = await pool.connect();
  try {
    await client.query('BEGIN');
    // ... 多個查詢 ...
    await client.query('COMMIT');
  } catch (err) {
    await client.query('ROLLBACK');
    throw err;
  } finally {
    client.release();
  }
  ```
- 借書時可用 `SELECT ... FOR UPDATE` 鎖定資料列，防止並發問題
- 統計查詢的逾期判斷：`status = 'active' AND due_date < NOW()`

## 進階挑戰（選做）

- **自動更新逾期狀態**：使用排程（如 `node-cron`）每天自動將逾期借閱的 status 更新為 `overdue`
- **Email 通知**：借書成功與即將到期（3 天前）發送提醒 email
- **Premium 會員**：`membership_type = 'premium'` 的會員借閱上限提高為 10 本，且還書期限為 30 天
- **API 文件**：使用 `swagger-jsdoc` + `swagger-ui-express` 生成 API 文件
- **整合測試**：用 `supertest` + `Jest` 撰寫涵蓋借書、還書流程的 E2E 測試
