# 第 20 週今日練習題：書籍借閱管理 REST API

## 題目說明

設計並實作一套「圖書館書籍借閱管理系統」的後端 REST API。系統需支援書籍的維護、會員管理、借閱記錄的建立與歸還，並包含查詢統計功能。這是一個整合性的實戰專案，涵蓋前幾週所有核心技術。

---

## 技術要求

- **Express.js**：RESTful 路由設計、中介軟體（驗證、錯誤處理）、路由模組化
- **PostgreSQL**：多資料表關聯（JOIN）、交易處理（Transaction）、分頁查詢

---

## 資料庫 Schema

請先建立以下三張資料表：

```sql
CREATE TABLE members (
  id        SERIAL PRIMARY KEY,
  name      VARCHAR(100) NOT NULL,
  email     VARCHAR(150) UNIQUE NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE books (
  id          SERIAL PRIMARY KEY,
  title       VARCHAR(200) NOT NULL,
  author      VARCHAR(100) NOT NULL,
  total_copies INT NOT NULL DEFAULT 1,
  created_at  TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE loans (
  id          SERIAL PRIMARY KEY,
  member_id   INT REFERENCES members(id),
  book_id     INT REFERENCES books(id),
  loaned_at   TIMESTAMPTZ DEFAULT NOW(),
  returned_at TIMESTAMPTZ
);
```

## 具體任務

### 1. 建立 Express 應用骨架
- 使用 `express`、`pg`（node-postgres）
- 建立 `routes/` 資料夾，分別存放 `members.js`、`books.js`、`loans.js`
- 在 `app.js` 中掛載路由：`/api/members`、`/api/books`、`/api/loans`

### 2. 會員 CRUD（`/api/members`）
| 方法   | 路徑         | 說明       |
|--------|--------------|------------|
| GET    | `/`          | 列出所有會員（支援 `?page=` 與 `?limit=` 分頁） |
| GET    | `/:id`       | 取得單一會員 |
| POST   | `/`          | 新增會員    |
| PUT    | `/:id`       | 更新會員資料 |
| DELETE | `/:id`       | 刪除會員    |

### 3. 書籍 CRUD（`/api/books`）
| 方法   | 路徑         | 說明       |
|--------|--------------|------------|
| GET    | `/`          | 列出書籍，支援 `?search=` 關鍵字（title 或 author）及分頁 |
| GET    | `/:id`       | 取得書籍詳情，含目前可借數量（`total_copies - 未歸還借閱數`） |
| POST   | `/`          | 新增書籍    |
| PUT    | `/:id`       | 更新書籍資料 |
| DELETE | `/:id`       | 刪除書籍（若有未歸還借閱則回傳 400）|

### 4. 借閱功能（`/api/loans`）
| 方法   | 路徑              | 說明                                       |
|--------|-------------------|--------------------------------------------|
| POST   | `/`               | 借閱書籍（需驗證書籍有可借數量，使用 Transaction）|
| PUT    | `/:id/return`     | 歸還書籍（設定 `returned_at` 為當下時間）  |
| GET    | `/`               | 查詢所有借閱紀錄（JOIN member、book 名稱，支援分頁）|
| GET    | `/member/:memberId` | 查詢特定會員的借閱歷史                   |

### 5. 統計端點（`/api/stats`）
- `GET /api/stats/top-books?limit=5`：回傳借閱次數最多的 N 本書
- `GET /api/stats/active-members?limit=5`：回傳借閱次數最多的 N 位會員

### 6. 錯誤處理中介軟體
- 資源不存在 → HTTP 404，`{ error: "Not found" }`
- 驗證失敗（缺欄位、書籍無存貨）→ HTTP 400，`{ error: "..." }`
- 伺服器錯誤 → HTTP 500，`{ error: "Internal server error" }`

## 提示

- 借閱時的「確認可借數量 → 建立 loan 紀錄」兩步驟要放在同一個 Transaction 中，避免並發問題。
- 分頁查詢可用 `LIMIT $1 OFFSET $2`，offset = (page - 1) * limit。
- 使用 `pool.query()` 進行一般查詢；需要 Transaction 時用 `pool.connect()` 取得 client，手動 `BEGIN` / `COMMIT` / `ROLLBACK`。
- 可在每個路由檔最上方 `require('../db')` 引入共用的 pg Pool 實例。
- `GET /api/books/:id` 的可借數量可用子查詢：
  ```sql
  SELECT b.*,
    b.total_copies - COUNT(l.id) FILTER (WHERE l.returned_at IS NULL) AS available_copies
  FROM books b
  LEFT JOIN loans l ON l.book_id = b.id
  WHERE b.id = $1
  GROUP BY b.id;
  ```

4. **Docker Compose**：撰寫 `docker-compose.yml`，一鍵啟動 PostgreSQL + Node.js 服務。
