# 第 13 週今日練習題：部落格平台 REST API 實戰專案

## 題目說明

綜合前 12 週所學，從零開始建構一個完整的「多使用者部落格平台」REST API。  
系統支援使用者註冊登入、文章發布與管理、分類標籤、留言系統、圖片封面上傳、分頁搜尋，以及完整的自動化測試覆蓋。

---

## 技術要求

- **Express.js**：模組化路由、多層 Middleware 組合、統一錯誤格式
- **PostgreSQL**：多資料表 JOIN 查詢、全文搜尋（`tsvector`）、交易處理
- **JWT**：存取令牌（15 分鐘）+ 刷新令牌（7 天）雙令牌機制
- **Multer**：文章封面圖片上傳（限 JPEG / PNG，最大 3MB）
- **Jest + Supertest**：端對端 API 測試，覆蓋率 ≥ 80%
- **資料驗證**：`zod` 或 `joi` Schema 驗證

## 資料庫結構

```sql
-- 使用者
CREATE TABLE users (
  id           SERIAL PRIMARY KEY,
  username     VARCHAR(50)  UNIQUE NOT NULL,
  email        VARCHAR(255) UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,
  bio          TEXT,
  avatar_url   TEXT,
  created_at   TIMESTAMPTZ DEFAULT NOW()
);

-- 分類
CREATE TABLE categories (
  id   SERIAL PRIMARY KEY,
  name VARCHAR(100) UNIQUE NOT NULL,
  slug VARCHAR(100) UNIQUE NOT NULL
);

-- 文章
CREATE TABLE posts (
  id           SERIAL PRIMARY KEY,
  author_id    INT REFERENCES users(id) ON DELETE CASCADE,
  category_id  INT REFERENCES categories(id) ON DELETE SET NULL,
  title        VARCHAR(255) NOT NULL,
  slug         VARCHAR(255) UNIQUE NOT NULL,
  content      TEXT NOT NULL,
  cover_url    TEXT,
  status       VARCHAR(20) DEFAULT 'draft'
                CHECK (status IN ('draft', 'published', 'archived')),
  search_vector TSVECTOR,
  published_at TIMESTAMPTZ,
  created_at   TIMESTAMPTZ DEFAULT NOW(),
  updated_at   TIMESTAMPTZ DEFAULT NOW()
);

-- 全文搜尋觸發器
CREATE INDEX posts_search_idx ON posts USING GIN(search_vector);

CREATE OR REPLACE FUNCTION update_post_search()
RETURNS TRIGGER AS $$
BEGIN
  NEW.search_vector := to_tsvector('english', NEW.title || ' ' || COALESCE(NEW.content, ''));
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER post_search_update
BEFORE INSERT OR UPDATE ON posts
FOR EACH ROW EXECUTE FUNCTION update_post_search();

-- 標籤
CREATE TABLE tags (
  id   SERIAL PRIMARY KEY,
  name VARCHAR(100) UNIQUE NOT NULL
);

-- 文章 ↔ 標籤（多對多）
CREATE TABLE post_tags (
  post_id INT REFERENCES posts(id) ON DELETE CASCADE,
  tag_id  INT REFERENCES tags(id)  ON DELETE CASCADE,
  PRIMARY KEY (post_id, tag_id)
);

-- 留言
CREATE TABLE comments (
  id         SERIAL PRIMARY KEY,
  post_id    INT REFERENCES posts(id)  ON DELETE CASCADE,
  author_id  INT REFERENCES users(id)  ON DELETE CASCADE,
  parent_id  INT REFERENCES comments(id) ON DELETE CASCADE,
  content    TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 刷新令牌
CREATE TABLE refresh_tokens (
  id         SERIAL PRIMARY KEY,
  user_id    INT REFERENCES users(id) ON DELETE CASCADE,
  token      TEXT UNIQUE NOT NULL,
  expires_at TIMESTAMPTZ NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

## 具體任務

### 1. 專案初始化
- `npm init`，安裝所需套件：
  ```
  express pg bcryptjs jsonwebtoken multer zod jest supertest dotenv slugify
  ```
- 建立 `.env`（`DATABASE_URL`、`JWT_SECRET`、`JWT_REFRESH_SECRET`、`PORT`）
- 建立 `db/init.sql` 並執行資料庫初始化

### 2. 使用者模組（`/api/auth`）
1. `POST /api/auth/register` — 驗證 username（3–30 字）、email 格式、密碼強度（≥8 字含數字）
2. `POST /api/auth/login` — 比對密碼，回傳 `accessToken`（15 分鐘）+ `refreshToken`（7 天，存入 DB）
3. `POST /api/auth/refresh` — 以 refreshToken 換發新 accessToken（驗證 DB 紀錄未過期）
4. `POST /api/auth/logout` — 將 refreshToken 從 DB 刪除（使其失效）

### 3. 認證 Middleware
- 解析 `Authorization: Bearer <token>`，驗證 JWT，注入 `req.user`
- 選擇性認證 Middleware（`optionalAuth`）：有 token 就解析，無 token 不阻擋

### 4. 文章模組（`/api/posts`）
1. `GET /api/posts` — 公開列表，支援：
   - 分頁（`?page=1&limit=10`）
   - 依分類篩選（`?category=tech`）
   - 依標籤篩選（`?tag=javascript`）
   - 全文搜尋（`?q=關鍵字`，使用 PostgreSQL `tsvector`）
   - 排序（`?sort=published_at&order=desc`）
   - 僅回傳 `status=published` 的文章
2. `POST /api/posts`（需認證）— 建立文章（草稿），slug 由 title 自動生成（確保唯一），同一 Transaction 內附加標籤
3. `GET /api/posts/:slug` — 取得文章詳情（含作者資訊、分類、標籤陣列、留言數）
4. `PATCH /api/posts/:slug`（需認證，限作者）— 更新文章，`status` 改為 `published` 時自動設定 `published_at`
5. `DELETE /api/posts/:slug`（需認證，限作者）— 刪除文章
6. `POST /api/posts/:slug/cover`（需認證，限作者）— 上傳封面圖片（JPEG / PNG，≤ 3MB）

### 5. 分類模組（`/api/categories`）
1. `GET /api/categories` — 列出所有分類（附帶各分類已發布文章數）
2. `POST /api/categories`（需認證）— 建立分類，slug 自動生成
3. `DELETE /api/categories/:id`（需認證）— 刪除分類（關聯文章設為 NULL）

### 6. 標籤模組（`/api/tags`）
1. `GET /api/tags` — 列出所有標籤（附帶使用次數，依次數降序）
2. `POST /api/tags`（需認證）— 建立標籤（同名重複回傳 `409`）

### 7. 留言模組（`/api/posts/:slug/comments`）
1. `GET` — 取得文章留言（支援巢狀：頂層留言 + 子回覆）
2. `POST`（需認證）— 新增留言，`parent_id` 可選（回覆某留言）
3. `DELETE /:commentId`（需認證，限留言作者或文章作者）— 刪除留言（連帶刪除子回覆）

### 8. 使用者個人資料（`/api/users`）
1. `GET /api/users/:username` — 取得使用者公開資料（含已發布文章列表）
2. `PATCH /api/users/me`（需認證）— 更新 bio

### 9. 統一錯誤處理 Middleware
- 捕捉所有未處理錯誤，回傳統一格式：
  ```json
  {
    "error": "人類可讀訊息",
    "code": "ERROR_CODE",
    "details": {}
  }
  ```
- 針對 `zod` 驗證錯誤自動格式化為欄位層級錯誤

### 10. 測試套件（Jest + Supertest）
在 `tests/` 目錄撰寫至少下列測試案例：
- 完整 Auth 流程：register → login → refresh → logout
- 建立文章並附加標籤（驗證 JOIN 結果）
- 全文搜尋（驗證 `?q=` 參數正確觸發 `tsvector` 查詢）
- 分頁查詢（驗證 `total` / `page` / `data` / `totalPages` 欄位）
- 上傳超過大小限制的封面圖片回傳 `400`
- 非作者嘗試更新 / 刪除文章回傳 `403`
- 刷新過期 Token 回傳 `401`

## 提示

- `slugify` 套件可快速將中英文標題轉為 URL 友好的 slug，記得加 `{ lower: true }` 選項
- `tsvector` 全文搜尋查詢：`WHERE search_vector @@ plainto_tsquery('english', $1)`
- 雙令牌機制中，accessToken 存在記憶體（或 httpOnly cookie），refreshToken 存入 DB 才能主動撤銷
- 巢狀留言可用遞迴 CTE 或應用層組裝；資料量小時應用層組裝即可
- `pool.connect()` 搭配 `BEGIN / COMMIT / ROLLBACK` 確保文章建立與標籤綁定的原子性

## 進階挑戰（選做）

1. **文章按讚**：新增 `post_likes` 資料表，`POST /api/posts/:slug/like` 切換按讚狀態（使用 `ON CONFLICT DO UPDATE`）
2. **閱讀統計**：每次 `GET /api/posts/:slug` 時以非阻塞方式更新 `views` 計數（`UPDATE ... SET views = views + 1`，不影響回應時間）
3. **草稿預覽連結**：為草稿文章產生短期有效的 signed URL（JWT 簽名，有效期 1 小時），讓作者可分享預覽
4. **Rate Limiting**：對 `/api/auth` 路由加入每 IP 每 15 分鐘最多 10 次請求限制（可使用 `express-rate-limit`）
5. **Swagger 文件**：使用 `swagger-jsdoc` + `swagger-ui-express` 自動產生 OpenAPI 3.0 文件
