# 第 8 週今日練習題：檔案上傳與管理 API

## 題目說明

建立一個支援檔案上傳的 RESTful API，使用者可以上傳圖片或文件，系統會將檔案儲存至指定目錄，並將上傳紀錄寫入 PostgreSQL 資料庫，同時提供查詢與刪除上傳檔案的功能。

## 技術要求

- **Express.js**：建立上傳、查詢、刪除路由；使用 multer middleware 處理 multipart/form-data 請求
- **PostgreSQL**：建立 `uploads` 資料表儲存檔案元資料（原始檔名、儲存路徑、大小、MIME 類型、上傳時間）
- **multer**：設定儲存引擎（diskStorage）、限制檔案大小（最大 5MB）、過濾允許的檔案類型

## 具體任務

1. **建立資料庫資料表**
   ```sql
   CREATE TABLE uploads (
     id SERIAL PRIMARY KEY,
     original_name VARCHAR(255) NOT NULL,
     stored_name   VARCHAR(255) NOT NULL,
     mime_type     VARCHAR(100) NOT NULL,
     size_bytes    INTEGER NOT NULL,
     upload_path   TEXT NOT NULL,
     created_at    TIMESTAMP DEFAULT NOW()
   );
   ```

2. **設定 multer 儲存引擎**
   - 上傳目錄：`uploads/` 資料夾（若不存在請自動建立）
   - 儲存檔名：以 `Date.now() + '-' + 原始檔名` 避免重名
   - 允許類型：`image/jpeg`、`image/png`、`image/gif`、`application/pdf`
   - 單次上傳大小限制：5 MB

3. **實作路由**
   - `POST /upload`：上傳單一檔案，成功後將元資料寫入 DB，回傳 JSON（id、檔名、大小、上傳時間）
   - `GET /uploads`：列出所有上傳紀錄（從 DB 查詢），支援 `?mime=image/png` 篩選類型
   - `GET /uploads/:id/file`：依 id 從 DB 查到路徑後，以 `res.sendFile` 回傳實際檔案
   - `DELETE /uploads/:id`：從 DB 刪除紀錄，並使用 `fs.unlink` 刪除實體檔案

4. **錯誤處理**
   - 檔案類型不符時回傳 `400 { error: "不支援的檔案類型" }`
   - 超過大小限制時回傳 `413 { error: "檔案超過 5MB 限制" }`
   - 查無 id 時回傳 `404 { error: "找不到該檔案紀錄" }`

5. **測試**
   使用 `curl` 或 Postman 測試所有路由是否正常運作：
   ```bash
   curl -X POST http://localhost:3000/upload \
     -F "file=@/path/to/test.png"
   ```

## 提示

- `multer.diskStorage` 的 `destination` callback 可用 `fs.mkdirSync` 確保目錄存在
- `fileFilter` 函式中，呼叫 `cb(new Error('...'), false)` 可拒絕檔案並傳遞錯誤給 multer
- multer 的錯誤（`MulterError`）與一般錯誤需在 Express 錯誤處理 middleware 中分別判斷：
  ```js
  if (err instanceof multer.MulterError) { ... }
  ```
- `res.sendFile` 需傳入絕對路徑，可用 `path.resolve(upload_path)` 轉換
- 刪除檔案前先確認紀錄存在，再做 `fs.unlink`，避免 DB 與檔案系統不同步

## 進階挑戰（選做）

- 支援 `POST /upload/multiple`，允許一次上傳最多 5 個檔案（使用 `multer.array('files', 5)`）
- 對圖片上傳後，使用 `sharp` 套件自動產生縮圖（寬度 200px），並將縮圖路徑也存入 DB
- 加入 JWT 驗證（沿用第 7 週成果），限制只有已登入使用者才能上傳與刪除
- 實作上傳進度回報：使用 Server-Sent Events（SSE）將已上傳位元組數即時推送給客戶端
