# 第 15 週今日練習題：個人書籤收藏 REST API（實戰專案）

## 題目說明

建立一套「個人書籤收藏系統」REST API，讓使用者可以儲存、分類、搜尋網路書籤。
整合 Express.js、PostgreSQL，並透過 JWT 保護所有私人資料。
本題著重於**資料關聯設計**、**全文搜尋**與**批次操作**，是對前 14 週技術的綜合應用。

---

## 技術要求

- **Express.js**：Router 模組化、自訂 Middleware、統一錯誤處理
- **PostgreSQL**：多資料表（users / bookmarks / collections / bookmark_collections）、JOIN、全文搜尋（`tsvector`）
- **JWT**：登入後核發 Token，Middleware 保護受限路由
- **Transaction**：批次新增書籤與分類同步完成或全部回滾
- **分頁 & 排序**：支援 `?page=`、`?limit=`、`?sort=`、`?order=`
- **資料驗證**：URL 格式、必填欄位、長度限制

## 具體任務

### 1. 資料庫設計

建立四張資料表：

```sql
CREATE TABLE users (
  id         SERIAL PRIMARY KEY,
  email      VARCHAR(255) UNIQUE NOT NULL,
  password   VARCHAR(255) NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE bookmarks (
  id          SERIAL PRIMARY KEY,
  user_id     INTEGER REFERENCES users(id) ON DELETE CASCADE,
  url         TEXT NOT NULL,
  title       VARCHAR(255) NOT NULL,
  description TEXT,
  is_public   BOOLEAN DEFAULT FALSE,
  search_vec  TSVECTOR,
  created_at  TIMESTAMPTZ DEFAULT NOW()
);

-- 自動更新 search_vec（需加觸發器）
CREATE INDEX bookmarks_search_idx ON bookmarks USING GIN(search_vec);

CREATE TABLE collections (
  id         SERIAL PRIMARY KEY,
  user_id    INTEGER REFERENCES users(id) ON DELETE CASCADE,
  name       VARCHAR(100) NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE bookmark_collections (
  bookmark_id  INTEGER REFERENCES bookmarks(id) ON DELETE CASCADE,
  collection_id INTEGER REFERENCES collections(id) ON DELETE CASCADE,
  PRIMARY KEY (bookmark_id, collection_id)
);
```

新增 `search_vec` 自動更新觸發器：

```sql
CREATE OR REPLACE FUNCTION update_bookmark_search()
RETURNS TRIGGER AS $$
BEGIN
  NEW.search_vec :=
    to_tsvector('simple', COALESCE(NEW.title, '')) ||
    to_tsvector('simple', COALESCE(NEW.description, ''));
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER bookmark_search_trigger
BEFORE INSERT OR UPDATE ON bookmarks
FOR EACH ROW EXECUTE FUNCTION update_bookmark_search();
```

### 2. 使用者認證

| 方法 | 路由             | 說明                    |
|------|------------------|-------------------------|
| POST | `/auth/register` | 註冊（bcrypt 雜湊密碼） |
| POST | `/auth/login`    | 登入，回傳 JWT          |

### 3. 書籤 CRUD（需 JWT，除公開書籤外）

| 方法   | 路由                    | 說明                               |
|--------|-------------------------|------------------------------------|
| GET    | `/bookmarks`            | 列出自己的書籤（分頁 & 排序）      |
| POST   | `/bookmarks`            | 新增書籤（可同時指定 collection）  |
| GET    | `/bookmarks/:id`        | 取得單一書籤（含所屬分類）         |
| PATCH  | `/bookmarks/:id`        | 更新書籤資料                       |
| DELETE | `/bookmarks/:id`        | 刪除書籤                           |
| GET    | `/bookmarks/public`     | 列出所有公開書籤（**不需** JWT）   |

### 4. 分類（Collection）管理

| 方法   | 路由                                    | 說明                       |
|--------|-----------------------------------------|----------------------------|
| GET    | `/collections`                          | 列出自己所有分類            |
| POST   | `/collections`                          | 建立新分類                  |
| DELETE | `/collections/:id`                      | 刪除分類（不刪除書籤本身）  |
| POST   | `/collections/:id/bookmarks`            | 批次將書籤加入分類          |
| DELETE | `/collections/:id/bookmarks/:bookmarkId`| 移除書籤與分類的關聯        |

### 5. 全文搜尋

```
GET /bookmarks?search=javascript tutorial
```

使用 PostgreSQL `tsvector` 搜尋 title + description：

```sql
SELECT * FROM bookmarks
WHERE user_id = $1
  AND search_vec @@ plainto_tsquery('simple', $2)
ORDER BY ts_rank(search_vec, plainto_tsquery('simple', $2)) DESC;
```

### 6. 批次操作（Transaction）

`POST /collections/:id/bookmarks` 的 request body：

```json
{ "bookmark_ids": [1, 2, 3] }
```

在同一個 Transaction 內：
1. 確認每個 `bookmark_id` 都屬於當前使用者
2. 批次插入 `bookmark_collections`（`ON CONFLICT DO NOTHING`）
3. 任一步驟失敗則整批回滾

### 7. 統一錯誤格式

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "url 格式不正確，必須以 http:// 或 https:// 開頭"
  }
}
```

常見錯誤碼：`VALIDATION_ERROR`、`UNAUTHORIZED`、`NOT_FOUND`、`FORBIDDEN`

## 提示

- URL 驗證可用正規表達式：`/^https?:\/\/.+/` 或 `new URL(url)` 搭配 try/catch
- JWT Middleware 獨立為 `middleware/auth.js`，掛載在需要保護的 Router 上
- 分頁公式：`LIMIT $1 OFFSET ($2 - 1) * $1`（$1 = limit, $2 = page）
- 全文搜尋索引在 INSERT/UPDATE 時由觸發器自動維護，不需手動設定
- `bookmark_collections` 使用複合主鍵，可防止重複關聯
