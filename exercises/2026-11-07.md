# 第 18 週今日練習題：書籍借閱管理系統 API

## 題目說明

實作一個完整的書籍借閱管理系統 REST API。系統需管理會員、書籍與借閱記錄，涵蓋 JWT 身份驗證、資料驗證、分頁查詢、交易處理與錯誤回應等核心技能。

## 技術要求
- **Express.js**：路由設計、自訂 Middleware、錯誤處理、JWT 保護路由
- **PostgreSQL**：多資料表關聯、JOIN 查詢、Transaction、分頁與排序

## 資料庫結構

```sql
-- 會員表
CREATE TABLE members (
  id SERIAL PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(150) UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);

-- 書籍表
CREATE TABLE books (
  id SERIAL PRIMARY KEY,
  title VARCHAR(200) NOT NULL,
  author VARCHAR(100) NOT NULL,
  isbn VARCHAR(13) UNIQUE NOT NULL,
  total_copies INT NOT NULL DEFAULT 1,
  available_copies INT NOT NULL DEFAULT 1
);

-- 借閱記錄表
CREATE TABLE borrowings (
  id SERIAL PRIMARY KEY,
  member_id INT REFERENCES members(id),
  book_id INT REFERENCES books(id),
  borrowed_at TIMESTAMP DEFAULT NOW(),
  due_date TIMESTAMP NOT NULL,
  returned_at TIMESTAMP
);
```

## 具體任務

1. **身份驗證模組**
   - `POST /api/auth/register`：會員註冊（驗證 email 格式、密碼長度 ≥ 8）
   - `POST /api/auth/login`：登入後回傳 JWT（有效期 24 小時）

2. **書籍管理（需 JWT）**
   - `GET /api/books`：列出所有書籍，支援 `?page=1&limit=10&search=關鍵字` 分頁與搜尋
   - `POST /api/books`：新增書籍（驗證 isbn 為 13 碼數字）
   - `GET /api/books/:id`：取得單本書籍詳細資訊

3. **借閱功能（需 JWT，使用 Transaction）**
   - `POST /api/borrowings`：借書
     - 請求 body：`{ book_id, due_date }`
     - 在同一 Transaction 中：確認書籍有存貨 → 建立借閱記錄 → 將 `available_copies - 1`
     - 若無庫存，回傳 `422 Unprocessable Entity`
   - `PATCH /api/borrowings/:id/return`：還書
     - 在同一 Transaction 中：更新 `returned_at` → 將 `available_copies + 1`
   - `GET /api/borrowings/my`：查詢目前登入者的借閱清單（JOIN books 顯示書名）

4. **統計端點（需 JWT）**
   - `GET /api/stats/top-books`：回傳借閱次數前 5 名的書籍（GROUP BY + ORDER BY）

## 提示
- 使用 `bcrypt` 雜湊密碼，`jsonwebtoken` 產生與驗證 JWT
- 自訂 `authMiddleware`：從 `Authorization: Bearer <token>` 取出並驗證 token，將 `req.user` 設為解碼後的 payload
- Transaction 使用 `pg` 的 `client.query('BEGIN')` / `COMMIT` / `ROLLBACK` 模式
- 分頁計算：`LIMIT $1 OFFSET $2`，offset = (page - 1) * limit
- 錯誤處理 Middleware 放在所有路由之後，統一格式：`{ error: "訊息" }`

## 進階挑戰（選做）
- 新增「逾期提醒」端點 `GET /api/borrowings/overdue`，列出所有 `due_date < NOW()` 且 `returned_at IS NULL` 的借閱紀錄（JOIN member 資訊）
- 為 `borrowings` 加上 `penalty_fee` 欄位，還書時若逾期自動計算罰款（每天 NT$5）
- 使用 `supertest` + `Jest` 為借書與還書端點撰寫整合測試
