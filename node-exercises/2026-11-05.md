# 第 18 週今日 Node.js 練習題：WebSocket 即時聊天室

## 題目說明

使用 Node.js 內建 HTTP 模組搭配 `ws` 套件，打造一個支援多人即時訊息的聊天室伺服器。用戶端透過 WebSocket 連線後，可以廣播訊息給所有線上使用者，伺服器也會定期發送「心跳」確認連線狀態。

---

## 技術要求

- **概念：** WebSocket 協定、事件驅動架構、廣播模式、連線管理
- **需要的套件：**
  - `ws` — WebSocket 伺服器實作

---

## 具體任務

1. **初始化專案**
   - `npm init -y` 並安裝 `ws`
   - 建立 `server.js` 作為 WebSocket 伺服器入口

2. **建立 WebSocket 伺服器**
   - 使用 `ws.WebSocketServer` 在 port `3000` 啟動
   - 每個連線時，要求用戶端送出第一則訊息作為 `nickname`（格式：`{"type":"join","nickname":"Alice"}`）

3. **實作訊息廣播**
   - 收到 `{"type":"message","text":"Hello!"}` 時，廣播給**所有已連線且已命名**的用戶端
   - 廣播格式：`{"type":"message","from":"Alice","text":"Hello!","timestamp":"ISO 字串"}`
   - 廣播時排除傳送者自己（其他人才收到）

4. **追蹤線上使用者**
   - 維護一個 `Map`，以 WebSocket 連線物件為 key，`{ nickname, joinedAt }` 為 value
   - 每當有人加入或離開，向所有人廣播目前線上人數：`{"type":"info","online":3}`

5. **心跳機制**
   - 每 30 秒對所有連線送出 `{"type":"ping"}`
   - 若用戶端超過 60 秒未有任何訊息（包含 pong），強制關閉連線

6. **優雅關閉伺服器**
   - 監聽 `SIGINT`（Ctrl+C），關閉前對所有用戶端廣播 `{"type":"info","text":"伺服器即將關閉"}` 再 `terminate()`

## 範例

```js
// server.js 骨架
const { WebSocketServer } = require('ws');
const http = require('http');

const server = http.createServer();
const wss = new WebSocketServer({ server });

const clients = new Map(); // ws => { nickname, lastSeen }

wss.on('connection', (ws) => {
  clients.set(ws, { nickname: null, lastSeen: Date.now() });

  ws.on('message', (raw) => {
    const data = JSON.parse(raw);
    // TODO: 處理 join / message
  });

  ws.on('close', () => {
    clients.delete(ws);
    broadcast({ type: 'info', online: clients.size });
  });
});

function broadcast(payload, exclude = null) {
  const msg = JSON.stringify(payload);
  for (const [ws] of clients) {
    if (ws !== exclude && ws.readyState === ws.OPEN) {
      ws.send(msg);
    }
  }
}

server.listen(3000, () => console.log('WebSocket 伺服器啟動於 ws://localhost:3000'));
```

```js
// 測試用的簡易客戶端（client.js）
const WebSocket = require('ws');
const ws = new WebSocket('ws://localhost:3000');

ws.on('open', () => {
  ws.send(JSON.stringify({ type: 'join', nickname: 'Alice' }));
  setTimeout(() => ws.send(JSON.stringify({ type: 'message', text: '大家好！' })), 1000);
});

ws.on('message', (data) => console.log('收到：', data.toString()));
```

---

## 提示

- `ws.readyState === WebSocket.OPEN` 才能安全呼叫 `ws.send()`
- `JSON.parse` 可能拋出例外，記得用 `try/catch` 包起來
- 心跳計時器用 `setInterval` 配合 `clearInterval` 在伺服器關閉時停止
- Node.js `process.on('SIGINT', handler)` 捕捉 Ctrl+C

## 學習重點（跟後端 API 的關聯）

| 概念 | 對應場景 |
|------|----------|
| WebSocket 持久連線 | 即時功能（聊天、通知、協同編輯）不必輪詢 REST |
| 事件驅動 (`on('message')`) | Node.js 非阻塞 I/O 的核心模式 |
| 廣播 vs 單播 | 與 REST 的請求/回應模型截然不同 |
| 連線狀態管理 | 類似 session 管理，但在記憶體中維護 |
| 心跳偵測 | 生產環境必備，防止殭屍連線佔用資源 |

REST API 和 WebSocket 是互補的：REST 適合資源操作（CRUD），WebSocket 適合低延遲的雙向推送。真實系統常同時使用兩者。

## 進階挑戰（選做）

1. **頻道（Room）支援**：`{"type":"join","nickname":"Bob","room":"general"}` 讓使用者加入特定頻道，訊息只在同頻道廣播
2. **私訊**：`{"type":"dm","to":"Alice","text":"嗨"}` 只傳給指定用戶
3. **歷史訊息**：用陣列儲存最近 50 則訊息，新用戶加入時補發給他
4. **整合 REST API**：用 Express 在同一個 HTTP server 上加掛 `/api/online` 端點，回傳目前線上使用者列表
