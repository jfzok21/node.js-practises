# 第 20 週今日 Node.js 練習題：WebSocket 即時聊天室

## 題目說明

使用 Node.js 內建的 `ws` 套件建立一個即時雙向通訊的聊天室伺服器。用戶端連線後可以廣播訊息給所有在線用戶，伺服器也需要追蹤在線人數並在用戶加入／離開時通知所有人。

## 技術要求
- 概念：WebSocket 協定、事件驅動架構、廣播模式、連線管理
- 需要的套件：`ws`（WebSocket 伺服器）、`uuid`（產生用戶 ID）

## 具體任務

1. **初始化專案**
   - `npm init -y`
   - 安裝 `ws` 與 `uuid` 套件
   - 建立 `server.js` 作為 WebSocket 伺服器

2. **建立 WebSocket 伺服器**
   - 監聽 port `8080`
   - 每個連線自動分配唯一 ID（使用 `uuid`）
   - 維護一個 `clients` Map：`{ id -> ws }`

3. **實作廣播邏輯**
   - 收到任一用戶的訊息時，廣播給所有連線中的用戶
   - 訊息格式（JSON）：
     ```json
     { "type": "message", "from": "user-id", "text": "...", "timestamp": "ISO 字串" }
     ```

4. **處理用戶進入／離開事件**
   - 用戶連線時廣播：`{ "type": "join", "id": "...", "online": N }`
   - 用戶斷線時廣播：`{ "type": "leave", "id": "...", "online": N }`

5. **心跳機制（Ping/Pong）**
   - 每 30 秒對所有連線發送 `ping`
   - 若用戶未在 60 秒內回應 `pong`，則強制斷線並清理 Map

6. **簡易 HTTP 健康檢查**
   - 在同一個 port 上（使用 `http` 模組）加掛 `GET /health`
   - 回傳 `{ "status": "ok", "online": N }`

## 範例

```js
// 伺服器啟動輸出
// WebSocket 聊天室伺服器已啟動，監聽 ws://localhost:8080

// 用戶 A 連線
// → 廣播給所有人：{ type: 'join', id: 'uuid-A', online: 1 }

// 用戶 A 傳送訊息 "Hello!"
// → 廣播：{ type: 'message', from: 'uuid-A', text: 'Hello!', timestamp: '2026-11-23T...' }

// 用戶 B 連線
// → 廣播：{ type: 'join', id: 'uuid-B', online: 2 }

// 用戶 A 斷線
// → 廣播：{ type: 'leave', id: 'uuid-A', online: 1 }

// GET /health 回應
// { status: 'ok', online: 1 }
```

## 提示
- `wss.clients` 是內建的 Set，但自己維護 Map 更方便追蹤用戶 ID
- `ws.readyState === WebSocket.OPEN` 才能安全地 `send()`
- `JSON.parse` 時記得用 try/catch，用戶端可能傳非 JSON 訊息
- 心跳機制可用 `setInterval` + 為每個 ws 附加 `isAlive` 屬性

## 學習重點（跟後端 API 的關聯）

WebSocket 是 REST API 的補充：REST 適合「請求—回應」場景，WebSocket 適合需要**伺服器主動推送**的場景（通知、即時資料、協作編輯）。掌握這個模式後，你可以在 Express 應用中同時掛載 REST endpoint 與 WebSocket，實現混合架構。在生產環境中通常搭配 Redis Pub/Sub 讓多個伺服器節點之間可以互相廣播，解決水平擴展問題。

## 進階挑戰（選做）

1. **頻道（Channel）支援**：用戶連線時傳 `{ type: 'join', channel: 'general' }`，廣播只在同頻道內進行
2. **私訊**：支援 `{ type: 'dm', to: 'user-id', text: '...' }` 格式，只傳給指定用戶
3. **訊息歷史**：用陣列在記憶體中保留最後 50 條訊息，新用戶連線時自動推送歷史紀錄
4. **用 `wscat` 或簡易 HTML 前端** 實際測試多個用戶同時連線的效果
