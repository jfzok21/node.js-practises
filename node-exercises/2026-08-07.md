# 第 5 週今日 Node.js 練習題：建立你的第一個 Express 應用程式

## 題目說明

使用 Express.js 建立一個簡單的書籍管理 API 伺服器。Express 是 Node.js 最流行的 Web 框架，能大幅簡化路由設計與請求處理。本題讓你熟悉 Express 的核心概念：路由、請求物件（req）、回應物件（res）、以及簡單的記憶體資料管理。

---

## 技術要求

- **概念**：Express 路由、HTTP 方法（GET / POST / PUT / DELETE）、JSON 回應、狀態碼
- **需要的套件**：
  ```bash
  npm init -y
  npm install express
  ```

---

## 具體任務

1. **初始化專案並安裝 Express**
   - 建立 `book-api/` 資料夾，執行 `npm init -y && npm install express`

2. **建立 `index.js`，設定 Express 應用程式**
   - 監聽 port `3000`
   - 使用 `express.json()` middleware 解析 JSON 請求體

3. **實作書籍 CRUD 路由**（資料存在記憶體陣列中，不需資料庫）：
   - `GET /books` — 回傳所有書籍清單
   - `GET /books/:id` — 回傳單本書（找不到時回傳 404）
   - `POST /books` — 新增一本書（需傳入 `title` 與 `author`）
   - `PUT /books/:id` — 更新書籍資料
   - `DELETE /books/:id` — 刪除書籍

4. **回傳統一 JSON 格式**
   ```json
   { "success": true, "data": ... }
   { "success": false, "message": "..." }
   ```

5. **使用 curl 或 Postman 測試所有端點**

---

## 範例

```js
// index.js
const express = require('express');
const app = express();

app.use(express.json());

let books = [
  { id: 1, title: '深入淺出 Node.js', author: '朴靈' },
  { id: 2, title: 'JavaScript 精粹', author: 'Douglas Crockford' }
];
let nextId = 3;

// GET /books
app.get('/books', (req, res) => {
  res.json({ success: true, data: books });
});

// GET /books/:id
app.get('/books/:id', (req, res) => {
  const book = books.find(b => b.id === parseInt(req.params.id));
  if (!book) return res.status(404).json({ success: false, message: '找不到該書籍' });
  res.json({ success: true, data: book });
});

// POST /books
app.post('/books', (req, res) => {
  const { title, author } = req.body;
  if (!title || !author) {
    return res.status(400).json({ success: false, message: 'title 與 author 為必填欄位' });
  }
  const newBook = { id: nextId++, title, author };
  books.push(newBook);
  res.status(201).json({ success: true, data: newBook });
});

// PUT /books/:id
app.put('/books/:id', (req, res) => {
  const index = books.findIndex(b => b.id === parseInt(req.params.id));
  if (index === -1) return res.status(404).json({ success: false, message: '找不到該書籍' });
  books[index] = { ...books[index], ...req.body };
  res.json({ success: true, data: books[index] });
});

// DELETE /books/:id
app.delete('/books/:id', (req, res) => {
  const index = books.findIndex(b => b.id === parseInt(req.params.id));
  if (index === -1) return res.status(404).json({ success: false, message: '找不到該書籍' });
  const deleted = books.splice(index, 1)[0];
  res.json({ success: true, data: deleted });
});

app.listen(3000, () => console.log('書籍 API 伺服器運行在 http://localhost:3000'));
```

**測試指令：**
```bash
# 取得所有書籍
curl http://localhost:3000/books

# 新增書籍
curl -X POST http://localhost:3000/books \
  -H "Content-Type: application/json" \
  -d '{"title":"Clean Code","author":"Robert C. Martin"}'

# 更新書籍
curl -X PUT http://localhost:3000/books/1 \
  -H "Content-Type: application/json" \
  -d '{"title":"深入淺出 Node.js（修訂版）"}'

# 刪除書籍
curl -X DELETE http://localhost:3000/books/2
```

---

## 提示

- `req.params.id` 取得的是**字串**，記得用 `parseInt()` 轉換後再比對
- `express.json()` 必須放在路由之前，否則 `req.body` 會是 `undefined`
- HTTP 狀態碼語意：`200` 成功、`201` 建立成功、`400` 請求錯誤、`404` 資源不存在
- 用展開運算子 `{ ...books[index], ...req.body }` 做部分更新，避免覆蓋整個物件

---

## 學習重點（跟後端 API 的關聯）

Express 路由對應的是後端 API 的「端點設計」核心。在真實專案中，每個路由通常會：
1. 接收並驗證請求參數
2. 呼叫 Service 層處理業務邏輯
3. 存取資料庫（本週用記憶體模擬）
4. 統一格式回傳 JSON

本週打好的 Express 基礎，後續幾週會加上 Middleware（錯誤處理、身份驗證）、資料庫（PostgreSQL）、以及 JWT 驗證，逐步組建出完整的後端架構。

## 進階挑戰（選做）

1. **查詢參數篩選**：支援 `GET /books?author=Douglas` 依作者篩選書籍
2. **分頁功能**：支援 `GET /books?page=1&limit=5` 分頁回傳
3. **路由模組化**：將書籍路由抽到 `routes/books.js`，用 `app.use('/books', bookRouter)` 掛載
4. **404 兜底路由**：加一個 `app.use('*', ...)` 處理所有未定義路由，回傳友善訊息
