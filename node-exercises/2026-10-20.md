# 第 16 週今日 Node.js 練習題：即時聊天室 API（Socket.IO + Redis Pub/Sub）

## 題目說明

綜合運用前幾週所學，打造一個支援多房間的即時聊天後端系統。使用者透過 JWT 驗證身份後加入聊天室，訊息透過 **Socket.IO** 即時推送；搭配 **Redis Pub/Sub** 實現多進程水平擴展，讓聊天訊息能跨伺服器實例傳遞。

## 技術要求
- 概念：WebSocket、事件驅動架構、Redis Pub/Sub、Socket.IO 命名空間/房間、JWT 中介驗證
- 需要的套件：`express`, `socket.io`, `ioredis`, `jsonwebtoken`, `bcryptjs`, `pg`, `dotenv`, `jest`, `supertest`

## 具體任務

1. **專案初始化**
   - `npm init -y`，安裝上述套件
   - 建立 `.env`（`PORT`、`JWT_SECRET`、`DATABASE_URL`、`REDIS_URL`）
   - 目錄結構：
     ```
     src/
       routes/       # HTTP REST 路由
       socket/       # Socket.IO 事件處理
       middleware/   # JWT 驗證
       db/           # PostgreSQL 連線
     ```

2. **資料庫 Schema**
   - `users` 資料表：`id`（serial PK）、`username`（unique）、`password_hash`、`created_at`
   - `rooms` 資料表：`id`（serial PK）、`name`（unique）、`created_at`
   - `messages` 資料表：`id`（serial PK）、`room_id`（FK → rooms）、`user_id`（FK → users）、`content`（text）、`created_at`

3. **REST API 端點**
   - `POST /api/auth/register`：建立使用者（username、password）
   - `POST /api/auth/login`：驗證後回傳 JWT（有效期 24 小時）
   - `GET /api/rooms`：列出所有聊天室
   - `POST /api/rooms`：建立新聊天室（需 JWT）
   - `GET /api/rooms/:roomId/messages?limit=50`：取得最近 N 筆歷史訊息

4. **Socket.IO 即時功能**
   - 連線時驗證 JWT（從 `socket.handshake.auth.token` 取出）
   - 事件：
     - `join_room`：加入指定房間，廣播「${username} 加入了聊天室」
     - `send_message`：發送訊息，儲存至 PostgreSQL，並 Pub/Sub 廣播至所有進程
     - `leave_room`：離開房間，廣播「${username} 離開了聊天室」
     - `typing`：廣播打字狀態（不儲存 DB），throttle 1 秒

5. **Redis Pub/Sub 廣播**
   - 使用兩個 `ioredis` 實例：一個 publisher、一個 subscriber
   - 當收到 `send_message` 事件時，先存 DB，再 `publisher.publish('chat', JSON.stringify(payload))`
   - Subscriber 訂閱 `chat` 頻道，收到後用 `io.to(roomId).emit('new_message', payload)` 廣播

6. **撰寫 Jest 測試**
   - 測試 `POST /api/auth/register`（成功、username 重複）
   - 測試 `GET /api/rooms/:roomId/messages`（帶 / 不帶 token）

## 範例

```js
// === REST API ===

// POST /api/auth/login
// Body: { "username": "alice", "password": "pass1234" }
// Response 200:
{ "token": "eyJhbGci..." }

// GET /api/rooms/1/messages?limit=10  (Authorization: Bearer <token>)
// Response 200:
[
  { "id": 5, "username": "alice", "content": "大家好！", "created_at": "2026-10-20T10:00:00Z" },
  { "id": 6, "username": "bob",   "content": "哈囉！",   "created_at": "2026-10-20T10:00:05Z" }
]

// === Socket.IO 客戶端範例 ===
const socket = io('http://localhost:3000', {
  auth: { token: 'eyJhbGci...' }
});

socket.emit('join_room', { roomId: 1 });

socket.emit('send_message', { roomId: 1, content: '大家好！' });

socket.on('new_message', (msg) => {
  console.log(`[${msg.username}]: ${msg.content}`);
});

socket.on('user_joined', ({ username }) => {
  console.log(`${username} 加入了聊天室`);
});
```

## 提示
- Socket.IO 的 JWT 驗證可用 middleware：`io.use((socket, next) => { /* verify token */ })`
- `ioredis` 的 subscriber 實例在訂閱模式下不能執行其他指令，需分開兩個 client
- 用 `socket.join(roomId)` 加入 Socket.IO 房間，`io.to(roomId).emit(...)` 廣播至整個房間
- `typing` 事件使用 `socket.to(roomId).emit(...)` 而非 `io.to(...)`，避免回傳給發送者
- 可用 `redis-cli SUBSCRIBE chat` 在終端觀察 Pub/Sub 訊息流

## 學習重點（跟後端 API 的關聯）

| 本週技能 | 實際場景 |
|----------|----------|
| Socket.IO 即時推送 | 線上客服、股票報價、協作編輯 |
| Redis Pub/Sub | 跨伺服器廣播（水平擴展不丟訊息）|
| JWT Socket 驗證 | 確保只有登入用戶能發訊息 |
| 事件驅動架構 | 微服務之間的非同步通訊 |
| 歷史訊息 API | 新加入用戶可補看錯過的訊息 |

## 進階挑戰（選做）

- **已讀回執**：在 `messages` 加入 `read_by`（jsonb 陣列），`socket.emit('read', { messageId })` 更新並廣播
- **私訊（DM）**：用 `socket.to(recipientSocketId).emit(...)` 實現一對一訊息
- **訊息搜尋**：`GET /api/rooms/:id/messages?q=關鍵字` 用 PostgreSQL `ILIKE` 做全文搜尋
- **連線狀態追蹤**：用 Redis Hash 記錄在線用戶（`HSET online_users userId socketId`），`GET /api/rooms/:id/online` 列出在線人數
- **Docker Compose**：建立 `docker-compose.yml`，一鍵啟動 Node.js + PostgreSQL + Redis 三個服務
