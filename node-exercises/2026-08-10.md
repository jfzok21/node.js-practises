# 第 5 週今日 Node.js 練習題：用 Express 建立你的第一個 Web 伺服器

## 題目說明

本週開始學習 Express.js——Node.js 最流行的 Web 框架。你將建立一個具備多條路由的 Express 伺服器，體驗 Express 如何讓 HTTP 路由變得更簡潔易讀，並理解 `res.json()`、`res.send()`、路由參數（route params）等核心概念。

---

## 技術要求

- **概念**：Express 安裝與初始化、路由定義（GET）、路由參數（`:id`）、Query String、JSON 回應
- **需要的套件**：
  - `express`（`npm install express`）

---

## 具體任務

1. **初始化專案**
   - 在 `week5/` 目錄下執行 `npm init -y`，並安裝 `express`。

2. **建立 `app.js`**，包含以下路由：

   | 路由 | 說明 |
   |------|------|
   | `GET /` | 回傳 `{ message: "Welcome to my Express server!" }` |
   | `GET /hello` | 接受 query string `?name=xxx`，回傳 `{ message: "Hello, xxx!" }`；若未傳入 name 則回傳 `"Hello, stranger!"` |
   | `GET /users` | 回傳一組假的使用者陣列（至少 3 筆，包含 id、name、email） |
   | `GET /users/:id` | 根據路由參數 `:id` 找到對應使用者，找不到時回傳 404 與錯誤訊息 |
   | `GET /status` | 回傳伺服器狀態，包含 `{ uptime, timestamp, status: "ok" }` |

3. **讓伺服器監聽 port 3000**，並在 console 印出啟動訊息。

4. （進階）為所有路由加上一個簡單的 **logging middleware**，在每次請求時印出 `[時間] METHOD /路徑`。

---

## 範例

```js
// app.js 骨架
const express = require('express');
const app = express();
const PORT = 3000;

// 靜態假資料
const users = [
  { id: 1, name: 'Alice', email: 'alice@example.com' },
  { id: 2, name: 'Bob',   email: 'bob@example.com' },
  { id: 3, name: 'Carol', email: 'carol@example.com' },
];

// GET /
app.get('/', (req, res) => {
  res.json({ message: 'Welcome to my Express server!' });
});

// GET /hello?name=xxx
app.get('/hello', (req, res) => {
  const name = req.query.name || 'stranger';
  res.json({ message: `Hello, ${name}!` });
});

// GET /users
app.get('/users', (req, res) => {
  res.json(users);
});

// GET /users/:id
app.get('/users/:id', (req, res) => {
  const user = users.find(u => u.id === Number(req.params.id));
  if (!user) {
    return res.status(404).json({ error: 'User not found' });
  }
  res.json(user);
});

// GET /status
app.get('/status', (req, res) => {
  res.json({
    status: 'ok',
    uptime: process.uptime(),
    timestamp: new Date().toISOString(),
  });
});

app.listen(PORT, () => {
  console.log(`Server running at http://localhost:${PORT}`);
});
```

**測試指令（在另一個終端機執行）：**
```bash
curl http://localhost:3000/
curl "http://localhost:3000/hello?name=David"
curl http://localhost:3000/users
curl http://localhost:3000/users/2
curl http://localhost:3000/users/99   # 應回傳 404
curl http://localhost:3000/status
```

## 提示

- 用 `npm install express` 安裝套件，`require('express')` 引入。
- `req.params.id` 是**字串**，要用 `Number()` 或 `parseInt()` 轉型後再比較。
- `req.query` 是一個物件，包含所有 query string 參數。
- 路由順序很重要：Express 由上而下匹配，先匹配到的先執行。
- 可以用 `nodemon app.js` 讓伺服器在檔案修改後自動重啟（`npm install -g nodemon`）。

## 學習重點（跟後端 API 的關聯）

Express 是業界最常見的 Node.js API 框架，幾乎所有 REST API 專案都會直接或間接使用它。本週練習的每一個路由模式，都直接對應真實 API 的常見場景：

- **`GET /users`** → 列表查詢，對應 `SELECT * FROM users`
- **`GET /users/:id`** → 單筆查詢，對應 `SELECT * FROM users WHERE id = ?`
- **Query string** → 過濾條件，後續可擴展成搜尋、分頁參數
- **404 回應** → 標準錯誤處理模式，之後會抽成 middleware

理解這些路由結構是下週學習 Express Middleware 的基礎。

## 進階挑戰（選做）

1. **Logging Middleware**：在所有路由之前加上 middleware，記錄每次請求的時間、HTTP method 與路徑：
   ```js
   app.use((req, res, next) => {
     console.log(`[${new Date().toISOString()}] ${req.method} ${req.path}`);
     next();
   });
   ```

2. **支援查詢過濾**：讓 `GET /users?name=xxx` 能依名稱模糊搜尋，回傳符合的使用者清單。

3. **加上 `POST /users`**：先用 `app.use(express.json())` 解析請求 body，再把新使用者 push 進陣列並回傳。
