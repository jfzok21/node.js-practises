# 第 4 週今日 Node.js 練習題：使用內建 HTTP 模組建立簡易 REST API

## 題目說明

不使用任何外部框架，純粹利用 Node.js 內建的 `http` 模組，建立一個可以處理不同路由和 HTTP 方法的基礎 API 伺服器。這是理解 Express.js 等框架底層運作的關鍵練習。

## 技術要求

- 概念：HTTP 模組、路由解析、請求方法判斷、回應狀態碼、JSON 資料傳輸、body 解析
- 需要的套件：無（僅使用 Node.js 內建模組：`http`、`url`）

## 具體任務

1. 使用 `http.createServer()` 建立 HTTP 伺服器，監聽 port `3000`
2. 解析請求的 URL 路徑（`req.url`）和方法（`req.method`）來實作路由分派
3. 在記憶體中建立一個「待辦清單」陣列（`todos`），每筆資料包含 `id`、`title`、`done` 三個欄位
4. 實作以下路由：
   - `GET /todos`：以 JSON 格式回傳所有待辦事項（狀態碼 200）
   - `GET /todos/:id`：回傳指定 ID 的待辦事項（找不到時回傳 404）
   - `POST /todos`：從請求 body 讀取 JSON，新增一筆待辦事項（狀態碼 201）
   - `DELETE /todos/:id`：刪除指定 ID 的待辦事項（成功 200，找不到 404）
5. 所有回應都必須設定 `Content-Type: application/json` header
6. 未知路由回傳 `404`，並附上 `{"error": "路由不存在"}` 的 JSON 訊息

## 範例

```js
// server.js 骨架

const http = require('http');

let todos = [
  { id: 1, title: '學習 Node.js', done: false }
];
let nextId = 2;

function readBody(req) {
  return new Promise((resolve) => {
    let body = '';
    req.on('data', chunk => { body += chunk; });
    req.on('end', () => resolve(body ? JSON.parse(body) : {}));
  });
}

const server = http.createServer(async (req, res) => {
  const { method, url } = req;
  const parts = url.split('/').filter(Boolean); // ['todos'] 或 ['todos', '1']

  res.setHeader('Content-Type', 'application/json');

  if (parts[0] === 'todos') {
    const id = parts[1] ? parseInt(parts[1]) : null;

    if (method === 'GET' && !id) {
      // 回傳所有待辦事項
      res.writeHead(200);
      res.end(JSON.stringify(todos));

    } else if (method === 'GET' && id) {
      // TODO: 回傳單筆

    } else if (method === 'POST') {
      // TODO: 新增待辦事項

    } else if (method === 'DELETE' && id) {
      // TODO: 刪除待辦事項

    }
  } else {
    res.writeHead(404);
    res.end(JSON.stringify({ error: '路由不存在' }));
  }
});

server.listen(3000, () => console.log('伺服器已啟動：http://localhost:3000'));
```

## 提示

- 讀取 POST body 需要監聽 `req` 的 `data` 和 `end` 事件來收集資料片段，因為資料可能分批送達
- `req.on('data', chunk => body += chunk)` + `req.on('end', ...)` 是標準的 body 讀取模式
- `res.writeHead(statusCode, { 'Content-Type': 'application/json' })` 可同時設定狀態碼和 header
- `Array.findIndex()` 搭配 splice 可以刪除特定元素
- 記得處理 `JSON.parse()` 可能拋出例外的情況（`try/catch`）
