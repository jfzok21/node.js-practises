# 第 18 週今日 Node.js 練習題：即時聊天室 API（WebSocket + Express）

## 題目說明

建立一個支援即時通訊的聊天室後端服務，整合 Express REST API 與 WebSocket（ws 套件）。使用者可以透過 HTTP 加入聊天室，並透過 WebSocket 收發即時訊息。訊息記錄存在記憶體或 JSON 檔案中。

## 技術要求
- **概念**：WebSocket 雙向通訊、事件驅動、廣播機制、REST + WS 混合架構
- **需要的套件**：`express`、`ws`、`uuid`（選用）

## 具體任務

1. **建立 Express 伺服器並掛載 WebSocket Server**
   - 使用 `http.createServer(app)` 建立 HTTP server
   - 以同一個 server 物件建立 `new WebSocket.Server({ server })`
   - 監聽 `connection` 事件，為每個用戶端指派唯一 `clientId`

2. **實作房間管理 REST API**
   ```
   POST /rooms          → 建立聊天室（需帶 { name } body）
   GET  /rooms          → 列出所有聊天室
   GET  /rooms/:id/messages → 取得該房間的歷史訊息（最新 50 筆）
   ```

3. **實作 WebSocket 訊息協定**
   客戶端連線後傳送 JSON 指令：
   ```json
   { "type": "join",    "roomId": "abc123", "username": "Alice" }
   { "type": "message", "roomId": "abc123", "text": "Hello!" }
   { "type": "leave",   "roomId": "abc123" }
   ```
   伺服器廣播給同房間所有成員：
   ```json
   { "type": "message", "from": "Alice", "text": "Hello!", "timestamp": "..." }
   { "type": "system",  "text": "Alice 已加入" }
   ```

4. **處理斷線清理**
   - 監聽 WebSocket `close` 事件，將用戶從所有房間移除並廣播離開訊息

5. **錯誤處理**
   - 收到非 JSON 訊息時回傳 `{ type: "error", message: "Invalid JSON" }`
   - 加入不存在的房間時回傳 `{ type: "error", message: "Room not found" }`

## 範例

```js
// server.js 骨架
const express = require('express');
const http = require('http');
const WebSocket = require('ws');

const app = express();
app.use(express.json());

const server = http.createServer(app);
const wss = new WebSocket.Server({ server });

const rooms = {};   // { [roomId]: { name, messages: [] } }
const clients = {}; // { [clientId]: { ws, username, roomId } }

wss.on('connection', (ws) => {
  const clientId = Date.now().toString();
  clients[clientId] = { ws, username: null, roomId: null };

  ws.on('message', (raw) => {
    // 解析並路由 type: join / message / leave
  });

  ws.on('close', () => {
    // 清理 clients[clientId]，廣播離開
  });
});

// REST API
app.post('/rooms', (req, res) => { /* ... */ });
app.get('/rooms', (req, res) => { /* ... */ });
app.get('/rooms/:id/messages', (req, res) => { /* ... */ });

server.listen(3000, () => console.log('Server on :3000'));
```

```js
// 測試用客戶端（Node.js）
const WebSocket = require('ws');
const ws = new WebSocket('ws://localhost:3000');
ws.on('open', () => {
  ws.send(JSON.stringify({ type: 'join', roomId: 'room1', username: 'Alice' }));
  ws.send(JSON.stringify({ type: 'message', roomId: 'room1', text: 'Hello!' }));
});
ws.on('message', (data) => console.log('收到：', data.toString()));
```

## 提示
- `ws.send()` 只接受字串，記得 `JSON.stringify()`
- 廣播時用 `wss.clients` 或自己維護 `clients` 物件過濾同房間成員
- 先用 `curl` 測試 REST API，再用 WebSocket 客戶端腳本測試即時功能
- 可以用 `wscat`（`npx wscat -c ws://localhost:3000`）互動測試

## 學習重點（跟後端 API 的關聯）

| 概念 | WebSocket 聊天室的體現 |
|------|----------------------|
| 雙向通訊 | 伺服器主動推送訊息，不需客戶端輪詢 |
| 狀態管理 | 伺服器記憶每個連線的用戶狀態（房間、名稱）|
| 廣播模式 | 訊息扇出（fan-out）給多個訂閱者，常見於通知系統 |
| REST + WS 共存 | 歷史資料用 HTTP，即時事件用 WS — 現實系統的標準分工 |

## 進階挑戰（選做）

1. **持久化**：將訊息寫入 `messages.json`，伺服器重啟後仍能取得歷史記錄
2. **房間人數上限**：每個房間最多 10 人，超過時回傳錯誤
3. **私訊功能**：加入 `{ type: "dm", to: "Bob", text: "..." }` 指令，只傳給指定用戶
4. **心跳保活**：每 30 秒向客戶端送 ping，斷線超過 60 秒自動踢出
5. **TypeScript 重構**：加入 interface 定義訊息格式，享受型別安全
