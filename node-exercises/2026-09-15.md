# 第 11 週今日 Node.js 練習題：使用 Multer 實作多欄位檔案上傳 API

## 題目說明

建立一個 Express API，讓使用者可以同時上傳「大頭貼」與「個人作品集（多個檔案）」，並且在上傳後返回每個檔案的儲存路徑與相關資訊。這個練習模擬真實後端 API 中常見的檔案上傳情境。

## 技術要求

- **概念**：multipart/form-data 解析、磁碟儲存策略、檔案類型過濾、檔案大小限制
- **需要的套件**：
  - `express`
  - `multer`

## 具體任務

1. 初始化專案並安裝所需套件：
   ```bash
   npm init -y
   npm install express multer
   ```

2. 使用 `multer.diskStorage` 設定儲存策略：
   - 大頭貼存至 `uploads/avatars/` 目錄
   - 作品集檔案存至 `uploads/portfolio/` 目錄
   - 儲存的檔名格式為：`[時間戳記]-[原始檔名]`（例如 `1726387200000-photo.jpg`）

3. 設定 `fileFilter`，只允許上傳以下格式：
   - 大頭貼：`image/jpeg`、`image/png`
   - 作品集：`image/jpeg`、`image/png`、`application/pdf`

4. 設定檔案大小限制：
   - 大頭貼最大 **2MB**
   - 作品集每個檔案最大 **5MB**，最多同時上傳 **3 個**

5. 建立 `POST /upload/profile` 路由，接受以下兩個欄位：
   - `avatar`：單一檔案
   - `portfolio`：多個檔案（最多 3 個）

6. 回傳 JSON 結果，包含每個上傳檔案的 `originalname`、`filename`、`path`、`size`。

7. 加入錯誤處理中介軟體，處理 `multer` 拋出的 `MulterError`（例如超過大小限制或超過數量限制），並回傳友善的錯誤訊息。

## 範例

**請求（使用 curl）：**

```bash
curl -X POST http://localhost:3000/upload/profile \
  -F "avatar=@photo.jpg" \
  -F "portfolio=@work1.pdf" \
  -F "portfolio=@work2.jpg"
```

**成功回應（HTTP 200）：**

```json
{
  "message": "上傳成功",
  "avatar": {
    "originalname": "photo.jpg",
    "filename": "1726387200000-photo.jpg",
    "path": "uploads/avatars/1726387200000-photo.jpg",
    "size": 102400
  },
  "portfolio": [
    {
      "originalname": "work1.pdf",
      "filename": "1726387200001-work1.pdf",
      "path": "uploads/portfolio/1726387200001-work1.pdf",
      "size": 512000
    },
    {
      "originalname": "work2.jpg",
      "filename": "1726387200002-work2.jpg",
      "path": "uploads/portfolio/1726387200002-work2.jpg",
      "size": 204800
    }
  ]
}
```

**錯誤回應（HTTP 400，檔案超過大小限制）：**

```json
{
  "error": "檔案太大，大頭貼最大允許 2MB，作品集每個最大允許 5MB"
}
```

## 提示

- `multer.diskStorage` 的 `destination` callback 可以根據 `fieldname` 動態決定儲存目錄，記得先用 `fs.mkdirSync` 確認目錄存在。
- `multer().fields([...])` 可以同時處理多個不同欄位名稱的檔案。
- `fileFilter` callback 的簽章是 `(req, file, cb)`，允許時呼叫 `cb(null, true)`，拒絕時呼叫 `cb(null, false)` 或 `cb(new Error('...'))`。
- `MulterError` 可以從 `multer` 套件中解構匯入：`const { MulterError } = require('multer')`。
- 錯誤處理中介軟體需要四個參數：`(err, req, res, next)`。

## 學習重點

**與後端 API 的關聯：**

- 幾乎所有需要使用者上傳頭像、履歷、作品或附件的應用（社群平台、人力銀行、電商後台）都需要這類 API。
- `multipart/form-data` 是瀏覽器表單上傳檔案的標準格式，前端開發者的 `<input type="file">` 或 `FormData` 物件送出的請求，後端就需要這樣的解析邏輯。
- 磁碟儲存（diskStorage）適合小型或自建環境；生產環境通常會改用雲端物件儲存（如 AWS S3、Google Cloud Storage），概念相同但目的地不同。
- 嚴格的 `fileFilter` 與大小限制是**安全性**的基礎，防止惡意使用者上傳可執行檔案或撐爆磁碟空間。

## 進階挑戰（選做）

1. **加入 sharp 進行圖片壓縮**：上傳大頭貼後，使用 `sharp` 套件將圖片縮放至 200×200 像素，並轉存為 WebP 格式，再回傳壓縮後的路徑。

2. **記憶體儲存 + 串流至 S3**：將 `diskStorage` 改為 `memoryStorage`，取得 `file.buffer` 後，使用 `@aws-sdk/client-s3` 的 `PutObjectCommand` 將檔案串流上傳到 S3 Bucket（可使用 LocalStack 模擬本地 S3 環境）。

3. **加入上傳進度回報**：研究如何透過 Server-Sent Events（SSE）或 WebSocket，在上傳大型檔案時即時回傳進度百分比給前端。
