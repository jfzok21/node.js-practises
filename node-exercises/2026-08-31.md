# 第 8 週今日 Node.js 練習題：用 `pg` 連接 PostgreSQL 實作 CRUD API

## 題目說明

在這個練習中，你將使用 `pg`（node-postgres）套件讓 Node.js 應用程式連接到 PostgreSQL 資料庫，並實作一個簡單的「使用者管理」資料存取層（Data Access Layer），涵蓋新增、查詢、更新、刪除（CRUD）四個基本操作。

這是後端 API 開發的核心基礎：幾乎所有的後端服務都需要與關聯式資料庫互動，而 `pg` 是 Node.js 生態系中最廣泛使用的 PostgreSQL 客戶端。

---

## 技術要求

- **概念**：連線池（Connection Pool）、參數化查詢（Parameterized Query）、async/await、環境變數
- **需要的套件**：
  - `pg`（node-postgres）
  - `dotenv`（讀取 `.env` 設定檔）

安裝指令：
```bash
npm init -y
npm install pg dotenv
```

## 具體任務

### 1. 設定資料庫連線

建立 `.env` 檔案（不要 commit 進 git！），填入你的 PostgreSQL 連線資訊：

```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=practice_db
DB_USER=postgres
DB_PASSWORD=your_password
```

建立 `db.js`，使用 `Pool` 建立連線池：

```js
// db.js
require('dotenv').config();
const { Pool } = require('pg');

const pool = new Pool({
  host: process.env.DB_HOST,
  port: process.env.DB_PORT,
  database: process.env.DB_NAME,
  user: process.env.DB_USER,
  password: process.env.DB_PASSWORD,
});

module.exports = pool;
```

### 2. 建立資料表

建立 `setup.js`，執行 SQL 建立 `users` 資料表（若不存在則建立）：

```sql
CREATE TABLE IF NOT EXISTS users (
  id SERIAL PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(100) UNIQUE NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);
```

### 3. 實作 CRUD 函式

建立 `userRepository.js`，實作以下四個函式：

| 函式名稱 | 說明 |
|---|---|
| `createUser(name, email)` | 新增一位使用者，回傳新增的資料 |
| `getAllUsers()` | 取得所有使用者列表 |
| `getUserById(id)` | 依 ID 取得單一使用者 |
| `updateUser(id, name, email)` | 更新使用者資料 |
| `deleteUser(id)` | 刪除使用者，回傳被刪除的資料 |

### 4. 建立 `main.js` 測試所有功能

依序執行：新增 → 查詢全部 → 依 ID 查詢 → 更新 → 刪除，並在 console 印出每個步驟的結果。

## 範例

```js
// userRepository.js 參考結構

const pool = require('./db');

async function createUser(name, email) {
  const result = await pool.query(
    'INSERT INTO users (name, email) VALUES ($1, $2) RETURNING *',
    [name, email]
  );
  return result.rows[0];
}

async function getAllUsers() {
  const result = await pool.query('SELECT * FROM users ORDER BY created_at DESC');
  return result.rows;
}

async function getUserById(id) {
  const result = await pool.query('SELECT * FROM users WHERE id = $1', [id]);
  return result.rows[0] || null;
}

async function updateUser(id, name, email) {
  const result = await pool.query(
    'UPDATE users SET name = $1, email = $2 WHERE id = $3 RETURNING *',
    [name, email, id]
  );
  return result.rows[0] || null;
}

async function deleteUser(id) {
  const result = await pool.query(
    'DELETE FROM users WHERE id = $1 RETURNING *',
    [id]
  );
  return result.rows[0] || null;
}

module.exports = { createUser, getAllUsers, getUserById, updateUser, deleteUser };
```

```js
// main.js 測試執行範例

const repo = require('./userRepository');
const pool = require('./db');

async function main() {
  // 新增
  const newUser = await repo.createUser('Alice', 'alice@example.com');
  console.log('新增使用者：', newUser);

  // 查詢全部
  const allUsers = await repo.getAllUsers();
  console.log('所有使用者：', allUsers);

  // 依 ID 查詢
  const found = await repo.getUserById(newUser.id);
  console.log('依 ID 查詢：', found);

  // 更新
  const updated = await repo.updateUser(newUser.id, 'Alice Chen', 'alice.chen@example.com');
  console.log('更新後：', updated);

  // 刪除
  const deleted = await repo.deleteUser(newUser.id);
  console.log('已刪除：', deleted);

  await pool.end(); // 關閉連線池
}

main().catch(console.error);
```

預期輸出：
```
新增使用者：{ id: 1, name: 'Alice', email: 'alice@example.com', created_at: ... }
所有使用者：[ { id: 1, ... } ]
依 ID 查詢：{ id: 1, name: 'Alice', ... }
更新後：{ id: 1, name: 'Alice Chen', email: 'alice.chen@example.com', ... }
已刪除：{ id: 1, name: 'Alice Chen', ... }
```

## 提示

- **一定要用參數化查詢（`$1`, `$2`...）**，絕對不要用字串拼接 SQL，否則會有 SQL Injection 安全漏洞。
- `Pool` 會自動管理多個資料庫連線，比每次都建立新連線效率高很多。
- `result.rows` 是查詢結果的陣列，`result.rows[0]` 是第一筆。
- 用 `RETURNING *` 讓 INSERT / UPDATE / DELETE 直接回傳受影響的資料列。
- 測試完畢要呼叫 `pool.end()` 關閉連線，否則程式不會自動結束。
- 將 `.env` 加入 `.gitignore`，不要將密碼上傳到版本控制。

## 學習重點

**與後端 API 的關聯：**

資料庫存取層（Repository / DAO Pattern）是後端 API 架構的基礎模組。在真實專案中，API 路由處理器（Controller）會呼叫這裡的 Repository 函式，Repository 負責所有與資料庫的互動。這樣的分層讓程式碼更容易維護和測試：

```
HTTP Request → Router → Controller → Repository → PostgreSQL
```

本週學習的技能將在下週（JWT 身份驗證）中被廣泛使用——例如儲存用戶資料、查詢用戶是否存在等，都需要與資料庫互動。

## 進階挑戰（選做）

1. **交易（Transaction）**：實作一個函式，在同一個交易中同時新增使用者和其個人資料，確保兩筆操作要麼全部成功、要麼全部失敗（使用 `BEGIN` / `COMMIT` / `ROLLBACK`）。

2. **分頁查詢**：修改 `getAllUsers()` 接受 `page` 和 `limit` 參數，實作分頁功能（使用 `LIMIT` 和 `OFFSET`）。

3. **搜尋功能**：新增 `searchUsers(keyword)` 函式，依名稱或 Email 模糊搜尋使用者（使用 `ILIKE`）。

4. **連線錯誤處理**：在 `db.js` 監聽 `pool.on('error', ...)` 事件，當連線意外斷開時印出錯誤訊息。
