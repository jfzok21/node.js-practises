# 第 8 週今日 Node.js 練習題：使用 PostgreSQL 建立使用者資料庫

## 題目說明

在真實的後端應用中，資料必須持久化儲存。本練習帶你從零開始，使用 Node.js 連接 PostgreSQL 資料庫，建立一個簡單的使用者 CRUD（新增、讀取、更新、刪除）系統，讓你熟悉 SQL 查詢與 Node.js 的整合方式。

## 技術要求

- **概念**：PostgreSQL 連線池、參數化查詢（防 SQL injection）、CRUD 操作、async/await 與資料庫互動
- **需要的套件**：
  - `pg`（node-postgres）— PostgreSQL 客戶端

## 具體任務

1. **建立專案並安裝套件**
   - `npm init -y`
   - `npm install pg`

2. **設定資料庫連線**
   - 建立 `db.js`，使用 `pg.Pool` 建立連線池
   - 設定連線參數（host、port、database、user、password）

3. **建立資料表**
   - 撰寫並執行 SQL，建立 `users` 資料表，欄位包含：
     - `id` SERIAL PRIMARY KEY
     - `name` VARCHAR(100) NOT NULL
     - `email` VARCHAR(150) UNIQUE NOT NULL
     - `created_at` TIMESTAMP DEFAULT NOW()

4. **實作 CRUD 函式**
   - `createUser(name, email)` — 新增使用者，回傳新建立的列
   - `getAllUsers()` — 查詢全部使用者
   - `getUserById(id)` — 依 id 查詢單一使用者
   - `updateUserName(id, newName)` — 更新使用者名稱
   - `deleteUser(id)` — 刪除使用者，回傳被刪除的列

5. **在 `index.js` 中依序呼叫以上函式**，並用 `console.log` 印出每步驟結果，最後關閉資料庫連線。

## 範例

```js
// db.js
const { Pool } = require('pg');

const pool = new Pool({
  host: 'localhost',
  port: 5432,
  database: 'practice_db',
  user: 'postgres',
  password: 'yourpassword',
});

module.exports = pool;

// users.js
const pool = require('./db');

async function createUser(name, email) {
  const result = await pool.query(
    'INSERT INTO users (name, email) VALUES ($1, $2) RETURNING *',
    [name, email]
  );
  return result.rows[0];
}

async function getAllUsers() {
  const result = await pool.query('SELECT * FROM users ORDER BY created_at DESC');
  return result.rows;
}

async function getUserById(id) {
  const result = await pool.query('SELECT * FROM users WHERE id = $1', [id]);
  return result.rows[0];
}

async function updateUserName(id, newName) {
  const result = await pool.query(
    'UPDATE users SET name = $1 WHERE id = $2 RETURNING *',
    [newName, id]
  );
  return result.rows[0];
}

async function deleteUser(id) {
  const result = await pool.query(
    'DELETE FROM users WHERE id = $1 RETURNING *',
    [id]
  );
  return result.rows[0];
}

module.exports = { createUser, getAllUsers, getUserById, updateUserName, deleteUser };

// index.js — 執行流程
const pool = require('./db');
const { createUser, getAllUsers, getUserById, updateUserName, deleteUser } = require('./users');

async function main() {
  // 建立資料表
  await pool.query(`
    CREATE TABLE IF NOT EXISTS users (
      id SERIAL PRIMARY KEY,
      name VARCHAR(100) NOT NULL,
      email VARCHAR(150) UNIQUE NOT NULL,
      created_at TIMESTAMP DEFAULT NOW()
    )
  `);

  const alice = await createUser('Alice', 'alice@example.com');
  console.log('新增使用者：', alice);

  const bob = await createUser('Bob', 'bob@example.com');
  console.log('新增使用者：', bob);

  const all = await getAllUsers();
  console.log('所有使用者：', all);

  const found = await getUserById(alice.id);
  console.log('查詢單一使用者：', found);

  const updated = await updateUserName(alice.id, 'Alice Chen');
  console.log('更新使用者名稱：', updated);

  const deleted = await deleteUser(bob.id);
  console.log('刪除使用者：', deleted);

  await pool.end();
}

main().catch(console.error);

// 預期輸出（id 與 created_at 依實際值而異）：
// 新增使用者：{ id: 1, name: 'Alice', email: 'alice@example.com', created_at: ... }
// 新增使用者：{ id: 2, name: 'Bob', email: 'bob@example.com', created_at: ... }
// 所有使用者：[ { id: 2, ... }, { id: 1, ... } ]
// 查詢單一使用者：{ id: 1, name: 'Alice', ... }
// 更新使用者名稱：{ id: 1, name: 'Alice Chen', ... }
// 刪除使用者：{ id: 2, name: 'Bob', ... }
```

## 提示

- 使用 `$1, $2` 佔位符而非字串拼接，可防止 SQL Injection 攻擊。
- `Pool` 比 `Client` 更適合應用程式使用，因為它會自動管理多個連線。
- `RETURNING *` 讓 INSERT / UPDATE / DELETE 直接回傳被影響的列，不需再查一次。
- 若本機沒有 PostgreSQL，可用 Docker 快速啟動：
  ```bash
  docker run --name pg-practice -e POSTGRES_PASSWORD=yourpassword -p 5432:5432 -d postgres
  ```
- 記得在程式結束時呼叫 `pool.end()`，否則 Node.js process 不會自動退出。

## 學習重點（跟後端 API 的關聯）

這週的練習是後端開發的核心基礎：

- **真實 API 的資料層**：幾乎所有 REST API 背後都有資料庫。你在這裡學到的 `Pool` + 參數化查詢，就是 Express 路由 handler 裡呼叫的那層邏輯。
- **資料持久化**：不同於之前用陣列暫存資料，PostgreSQL 讓資料在伺服器重啟後仍然存在。
- **SQL Injection 防護**：`$1, $2` 佔位符是後端安全的第一道防線，在接收使用者輸入時絕不能省略。
- **連線池管理**：`pg.Pool` 的概念在所有語言的資料庫操作中都通用（MySQL、MongoDB 等也有類似機制）。

## 進階挑戰（選做）

1. **加入 `dotenv`**：將資料庫連線參數移到 `.env` 檔案，用 `process.env` 讀取，避免硬碼敏感資訊。
2. **加入 email 格式驗證**：在 `createUser` 函式中，用正規表達式驗證 email 格式，若格式不對就拋出錯誤。
3. **分頁查詢**：修改 `getAllUsers` 支援 `limit` 與 `offset` 參數，實作分頁功能。
4. **整合 Express**：將 CRUD 函式包裝成 Express 路由（`GET /users`、`POST /users`、`PUT /users/:id`、`DELETE /users/:id`），讓資料庫操作可透過 HTTP 呼叫。
