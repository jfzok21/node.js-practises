# 第 11 週今日 Node.js 練習題：使用 Multer 實作檔案上傳 API

## 題目說明

建立一個 Express REST API，讓使用者可以上傳圖片或文件。你需要使用 `multer` 中介軟體處理 `multipart/form-data` 請求，並實作上傳大小限制、檔案類型驗證，以及上傳後回傳檔案資訊。

## 技術要求

- **概念**：multipart/form-data、MIME type 驗證、檔案儲存策略（diskStorage / memoryStorage）、Express Middleware
- **需要的套件**：
  - `express`
  - `multer`

## 具體任務

1. **初始化專案**
   - 建立新資料夾 `file-upload-api`，執行 `npm init -y`
   - 安裝 `express` 和 `multer`

2. **設定 Multer 的 diskStorage**
   - 指定上傳目標資料夾為 `uploads/`
   - 自訂檔案名稱（加入時間戳避免衝突）：`Date.now() + '-' + originalname`

3. **加入檔案驗證**
   - 只允許 `image/jpeg`、`image/png`、`application/pdf` 三種 MIME type
   - 超出允許類型時，使用 `cb(new Error('不支援的檔案類型'), false)` 拒絕上傳
   - 限制單一檔案最大為 5MB（`limits: { fileSize: 5 * 1024 * 1024 }`）

4. **實作上傳端點**
   - `POST /upload`：接受單一檔案（欄位名稱 `file`），回傳上傳後的檔案資訊
   - `POST /upload-multiple`：接受最多 5 個檔案（欄位名稱 `files`），回傳所有檔案資訊
   - `GET /files`：列出 `uploads/` 資料夾中的所有檔案名稱

5. **錯誤處理 Middleware**
   - 攔截 Multer 錯誤（如超過大小限制 `MulterError`）並回傳有意義的錯誤訊息

## 範例

```js
// POST /upload 成功回應
{
  "message": "檔案上傳成功",
  "file": {
    "originalname": "photo.jpg",
    "filename": "1727136000000-photo.jpg",
    "mimetype": "image/jpeg",
    "size": 204800,
    "path": "uploads/1727136000000-photo.jpg"
  }
}

// POST /upload 錯誤回應（類型不符）
{
  "error": "不支援的檔案類型"
}

// POST /upload 錯誤回應（超過大小限制）
{
  "error": "檔案大小超過限制（最大 5MB）"
}

// GET /files 回應
{
  "files": [
    "1727136000000-photo.jpg",
    "1727136001000-document.pdf"
  ]
}
```

## 提示

- 記得在 Express app 啟動前先確保 `uploads/` 資料夾存在（可用 `fs.mkdirSync('uploads', { recursive: true })`）
- `multer` 的 `fileFilter` callback 格式為 `(req, file, cb)`，接受用 `cb(null, true)`，拒絕用 `cb(null, false)` 或 `cb(new Error(...))`
- Multer 錯誤要用專屬 error middleware 處理（四個參數：`err, req, res, next`），並判斷 `err instanceof multer.MulterError`
- 使用 curl 測試：`curl -X POST http://localhost:3000/upload -F "file=@./test.jpg"`

## 學習重點

**與後端 API 的關聯：**

檔案上傳是實際後端開發中非常常見的需求，例如使用者大頭照上傳、履歷 PDF 上傳、商品圖片管理等。掌握 Multer 能讓你了解：

- 如何處理 `Content-Type: multipart/form-data` 與一般 JSON 請求的差異
- 伺服器端的安全性驗證（類型白名單、大小限制）防止惡意上傳
- 雲端部署時 diskStorage 要替換成 S3/GCS 等雲端儲存（Multer 架構支援替換 storage engine）

## 進階挑戰（選做）

1. **整合 `sharp` 套件**：上傳圖片後自動壓縮並產生縮圖（寬度 200px），一併儲存縮圖版本
2. **加入上傳記錄**：每次上傳成功後，將檔案資訊（名稱、大小、時間）append 寫入 `uploads/log.json`
3. **DELETE /files/:filename**：實作刪除端點，用 `fs.unlink` 刪除指定檔案，並回傳操作結果
