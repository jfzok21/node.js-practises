# 第 3 週今日 Node.js 練習題：非同步任務排程器

## 題目說明

建立一個模擬「非同步任務排程器」的程式。你需要用三種方式（Callback、Promise、async/await）分別實作同一個「讀取用戶資料 → 取得訂單 → 計算總金額」的流程，體驗三種非同步寫法的差異。

## 技術要求
- 概念：Callback、Promise、async/await、Promise.all、錯誤處理（try/catch）
- 需要的套件：無（使用 Node.js 內建功能）

## 具體任務

1. **Callback 版本**：用巢狀 callback 模擬「先取得用戶 → 再取得訂單 → 計算總金額」。
2. **Promise 版本**：用 `.then().catch()` 串接相同流程，消除巢狀。
3. **async/await 版本**：用 `async function` 加 `try/catch` 改寫，讓程式碼像同步一樣易讀。
4. **進階**：用 `Promise.all` 同時平行取得多位用戶的訂單，比較與序列執行的時間差異。

## 範例

```js
// 模擬非同步 API（用 setTimeout 模擬延遲）
function getUser(userId, callback) {
  setTimeout(() => {
    if (!userId) return callback(new Error('userId 必填'));
    callback(null, { id: userId, name: '小明' });
  }, 100);
}

function getOrders(userId, callback) {
  setTimeout(() => {
    callback(null, [
      { id: 1, amount: 350 },
      { id: 2, amount: 120 },
    ]);
  }, 100);
}

// --- Callback 版本 ---
getUser(1, (err, user) => {
  if (err) return console.error('Error:', err.message);
  getOrders(user.id, (err, orders) => {
    if (err) return console.error('Error:', err.message);
    const total = orders.reduce((sum, o) => sum + o.amount, 0);
    console.log(`${user.name} 的訂單總金額：${total}`); // 小明 的訂單總金額：470
  });
});

// --- Promise 版本 ---
function getUserPromise(userId) {
  return new Promise((resolve, reject) => {
    getUser(userId, (err, user) => (err ? reject(err) : resolve(user)));
  });
}

function getOrdersPromise(userId) {
  return new Promise((resolve, reject) => {
    getOrders(userId, (err, orders) => (err ? reject(err) : resolve(orders)));
  });
}

getUserPromise(1)
  .then(user => getOrdersPromise(user.id).then(orders => ({ user, orders })))
  .then(({ user, orders }) => {
    const total = orders.reduce((sum, o) => sum + o.amount, 0);
    console.log(`${user.name} 的訂單總金額：${total}`);
  })
  .catch(err => console.error('Error:', err.message));

// --- async/await 版本 ---
async function getUserOrders(userId) {
  const user = await getUserPromise(userId);
  const orders = await getOrdersPromise(user.id);
  const total = orders.reduce((sum, o) => sum + o.amount, 0);
  console.log(`${user.name} 的訂單總金額：${total}`);
}

getUserOrders(1).catch(err => console.error('Error:', err.message));
```

## 提示
- `setTimeout(fn, ms)` 是最常見的非同步模擬方式，0ms 也算非同步。
- Callback 的第一個參數慣例是 `error`，沒有錯誤時傳 `null`，這稱為「error-first callback」。
- `new Promise((resolve, reject) => {...})` 是將 callback API 轉為 Promise 的標準寫法（promisify）。
- `async` 函式一定回傳 Promise，即使你 `return` 的是普通值。
- `await` 只能在 `async` 函式內使用；若要在模組最頂層使用，需要 `"type": "module"` 或 Node 22+ Top-level await。

## 學習重點
（跟後端 API 的關聯）

後端 API 幾乎所有操作都是非同步的：查資料庫、呼叫外部服務、讀寫檔案。
- **Express route handler** 大量使用 `async/await`，若未加 try/catch 且 Promise 拋錯，會讓伺服器 crash（需搭配 error middleware 或 `express-async-errors`）。
- **Promise.all** 對應 API 中「同時查多張表、平行呼叫多個微服務」，可大幅縮短回應時間。
- 理解 callback → Promise → async/await 的演進，有助於閱讀各種版本的第三方套件原始碼。

2. **自製 promisify**：實作一個 `promisify(fn)` 函式，可將任何 error-first callback 函式轉為回傳 Promise 的版本（類似 Node.js 內建的 `util.promisify`）。

3. **逾時機制**：用 `Promise.race` 為 API 呼叫加上 2 秒逾時，超時則 reject 並顯示「請求逾時」錯誤。
