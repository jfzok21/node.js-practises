# 第 13 週今日 Node.js 練習題：部落格後端 API 實戰專案

## 題目說明

綜合前 12 週所學，建立一個具備完整功能的 **部落格後端 API**。這個專案將整合 Express、PostgreSQL、JWT 身份驗證、檔案上傳、輸入驗證與 Jest 測試，模擬真實工作環境中的後端開發流程。

## 技術要求

- **概念**：REST API 設計、MVC 架構分層、JWT 身份驗證、資料庫關聯設計、錯誤處理中介軟體
- **需要的套件**：
  - `express` — 路由與伺服器

  - `multer` — 封面圖片上傳
  - `joi` — 輸入驗證
  - `jest` + `supertest` — API 測試

## 具體任務

### 1. 資料庫設計

建立以下三張資料表：

```sql
-- 使用者
CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  username VARCHAR(50) UNIQUE NOT NULL,
  email VARCHAR(100) UNIQUE NOT NULL,
  password_hash VARCHAR(255) NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);

-- 文章
CREATE TABLE posts (
  id SERIAL PRIMARY KEY,
  title VARCHAR(200) NOT NULL,
  content TEXT NOT NULL,
  cover_image VARCHAR(255),
  author_id INTEGER REFERENCES users(id) ON DELETE CASCADE,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- 標籤（多對多）
CREATE TABLE tags (
  id SERIAL PRIMARY KEY,
  name VARCHAR(50) UNIQUE NOT NULL
);

CREATE TABLE post_tags (
  post_id INTEGER REFERENCES posts(id) ON DELETE CASCADE,
  tag_id INTEGER REFERENCES tags(id) ON DELETE CASCADE,
  PRIMARY KEY (post_id, tag_id)
);
```

### 3. 實作 API 端點

| 方法   | 路徑                   | 說明               | 需登入 |
|--------|------------------------|--------------------|--------|
| POST   | /api/auth/register     | 使用者註冊         | 否     |
| POST   | /api/auth/login        | 使用者登入         | 否     |
| GET    | /api/posts             | 取得所有文章列表   | 否     |
| GET    | /api/posts/:id         | 取得單篇文章       | 否     |
| POST   | /api/posts             | 建立新文章         | 是     |
| PUT    | /api/posts/:id         | 更新文章           | 是（作者本人）|
| DELETE | /api/posts/:id         | 刪除文章           | 是（作者本人）|
| POST   | /api/posts/:id/cover   | 上傳封面圖片       | 是     |

### 4. 實作 JWT 驗證中介軟體

```js
// src/middleware/auth.js
const jwt = require('jsonwebtoken');

module.exports = (req, res, next) => {
  const token = req.headers.authorization?.split(' ')[1];
  if (!token) return res.status(401).json({ error: '未提供 Token' });

  try {
    req.user = jwt.verify(token, process.env.JWT_SECRET);
    next();
  } catch {
    res.status(401).json({ error: 'Token 無效或已過期' });
  }
};
```

### 5. 撰寫至少 6 個 Jest 測試

涵蓋：
- 成功註冊 → 回傳 201
- 重複 email 註冊 → 回傳 400
- 成功登入 → 回傳含 `token` 的 JSON
- 未登入建立文章 → 回傳 401
- 成功建立文章 → 回傳 201
- 非作者刪除文章 → 回傳 403

## 提示

- 使用 `bcrypt.hash(password, 10)` 儲存密碼，用 `bcrypt.compare()` 驗證
- JWT 簽發時放入 `{ id, username }`，設定 `expiresIn: '7d'`
- `multer` 設定 `dest: 'uploads/'`，並限制 `fileFilter` 只接受 `image/*`
- Joi 驗證可抽成通用中介軟體：`validate(schema)` 回傳一個 middleware function
- 文章列表可支援 `?page=1&limit=10` 分頁查詢
- 使用 `pg` 的 `pool.query()` 搭配 `$1, $2` 防止 SQL Injection

## 學習重點（跟後端 API 的關聯）

這個專案整合了真實工作中最常見的後端開發模式：

- **分層架構（MVC）**：路由負責接收，Controller 處理邏輯，db 模組負責資料存取，讓程式碼易維護
- **身份驗證流程**：無狀態 JWT 是現代 REST API 的標準做法，搭配 Bearer Token 規範
- **資料庫關聯**：多對多關聯（文章與標籤）在實際專案中非常常見
- **錯誤處理**：統一的 `errorHandler` 中介軟體讓 API 回應格式一致
- **輸入驗證**：在 Controller 執行前先驗證，防止無效資料進入資料庫
- **自動化測試**：每次修改後跑 `jest` 確保功能不退步，是團隊協作的基石

## 進階挑戰（選做）

1. **分頁 + 搜尋**：`GET /api/posts?page=2&limit=5&keyword=nodejs` 支援關鍵字搜尋文章標題
2. **留言功能**：新增 `comments` 資料表，實作 `POST /api/posts/:id/comments`
3. **Rate Limiting**：使用 `express-rate-limit` 限制登入 API 每分鐘最多 5 次請求，防止暴力破解
4. **Refresh Token**：實作雙 Token 機制（access token 短效 + refresh token 長效），提升安全性
5. **Docker 化**：撰寫 `Dockerfile` 與 `docker-compose.yml`，一鍵啟動 API + PostgreSQL
