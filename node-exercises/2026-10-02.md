# 第 13 週今日 Node.js 練習題：迷你部落格 REST API 完整實作

## 題目說明

綜合前 12 週所學，從零開始建立一個具備使用者認證、文章 CRUD、圖片上傳與完整測試的迷你部落格後端 API。這是一個讓你把所有技能整合在一起的實戰專案。

## 技術要求

- **概念：** Express、JWT 身份驗證、PostgreSQL CRUD、輸入驗證、檔案上傳、Jest 整合測試
- **需要的套件：**
  ```
  express
  pg
  jsonwebtoken
  bcrypt
  express-validator
  multer
  jest
  supertest
  dotenv
  ```

## 具體任務

### 1. 專案初始化
- 執行 `npm init -y` 並安裝所有套件
- 建立 `.env` 檔案，設定 `DATABASE_URL`、`JWT_SECRET`、`PORT`
- 建立資料夾結構：
  ```
  src/
    routes/
    controllers/
    middlewares/
    db/
  uploads/
  tests/
  ```

### 2. 資料庫設計（PostgreSQL）
建立兩張資料表：
```sql
CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  username VARCHAR(50) UNIQUE NOT NULL,
  email VARCHAR(100) UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE posts (
  id SERIAL PRIMARY KEY,
  title VARCHAR(200) NOT NULL,
  content TEXT NOT NULL,
  image_url TEXT,
  author_id INTEGER REFERENCES users(id) ON DELETE CASCADE,
  created_at TIMESTAMP DEFAULT NOW()
);
```

### 3. 使用者路由（`/api/auth`）
- `POST /register`：註冊（username、email、password），密碼用 bcrypt hash
- `POST /login`：登入，回傳 JWT token

### 4. 文章路由（`/api/posts`）
- `GET /`：取得所有文章（公開，含作者 username）
- `GET /:id`：取得單篇文章（公開）
- `POST /`：新增文章（需 JWT），支援上傳一張圖片（multer）
- `PUT /:id`：更新自己的文章（需 JWT，只能改自己的）
- `DELETE /:id`：刪除自己的文章（需 JWT，只能刪自己的）

### 5. 驗證（express-validator）
- 註冊：username 3–20 字元、email 格式、password 最少 8 字元
- 文章：title 不可空白且最多 200 字元、content 不可空白

### 6. 撰寫 Jest 測試（`tests/posts.test.js`）
至少測試以下情境：
- 未登入時 `POST /api/posts` 回傳 401
- 登入後可成功新增文章
- 嘗試刪除別人的文章回傳 403

## 範例

```js
// POST /api/auth/login
// 請求 body
{ "email": "alice@example.com", "password": "secret123" }

// 成功回應 200
{ "token": "eyJhbGci..." }

// POST /api/posts（Header: Authorization: Bearer <token>）
// 請求 body (form-data)
{ "title": "我的第一篇文章", "content": "Hello World!", "image": <file> }

// 成功回應 201
{
  "id": 1,
  "title": "我的第一篇文章",
  "content": "Hello World!",
  "image_url": "/uploads/1727827200000.jpg",
  "author_id": 3,
  "created_at": "2026-10-02T10:00:00.000Z"
}

// DELETE /api/posts/1（嘗試刪除別人的文章）
// 回應 403
{ "error": "無權限刪除此文章" }
```

## 提示

- JWT middleware 放在 `src/middlewares/auth.js`，用 `req.user` 傳遞解碼後的使用者資訊
- multer 設定 `dest: 'uploads/'`，只接受 `image/jpeg` 與 `image/png`
- 刪除／更新前先查詢文章的 `author_id` 是否等於 `req.user.id`
- 所有資料庫查詢集中在 `src/db/` 下各自的 query 檔案，控制器保持乾淨
- 測試時使用 `supertest` 直接測 Express app，不要真的啟動 server

## 學習重點（跟後端 API 的關聯）

這個專案模擬了真實後端工作中最常見的完整功能循環：

| 功能 | 對應真實場景 |
|------|-------------|
| JWT 驗證 middleware | 所有需要登入才能存取的 API |
| bcrypt 雜湊密碼 | 安全儲存使用者憑證 |
| multer 圖片上傳 | 頭像、商品圖、附件功能 |
| express-validator | 防止非法資料進入資料庫 |
| author_id 權限檢查 | 防止越權操作（IDOR 漏洞防護） |
| supertest + Jest | CI/CD 流程中自動化驗收測試 |

## 進階挑戰（選做）

1. **分頁**：`GET /api/posts?page=1&limit=10`，使用 SQL `LIMIT` 與 `OFFSET`
2. **搜尋**：`GET /api/posts?q=關鍵字`，使用 PostgreSQL `ILIKE`
3. **Refresh Token**：實作 access token（15 分鐘）+ refresh token（7 天）機制
4. **Rate Limiting**：安裝 `express-rate-limit`，限制登入端點每 IP 每分鐘最多 5 次
5. **Docker Compose**：撰寫 `docker-compose.yml`，讓整個專案一鍵啟動（Node app + PostgreSQL）
