# 第 9 週今日 Node.js 練習題：JWT 身份驗證系統

## 題目說明

實作一個具備 JWT（JSON Web Token）身份驗證機制的 Express API。使用者可以註冊、登入，並透過 JWT Token 存取受保護的路由。

## 技術要求

- 概念：JWT 簽發與驗證、Bearer Token、Middleware 保護路由、密碼雜湊
- 需要的套件：`express`、`jsonwebtoken`、`bcryptjs`、`dotenv`

## 具體任務

1. 初始化專案並安裝所需套件（`npm init -y && npm install express jsonwebtoken bcryptjs dotenv`）
2. 建立 `.env` 檔案，設定 `JWT_SECRET` 與 `PORT`
3. 建立 `POST /register` 路由：接收 `username` 與 `password`，使用 `bcryptjs` 雜湊密碼後儲存至記憶體陣列
4. 建立 `POST /login` 路由：驗證使用者名稱與密碼，成功後使用 `jsonwebtoken` 簽發有效期 1 小時的 Token
5. 建立 `authMiddleware`：從 `Authorization: Bearer <token>` 標頭中取出並驗證 JWT，驗證失敗回傳 `401`
6. 建立 `GET /profile` 受保護路由：套用 `authMiddleware`，回傳當前登入使用者的資訊

## 範例

```js
// .env
JWT_SECRET=mysupersecretkey
PORT=3000

// 註冊請求
// POST /register
// Body: { "username": "alice", "password": "pass123" }
// Response: { "message": "註冊成功" }

// 登入請求
// POST /login
// Body: { "username": "alice", "password": "pass123" }
// Response: { "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." }

// 存取受保護路由
// GET /profile
// Headers: Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
// Response: { "username": "alice", "message": "歡迎回來！" }

// 無效 Token 或未提供 Token
// GET /profile（無 Authorization 標頭）
// Response 401: { "error": "未授權，請先登入" }
```

## 提示

- 使用 `bcryptjs.hash(password, 10)` 進行密碼雜湊，`saltRounds` 設為 `10`
- 使用 `bcryptjs.compare(password, hashedPassword)` 驗證密碼
- 使用 `jwt.sign({ username }, process.env.JWT_SECRET, { expiresIn: '1h' })` 簽發 Token
- 使用 `jwt.verify(token, process.env.JWT_SECRET)` 驗證 Token，記得用 `try/catch` 捕捉 `JsonWebTokenError` 與 `TokenExpiredError`
- Middleware 中透過 `req.headers.authorization?.split(' ')[1]` 取得 Token
- 驗證成功後將解碼資訊掛到 `req.user`，讓後續路由使用

## 學習重點（跟後端 API 的關聯）

JWT 是現代 REST API 無狀態身份驗證的核心機制。伺服器不需儲存 Session，Token 本身即攜帶使用者資訊。這套模式廣泛應用於：

- 前後端分離的 SPA 應用（React/Vue + Express）
- 微服務間的服務對服務驗證
- 行動 App 呼叫後端 API

掌握 `authMiddleware` 的寫法，可輕鬆為任何路由加上身份保護，是建構安全 API 的基礎。

## 進階挑戰（選做）

1. **Refresh Token 機制**：額外簽發有效期 7 天的 Refresh Token，並建立 `POST /refresh` 路由，用 Refresh Token 換取新的 Access Token
2. **角色授權（RBAC）**：在 Token payload 中加入 `role`（如 `admin` / `user`），建立 `authorizeRole('admin')` Middleware，讓特定路由只有 admin 能存取
3. **Token 黑名單**：登出時將 Token 加入記憶體黑名單，`authMiddleware` 驗證時額外檢查是否已被登出
