# 第 4 週今日 Node.js 練習題：從零打造 HTTP 伺服器

## 題目說明

不依賴任何框架，只用 Node.js 內建的 `http` 模組，手刻一個能處理多種路由與 HTTP 方法的 JSON API 伺服器。這個練習讓你徹底理解 Express 背後的運作原理。

你要建立一個「任務管理 API」，支援：
- `GET /tasks` — 取得所有任務
- `GET /tasks/:id` — 取得單一任務
- `POST /tasks` — 新增任務
- `DELETE /tasks/:id` — 刪除任務
- 其他路徑 — 回傳 404

## 技術要求

- 概念：`http.createServer`、`IncomingMessage`、`ServerResponse`、路由手動解析、Request body 收集、JSON 回應
- 需要的套件：無（純 Node.js 內建模組）

## 具體任務

### 任務一：啟動伺服器

1. 建立 `task-server.js`
2. 用 `http.createServer((req, res) => { ... })` 建立伺服器
3. 監聽 `3000` 埠
4. 伺服器啟動後印出 `Server running at http://localhost:3000`

### 任務二：建立記憶體資料儲存

1. 宣告一個陣列 `let tasks = []` 作為記憶體資料庫
2. 宣告 `let nextId = 1` 作為遞增 ID 計數器
3. 預先加入兩筆初始資料：
   ```js
   { id: 1, title: '學習 http 模組', done: false }
   { id: 2, title: '完成今日練習', done: false }
   ```

### 任務三：實作路由與回應

在 `createServer` 的 callback 中，根據 `req.method` 和 `req.url` 決定行為：

1. **`GET /tasks`**：回傳 `{ tasks }` JSON，狀態碼 `200`
2. **`GET /tasks/:id`**：解析 URL 取出 id，找到任務後回傳 `{ task }`；找不到回傳 `{ error: 'Task not found' }` 狀態碼 `404`
3. **`POST /tasks`**：收集 Request body（用 `req.on('data')` 和 `req.on('end')`），解析 JSON，建立新任務並加入陣列，回傳 `{ task }` 狀態碼 `201`
4. **`DELETE /tasks/:id`**：刪除對應任務，回傳 `{ message: 'Deleted' }` 狀態碼 `200`；找不到回傳 `404`
5. **其他所有路徑**：回傳 `{ error: 'Not Found' }` 狀態碼 `404`

### 任務四：設定 JSON 回應標頭

每個回應都必須設定：
```js
res.setHeader('Content-Type', 'application/json')
```

### 任務五：測試 API

用 `curl` 指令測試每個端點：
```bash
# 取得所有任務
curl http://localhost:3000/tasks

# 取得單一任務
curl http://localhost:3000/tasks/1

# 新增任務
curl -X POST http://localhost:3000/tasks \
  -H "Content-Type: application/json" \
  -d '{"title": "讀 Node.js 文件"}'

# 刪除任務
curl -X DELETE http://localhost:3000/tasks/1
```

## 範例

```js
// task-server.js 骨架

const http = require('http')

let tasks = [
  { id: 1, title: '學習 http 模組', done: false },
  { id: 2, title: '完成今日練習', done: false }
]
let nextId = 3

function sendJSON(res, statusCode, data) {
  res.writeHead(statusCode, { 'Content-Type': 'application/json' })
  res.end(JSON.stringify(data))
}

function collectBody(req) {
  return new Promise((resolve) => {
    let body = ''
    req.on('data', chunk => { body += chunk })
    req.on('end', () => resolve(body))
  })
}

const server = http.createServer(async (req, res) => {
  const { method, url } = req

  // 路由比對範例
  if (method === 'GET' && url === '/tasks') {
    // TODO: 回傳所有任務
  } else if (method === 'GET' && url.startsWith('/tasks/')) {
    // TODO: 取出 id，找到並回傳單一任務
  } else if (method === 'POST' && url === '/tasks') {
    // TODO: 收集 body，新增任務
  } else if (method === 'DELETE' && url.startsWith('/tasks/')) {
    // TODO: 刪除任務
  } else {
    sendJSON(res, 404, { error: 'Not Found' })
  }
})

server.listen(3000, () => {
  console.log('Server running at http://localhost:3000')
})
```

預期輸出（`curl http://localhost:3000/tasks`）：
```json
{
  "tasks": [
    { "id": 1, "title": "學習 http 模組", "done": false },
    { "id": 2, "title": "完成今日練習", "done": false }
  ]
}
```

## 提示

- `req.url` 包含完整路徑，如 `/tasks/3`；用 `url.split('/')` 或正則取出 ID
- `parseInt(id)` 轉換字串 ID 為數字再做比對
- `JSON.stringify(data)` 將物件轉為字串後才能用 `res.end()` 送出
- `async` callback 搭配 `await collectBody(req)` 是收集 POST body 最乾淨的做法
- 若 `JSON.parse(body)` 的 body 是空字串會拋錯，記得先判斷 `body` 是否有值

## 學習重點（跟後端 API 的關聯）

Express 的本質就是對 `http` 模組的封裝：
- `app.get('/tasks', handler)` → 對應你手寫的 `method === 'GET' && url === '/tasks'`
- `res.json(data)` → 對應你手寫的 `sendJSON(res, 200, data)`
- `req.body` → 對應你手寫的 `collectBody(req)` + `JSON.parse`

親手實作這些細節後，你對 Express 的每個功能都會有更深的直覺，排查問題也會更有把握。

## 進階挑戰（選做）

1. **支援 `PUT /tasks/:id`**：更新指定任務的 `title` 或 `done` 狀態
2. **查詢字串篩選**：讓 `GET /tasks?done=true` 只回傳已完成的任務（提示：用 `new URL(req.url, 'http://localhost')` 解析 query string）
3. **錯誤邊界**：在 POST 時，若 body 解析失敗（非法 JSON），回傳 `400 Bad Request` 而非讓伺服器崩潰
4. **模擬 Express Router**：抽出一個 `router` 物件，支援 `router.get(path, handler)` 和 `router.post(path, handler)` 的註冊方式
