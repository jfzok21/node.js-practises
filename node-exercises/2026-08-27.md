# 第 8 週今日 Node.js 練習題：使用 PostgreSQL 建立留言板 API

## 題目說明

在實際的後端開發中，資料必須持久化儲存在資料庫中。本週將學習如何使用 Node.js 連接 PostgreSQL 資料庫，並透過 `pg` 套件執行 CRUD 操作，建立一個簡單的留言板 REST API。

## 技術要求

- **概念**：資料庫連線池（Connection Pool）、SQL 查詢（SELECT / INSERT / UPDATE / DELETE）、參數化查詢（防止 SQL Injection）、async/await 搭配資料庫操作
- **需要的套件**：
  - `express` — HTTP 伺服器框架
  - `pg` — PostgreSQL 客戶端（`npm install pg`）
  - `dotenv` — 管理環境變數（`npm install dotenv`）

## 具體任務

1. **建立資料庫設定**
   - 在專案根目錄建立 `.env` 檔案，設定 PostgreSQL 連線參數（`DB_HOST`、`DB_PORT`、`DB_USER`、`DB_PASSWORD`、`DB_NAME`）
   - 建立 `db.js`，使用 `pg.Pool` 建立連線池並匯出

2. **初始化資料表**
   - 建立 `init.sql`，定義 `messages` 資料表：
     ```sql
     CREATE TABLE IF NOT EXISTS messages (
       id SERIAL PRIMARY KEY,
       author VARCHAR(100) NOT NULL,
       content TEXT NOT NULL,
       created_at TIMESTAMP DEFAULT NOW()
     );
     ```
   - 在應用程式啟動時（或手動執行）建立資料表

3. **實作 CRUD 路由**（使用 Express）
   - `GET /messages` — 取得所有留言（依 `created_at` 降冪排序）
   - `POST /messages` — 新增留言（body: `{ author, content }`）
   - `PUT /messages/:id` — 更新留言內容（body: `{ content }`）
   - `DELETE /messages/:id` — 刪除留言

4. **使用參數化查詢**，確保所有 SQL 語句都使用 `$1`、`$2` 佔位符，避免 SQL Injection

5. **錯誤處理**：資料庫操作失敗時回傳適當的 HTTP 狀態碼與訊息

## 範例

```js
// db.js
const { Pool } = require('pg');
require('dotenv').config();

const pool = new Pool({
  host: process.env.DB_HOST,
  port: process.env.DB_PORT,
  user: process.env.DB_USER,
  password: process.env.DB_PASSWORD,
  database: process.env.DB_NAME,
});

module.exports = pool;

// routes/messages.js
const express = require('express');
const router = express.Router();
const pool = require('../db');

// 取得所有留言
router.get('/', async (req, res) => {
  try {
    const result = await pool.query(
      'SELECT * FROM messages ORDER BY created_at DESC'
    );
    res.json(result.rows);
  } catch (err) {
    res.status(500).json({ error: '資料庫查詢失敗' });
  }
});

// 新增留言
router.post('/', async (req, res) => {
  const { author, content } = req.body;
  if (!author || !content) {
    return res.status(400).json({ error: 'author 與 content 為必填欄位' });
  }
  try {
    const result = await pool.query(
      'INSERT INTO messages (author, content) VALUES ($1, $2) RETURNING *',
      [author, content]
    );
    res.status(201).json(result.rows[0]);
  } catch (err) {
    res.status(500).json({ error: '新增留言失敗' });
  }
});

// 刪除留言
router.delete('/:id', async (req, res) => {
  const { id } = req.params;
  try {
    const result = await pool.query(
      'DELETE FROM messages WHERE id = $1 RETURNING *',
      [id]
    );
    if (result.rowCount === 0) {
      return res.status(404).json({ error: '找不到該留言' });
    }
    res.json({ message: '留言已刪除', deleted: result.rows[0] });
  } catch (err) {
    res.status(500).json({ error: '刪除失敗' });
  }
});

module.exports = router;

// 預期 POST /messages 輸入
// Body: { "author": "Alice", "content": "Hello World!" }
// 回應: { "id": 1, "author": "Alice", "content": "Hello World!", "created_at": "..." }
```

## 提示

- 如果本機沒有安裝 PostgreSQL，可使用 Docker 快速啟動：
  ```bash
  docker run --name pg-dev -e POSTGRES_PASSWORD=password -e POSTGRES_DB=messages_db -p 5432:5432 -d postgres
  ```
- `pool.query()` 回傳的物件中，`result.rows` 是查詢結果陣列，`result.rowCount` 是受影響的行數
- 使用 `RETURNING *` 可讓 INSERT / UPDATE / DELETE 同時回傳被操作的資料列
- 記得將 `.env` 加入 `.gitignore`，不要把密碼推上 GitHub

## 學習重點

（跟後端 API 的關聯）

PostgreSQL 整合是後端 API 開發的核心技能。大多數生產環境的 API 都需要：

1. **連線池**：避免每次請求都重新建立連線，提高效能與資源利用率
2. **參數化查詢**：OWASP Top 10 安全防護的基礎，所有使用者輸入都不應直接嵌入 SQL 字串
3. **事務（Transaction）**：在第 9 週（JWT）之後，多步驟操作（如：建立帳號同時初始化個人資料）需要 `BEGIN / COMMIT / ROLLBACK` 確保原子性
4. **ORM 的前導知識**：理解原始 SQL 與 `pg` 的運作方式，有助於之後使用 Sequelize 或 Prisma 等 ORM 工具

## 進階挑戰（選做）

1. **分頁功能**：在 `GET /messages` 加入 `?page=1&limit=10` 查詢參數，使用 `LIMIT` 與 `OFFSET` 實作分頁
2. **搜尋功能**：加入 `?search=關鍵字` 參數，使用 `ILIKE` 做大小寫不敏感的內容搜尋
3. **Transaction 練習**：實作一個「轉移留言作者」的端點，同時更新舊作者的所有留言，並記錄操作 log，使用 Transaction 確保兩個操作要嘛全部成功、要嘛全部失敗
4. **連線狀態健康檢查**：新增 `GET /health` 端點，執行 `SELECT 1` 驗證資料庫連線是否正常，並回傳連線池狀態
