# 第 16 週今日 Node.js 練習題：即時聊天室（Socket.io 實戰）

## 題目說明

使用 **Socket.io** 搭配 Express 打造一個支援多房間的即時聊天室後端。使用者可以加入不同聊天室、傳送訊息，伺服器即時廣播給同室所有成員。藉此理解 WebSocket 雙向通訊的核心機制，以及它與傳統 REST API「請求-回應」模式的根本差異。

---

## 技術要求

- **概念**：WebSocket、事件驅動架構（Event-Driven）、Socket.io 房間（Rooms）、廣播（broadcast）、中介層（middleware）
- **需要的套件**：
  - `express` — HTTP 伺服器與靜態檔案服務
  - `socket.io` — WebSocket 雙向通訊
  - `uuid` — 產生訊息唯一 ID
  - `dotenv` — 環境變數管理

### 2. 伺服器初始化（`src/server.js`）

建立 Express + Socket.io 伺服器，並啟用 CORS：

```js
const express = require('express');
const http = require('http');
const { Server } = require('socket.io');
require('dotenv').config();

const app = express();
const httpServer = http.createServer(app);
const io = new Server(httpServer, {
  cors: { origin: '*' }
});

require('./socket')(io);

const PORT = process.env.PORT || 3000;
httpServer.listen(PORT, () => {
  console.log(`Chat server running on port ${PORT}`);
});

module.exports = { app, httpServer };
```

### 3. Socket 事件設計（需實作以下事件）

#### 客戶端 → 伺服器（監聽）

| 事件名稱        | Payload                              | 說明                                 |
|-----------------|--------------------------------------|--------------------------------------|
| `join_room`     | `{ room, username }`                 | 加入指定聊天室                       |
| `leave_room`    | `{ room, username }`                 | 離開聊天室                           |
| `send_message`  | `{ room, username, text }`           | 傳送訊息到指定房間                   |
| `get_history`   | `{ room }`                           | 取得該房間最近 50 則歷史訊息         |
| `typing_start`  | `{ room, username }`                 | 通知其他人「正在輸入…」              |
| `typing_stop`   | `{ room, username }`                 | 取消「正在輸入」狀態                 |

#### 伺服器 → 客戶端（發送）

| 事件名稱           | Payload                                      | 說明                               |
|--------------------|----------------------------------------------|------------------------------------|
| `user_joined`      | `{ username, room, timestamp }`              | 廣播有人加入房間                   |
| `user_left`        | `{ username, room, timestamp }`              | 廣播有人離開房間                   |
| `new_message`      | `{ id, username, text, room, timestamp }`    | 廣播新訊息給房間內所有人           |
| `message_history`  | `[{ id, username, text, timestamp }]`        | 回傳訊息歷史給請求者               |
| `room_users`       | `[username, ...]`                            | 回傳目前房間內的使用者清單         |
| `user_typing`      | `{ username }`                               | 廣播「正在輸入」通知（排除自己）   |
| `user_stopped_typing` | `{ username }`                            | 廣播停止輸入通知                   |

## 範例

```js
// 客戶端連線（使用 socket.io-client 測試）
const { io } = require('socket.io-client');

const socket = io('http://localhost:3000', {
  auth: { username: 'Alice' }
});

// 加入房間
socket.emit('join_room', { room: 'general', username: 'Alice' });

// 收到歡迎廣播
socket.on('user_joined', ({ username, room }) => {
  console.log(`${username} 加入了 ${room}`); // "Alice 加入了 general"
});

// 傳送訊息
socket.emit('send_message', {
  room: 'general',
  username: 'Alice',
  text: '大家好！'
});

// 收到訊息
socket.on('new_message', ({ id, username, text, timestamp }) => {
  console.log(`[${timestamp}] ${username}: ${text}`);
  // "[2026-10-26T...] Alice: 大家好！"
});

// 取得歷史
socket.emit('get_history', { room: 'general' });
socket.on('message_history', (messages) => {
  console.log('歷史訊息：', messages);
});
```

---

## 提示

- `socket.join(room)` 讓該 socket 加入 Socket.io 的 room，之後可用 `io.to(room).emit(...)` 廣播給房間所有人
- `socket.to(room).emit(...)` 廣播給房間裡「除了自己以外」的所有人（適合用在 typing 通知）
- 取得目前房間人數：`io.sockets.adapter.rooms.get(roomName)?.size ?? 0`
- `socket.on('disconnect', ...)` 可處理使用者非預期斷線的清理邏輯
- 用 `socket.io-client` 套件在 Node.js 中撰寫整合測試，不需要真實瀏覽器

| WebSocket 雙向通訊         | 即時通知、聊天室、協作工具（Figma、Notion 等）        |

| 記憶體狀態管理             | 快取層概念（未來可替換為 Redis Pub/Sub）               |

## 進階挑戰（選做）

1. **持久化訊息**：將 `messageStore` 改為 PostgreSQL，重啟伺服器後歷史仍在
2. **私訊功能**：實作 `private_message` 事件，僅傳送給指定 socket（`io.to(socketId).emit(...)`）
3. **房間清單 API**：新增 `GET /api/rooms` REST 端點，回傳目前活躍的所有房間與人數
4. **JWT 驗證**：在 Socket.io middleware 中驗證 `socket.handshake.auth.token`，確認身份後才允許連線
5. **訊息已讀回條**：當訊息被房間內所有人看到時，emit `message_read` 事件給原始發送者
