# 第 5 週今日 Node.js 練習題：打造你的第一個 Express 伺服器

## 題目說明

使用 Express 框架建立一個簡單的書籍管理 API 伺服器。透過這個練習，你將學會如何定義路由、處理不同 HTTP 方法、以及回傳 JSON 資料，這些都是後端 API 開發的核心基礎。

## 技術要求

- **概念**：Express 路由（routing）、HTTP 方法（GET / POST / DELETE）、`req.params`、`req.body`、`res.json()`
- **需要的套件**：
  - `express`（`npm install express`）

## 具體任務

1. 建立 `server.js`，初始化一個 Express 應用程式並監聽 3000 埠。
2. 在記憶體中維護一個書籍陣列（每本書有 `id`、`title`、`author` 欄位）。
3. 實作以下三個路由：
   - `GET /books` — 回傳所有書籍的 JSON 陣列。
   - `POST /books` — 從 `req.body` 讀取 `title` 與 `author`，新增一本書（自動產生遞增 id），回傳新增的書籍物件（HTTP 201）。
   - `DELETE /books/:id` — 依 `id` 刪除指定書籍，找不到時回傳 HTTP 404 與錯誤訊息。
4. 啟動伺服器後用 `curl` 或 Postman 測試三個端點，確認回應正確。

## 範例

```js
// server.js

const express = require('express');
const app = express();
app.use(express.json());

let books = [
  { id: 1, title: '深入淺出 Node.js', author: '朴靈' },
];
let nextId = 2;

// GET /books
app.get('/books', (req, res) => {
  res.json(books);
});

// POST /books
app.post('/books', (req, res) => {
  const { title, author } = req.body;
  const book = { id: nextId++, title, author };
  books.push(book);
  res.status(201).json(book);
});

// DELETE /books/:id
app.delete('/books/:id', (req, res) => {
  const id = parseInt(req.params.id, 10);
  const index = books.findIndex(b => b.id === id);
  if (index === -1) {
    return res.status(404).json({ error: '找不到該書籍' });
  }
  books.splice(index, 1);
  res.json({ message: '刪除成功' });
});

app.listen(3000, () => console.log('伺服器運行中：http://localhost:3000'));
```

**測試指令範例**

```bash
# 取得所有書籍
curl http://localhost:3000/books

# 新增書籍
curl -X POST http://localhost:3000/books \
  -H "Content-Type: application/json" \
  -d '{"title":"JavaScript 高效全端開發","author":"Cody Lindsay"}'

# 刪除 id=1 的書籍
curl -X DELETE http://localhost:3000/books/1
```

## 提示

- 使用 `app.use(express.json())` 讓 Express 能解析 JSON 請求本體。
- `req.params.id` 取回的是字串，記得用 `parseInt()` 轉為數字再比對。
- 回傳 201 狀態碼表示「資源已成功建立」，是 REST 慣例。
- 使用 `Array.findIndex()` 方便同時取得索引以便 `splice()` 刪除。

## 學習重點

**與後端 API 的關聯**

Express 是 Node.js 生態系中最主流的 Web 框架。這三個路由直接對應到真實 REST API 的核心骨架：GET 讀取、POST 新增、DELETE 刪除。掌握路由定義、請求解析與 HTTP 狀態碼後，你就能快速延伸到資料庫整合（第 8 週）與身份驗證（第 9 週），讓 API 從玩具變成生產等級的服務。

## 進階挑戰（選做）

1. **PUT /books/:id** — 更新指定書籍的 `title` 或 `author`，完成完整的 CRUD 操作。
2. **輸入驗證** — 若 POST 請求缺少 `title` 或 `author` 欄位，回傳 HTTP 400 與具體錯誤訊息。
3. **查詢篩選** — 支援 `GET /books?author=朴靈`，依 `author` 參數過濾結果（使用 `req.query`）。
