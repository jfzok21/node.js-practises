# 第 4 週今日 Node.js 練習題：打造你的第一個 HTTP 伺服器

## 題目說明

本週進入 Node.js 最核心的能力之一——**使用內建 `http` 模組建立 HTTP 伺服器**。不借助任何框架，你將親手處理請求與回應，理解 Web 伺服器最底層的運作方式，為之後學習 Express 打下扎實基礎。

---

## 技術要求

- **概念**：`http.createServer`、`req.url`、`req.method`、`res.writeHead`、`res.end`、路由手動分派
- **需要的套件**：無（Node.js 內建即可）

---

## 具體任務

1. **建立 `server.js`**，使用 `http.createServer` 啟動一個監聽 **3000 埠**的伺服器。

2. 實作以下四條路由（只需支援 `GET`）：

   | 路由 | 回傳內容 |
   |------|----------|
   | `GET /` | 純文字：`歡迎來到我的伺服器！` |
   | `GET /about` | 純文字：`這是關於頁面。` |
   | `GET /json` | JSON：`{ "message": "Hello, JSON!", "week": 4 }` |
   | 其他所有路由 | 狀態碼 404 + 純文字：`找不到頁面` |

3. 根據回傳格式正確設定 **`Content-Type`** Header：
   - 純文字使用 `text/plain; charset=utf-8`
   - JSON 使用 `application/json`

4. 伺服器啟動後，在終端機印出：
   ```
   伺服器已啟動，監聽 http://localhost:3000
   ```

5. **用 `curl` 或瀏覽器**測試每條路由，確認回傳內容與狀態碼皆正確。

---

## 範例

```js
// server.js
const http = require('http');

const server = http.createServer((req, res) => {
  const { url, method } = req;

  if (method === 'GET' && url === '/') {
    res.writeHead(200, { 'Content-Type': 'text/plain; charset=utf-8' });
    res.end('歡迎來到我的伺服器！');

  } else if (method === 'GET' && url === '/about') {
    res.writeHead(200, { 'Content-Type': 'text/plain; charset=utf-8' });
    res.end('這是關於頁面。');

  } else if (method === 'GET' && url === '/json') {
    res.writeHead(200, { 'Content-Type': 'application/json' });
    res.end(JSON.stringify({ message: 'Hello, JSON!', week: 4 }));

  } else {
    res.writeHead(404, { 'Content-Type': 'text/plain; charset=utf-8' });
    res.end('找不到頁面');
  }
});

server.listen(3000, () => {
  console.log('伺服器已啟動，監聽 http://localhost:3000');
});
```

```bash
# 測試指令
curl http://localhost:3000/
curl http://localhost:3000/about
curl http://localhost:3000/json
curl -i http://localhost:3000/unknown   # 應看到 404
```

---

## 提示

- `req.url` 包含路徑（如 `/json`），`req.method` 包含 HTTP 動詞（如 `GET`、`POST`）。
- `res.writeHead(狀態碼, { Header物件 })` 必須在 `res.end()` **之前**呼叫。
- `res.end()` 只接受字串或 Buffer；物件需先用 `JSON.stringify()` 轉換。
- 可用 `curl -i` 查看回應 Header，確認 `Content-Type` 是否設定正確。

---

## 學習重點（跟後端 API 的關聯）

| 本週學到的 | 對應到 Express / REST API 的概念 |
|-----------|----------------------------------|
| `req.url` | `req.path`、路由參數 `req.params` |
| `req.method` | HTTP 動詞路由（`app.get`、`app.post`…） |
| `res.writeHead` + `res.end` | `res.status().json()` 的底層實作 |
| 手動 if/else 路由分派 | Express Router 的前身 |

親自用 `http` 模組寫一遍，能讓你更清楚 Express 的每個方法究竟在做什麼，未來遇到奇怪的 Header 問題或框架行為時，你就知道往哪個層次除錯。

## 進階挑戰（選做）

1. **支援 `POST /echo`**：讀取請求 Body（`req.on('data', ...)` + `req.on('end', ...)`），將收到的 JSON 原封不動回傳。

2. **新增 `/time` 路由**：回傳目前伺服器時間的 JSON，格式為 `{ "time": "2026-07-29T10:00:00.000Z" }`。

3. **計數器路由**：每次 `GET /count` 都讓一個伺服器端變數 `+1`，並回傳目前的計數值。想想看：重啟伺服器後計數會歸零嗎？這讓你思考**狀態管理**的重要性。
