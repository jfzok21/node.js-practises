# 第 5 週今日 Node.js 練習題：Express 基礎路由與請求處理

## 題目說明

使用 Express.js 建立一個簡單的「書籍管理 API」伺服器。透過這個練習，你將學習如何用 Express 定義路由、處理不同 HTTP 方法、讀取 URL 參數與 Query String，並回傳 JSON 回應。

---

## 技術要求

- **概念**：Express 路由（GET / POST / PUT / DELETE）、`req.params`、`req.query`、`req.body`、`res.json()`、`res.status()`
- **需要的套件**：
  ```bash
  npm install express
  ```

---

## 具體任務

1. **初始化專案**：在 `week5-express-books/` 資料夾內執行 `npm init -y`，並安裝 `express`。

2. **建立 `index.js`**，在記憶體中用一個陣列儲存書籍資料，初始包含至少 3 本書，每本書的格式如下：
   ```js
   { id: 1, title: '深入淺出 Node.js', author: '朴靈', year: 2013 }
   ```

3. **實作以下四個路由**：
   - `GET /books` — 回傳所有書籍（支援 `?author=xxx` 篩選）
   - `GET /books/:id` — 依 id 回傳單本書；找不到時回傳 `404`
   - `POST /books` — 新增一本書（從 `req.body` 讀取），回傳新增結果（`201`）
   - `DELETE /books/:id` — 刪除指定 id 的書；找不到時回傳 `404`

4. **加入 `express.json()` middleware**，讓伺服器能解析 JSON 請求 body。

5. 啟動伺服器監聽 port `3000`，並在終端機輸出 `伺服器已啟動：http://localhost:3000`。

---

## 範例

```js
// GET /books
// 回應：
[
  { "id": 1, "title": "深入淺出 Node.js", "author": "朴靈", "year": 2013 },
  { "id": 2, "title": "Node.js 設計模式", "author": "Mario Casciaro", "year": 2020 },
  { "id": 3, "title": "Learning Node.js", "author": "Marc Wandschneider", "year": 2017 }
]

// GET /books?author=朴靈
// 回應：
[{ "id": 1, "title": "深入淺出 Node.js", "author": "朴靈", "year": 2013 }]

// GET /books/99
// 回應（404）：
{ "error": "找不到 id 為 99 的書籍" }

// POST /books  (body: {"title":"Clean Code","author":"Robert C. Martin","year":2008})
// 回應（201）：
{ "id": 4, "title": "Clean Code", "author": "Robert C. Martin", "year": 2008 }

// DELETE /books/2
// 回應：
{ "message": "書籍 id 2 已成功刪除" }
```

---

## 提示

- 用 `let nextId = 4` 這類變數自動遞增 id，避免 id 重複。
- `req.query.author` 可取得 `?author=xxx` 的值；記得用 `Array.filter()` 篩選。
- `req.params.id` 取到的是**字串**，記得用 `Number()` 或 `parseInt()` 轉型再與數字比較。
- 可用 `curl` 或 Postman / Insomnia 測試 POST 和 DELETE。

  ```bash
  # 測試新增
  curl -X POST http://localhost:3000/books \
    -H "Content-Type: application/json" \
    -d '{"title":"Clean Code","author":"Robert C. Martin","year":2008}'

  # 測試刪除
  curl -X DELETE http://localhost:3000/books/2
  ```

## 學習重點（跟後端 API 的關聯）

Express 是 Node.js 生態系中最主流的 Web 框架，也是幾乎所有 REST API 的起點。這個練習涵蓋的四個 HTTP 動詞（GET / POST / PUT / DELETE）正好對應 CRUD 操作，是後端 API 開發的基礎骨架。學會在 Express 中正確使用 `req` / `res` 物件，以及 middleware 的概念，往後整合資料庫（PostgreSQL）、JWT 驗證等功能時會更加順手。

## 進階挑戰（選做）

1. **新增 `PUT /books/:id` 路由**：讀取 `req.body` 更新指定書籍的資料，若 id 不存在則回傳 `404`。
2. **加入基本輸入驗證**：POST 時若 `title` 或 `author` 欄位為空，回傳 `400` 錯誤訊息。
3. **將初始書籍資料改從 `books.json` 檔案讀取**（使用 `fs.readFileSync`），讓資料與程式碼分離。
4. **使用 Express Router**：把書籍相關路由拆到 `routes/books.js`，再在 `index.js` 中 `app.use('/books', booksRouter)` 掛載。
