# 第 11 週今日 Node.js 練習題：使用 Multer 實作多種檔案上傳策略

## 題目說明

在真實的後端 API 中，檔案上傳是非常常見的需求，例如使用者頭像、商品圖片、PDF 合約等。本題將帶你使用 `multer` 套件，在 Express 中實作三種常見的上傳場景：單一檔案、多檔案，以及限制類型與大小的防護機制。

---

## 技術要求

- **概念**：multipart/form-data、Middleware 串接、檔案驗證、磁碟儲存 vs. 記憶體儲存
- **需要的套件**：
  - `express`
  - `multer`

```bash
npm init -y
npm install express multer
```

---

## 具體任務

1. **設定 Multer 磁碟儲存引擎**
   - 上傳目錄為 `uploads/`（不存在時自動建立）
   - 檔名格式：`<timestamp>-<原始檔名>`（避免重名覆蓋）

2. **建立三個 API 路由**

   | 方法 | 路徑 | 說明 |
   |------|------|------|
   | POST | `/upload/single` | 上傳單一圖片（欄位名稱 `avatar`） |
   | POST | `/upload/multiple` | 最多上傳 5 張圖片（欄位名稱 `photos`） |
   | POST | `/upload/document` | 僅接受 PDF，大小上限 2MB |

3. **在每個路由加上檔案過濾器（fileFilter）**
   - `/upload/single` 與 `/upload/multiple`：只允許 `image/jpeg`、`image/png`、`image/webp`
   - `/upload/document`：只允許 `application/pdf`
   - 不符合類型時，回傳 `400` 並說明原因

4. **統一錯誤處理 Middleware**
   - 捕捉 `multer.MulterError`（例如超過檔案數量限制、超過大小上限）
   - 回傳格式：`{ "error": "描述錯誤的訊息" }`

5. **成功回應格式（JSON）**
   ```json
   {
     "message": "上傳成功",
     "files": [
       {
         "originalname": "photo.png",
         "filename": "1726444800000-photo.png",
         "size": 204800,
         "mimetype": "image/png",
         "path": "uploads/1726444800000-photo.png"
       }
     ]
   }
   ```

## 範例

```js
// server.js 骨架

const express = require('express');
const multer  = require('multer');
const path    = require('path');
const fs      = require('fs');

const app = express();
const UPLOAD_DIR = 'uploads';

// 確保目錄存在
if (!fs.existsSync(UPLOAD_DIR)) fs.mkdirSync(UPLOAD_DIR);

// --- 磁碟儲存設定 ---
const storage = multer.diskStorage({
  destination: (req, file, cb) => cb(null, UPLOAD_DIR),
  filename:    (req, file, cb) => {
    const unique = `${Date.now()}-${file.originalname}`;
    cb(null, unique);
  },
});

// --- 圖片過濾器 ---
const imageFilter = (req, file, cb) => {
  const allowed = ['image/jpeg', 'image/png', 'image/webp'];
  if (allowed.includes(file.mimetype)) {
    cb(null, true);
  } else {
    cb(new Error(`不支援的檔案類型：${file.mimetype}`), false);
  }
};

// --- 各路由的 multer 實例 ---
const uploadSingle   = multer({ storage, fileFilter: imageFilter });
const uploadMultiple = multer({ storage, fileFilter: imageFilter });
const uploadPdf      = multer({
  storage,
  limits: { fileSize: 2 * 1024 * 1024 }, // 2 MB
  fileFilter: (req, file, cb) => {
    if (file.mimetype === 'application/pdf') {
      cb(null, true);
    } else {
      cb(new Error('只接受 PDF 檔案'), false);
    }
  },
});

// --- 路由 ---
app.post('/upload/single', uploadSingle.single('avatar'), (req, res) => {
  // TODO: 回傳成功 JSON
});

app.post('/upload/multiple', uploadMultiple.array('photos', 5), (req, res) => {
  // TODO: 回傳成功 JSON
});

app.post('/upload/document', uploadPdf.single('document'), (req, res) => {
  // TODO: 回傳成功 JSON
});

// --- 統一錯誤處理 ---
app.use((err, req, res, next) => {
  // TODO: 判斷 multer.MulterError 並回傳適當訊息
});

app.listen(3000, () => console.log('伺服器運行於 http://localhost:3000'));
```

## 提示

- `req.file` 是單一檔案，`req.files` 是陣列，別搞混。
- `multer.MulterError` 有 `code` 屬性，常見值：
  - `LIMIT_FILE_SIZE` — 檔案超過大小限制
  - `LIMIT_FILE_COUNT` — 檔案數量超過上限
  - `LIMIT_UNEXPECTED_FILE` — 欄位名稱不符
- 使用 `curl` 或 Postman 測試：
  ```bash
  # 上傳單一圖片
  curl -X POST http://localhost:3000/upload/single \
    -F "avatar=@./test.jpg"

  # 上傳多張圖片
  curl -X POST http://localhost:3000/upload/multiple \
    -F "photos=@./a.jpg" -F "photos=@./b.png"

  # 上傳 PDF
  curl -X POST http://localhost:3000/upload/document \
    -F "document=@./report.pdf"
  ```

## 學習重點（跟後端 API 的關聯）

檔案上傳涉及 `multipart/form-data` 編碼，這與一般 JSON body 完全不同，需要專用 middleware 解析。Multer 在真實 API 中常見於：

- **使用者大頭照更新**（PUT `/users/me/avatar`）
- **電商商品圖片管理**（POST `/products/:id/images`）
- **KYC / 文件審核**（POST `/verifications/documents`）

在正式環境中，`uploads/` 目錄通常會換成雲端儲存（AWS S3、Google Cloud Storage），multer 提供 `multer-s3` 等儲存引擎支援直接串接，概念完全相同。

## 進階挑戰（選做）

1. **圖片尺寸驗證**：使用 `sharp` 套件，在儲存前確認圖片寬高不超過 4096×4096，否則拒絕上傳。
2. **上傳進度回報**：整合 `Server-Sent Events (SSE)`，讓前端即時顯示上傳百分比。
3. **暫存轉雲端**：先用 `multer.memoryStorage()` 將檔案存入記憶體，再上傳至模擬的 S3（本地可用 `minio`）。
4. **限速保護**：結合 `express-rate-limit`，對 `/upload/*` 路由設定每分鐘最多 10 次請求。
