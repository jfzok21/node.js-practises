# 第 4 週今日 Node.js 練習題：打造迷你 HTTP 路由伺服器

## 題目說明

使用 Node.js 內建的 `http` 模組，不依賴任何第三方框架，手刻一個能處理多條路由的 HTTP 伺服器。這個練習幫助你理解 Express、Fastify 等框架底層究竟做了什麼。

---

## 技術要求

- **概念**：`http.createServer`、`req.url`、`req.method`、`res.writeHead`、`res.end`、JSON 回應
- **需要的套件**：無（僅使用 Node.js 內建模組）

---

## 具體任務

1. **建立伺服器**  
   使用 `http.createServer` 建立一個監聽在 `3000` 埠的伺服器。

2. **實作以下路由**

   | 方法   | 路徑        | 回應內容                                         |
   |--------|-------------|--------------------------------------------------|
   | GET    | `/`         | `{ "message": "歡迎來到迷你 API！" }`            |
   | GET    | `/ping`     | `{ "status": "pong" }`                           |
   | GET    | `/users`    | `{ "users": ["Alice", "Bob", "Charlie"] }`       |
   | POST   | `/echo`     | 將收到的 JSON body 原封不動回傳                  |
   | 其他   | 任何路徑    | HTTP 404，`{ "error": "Route not found" }`       |

3. **正確設定 Content-Type**  
   所有回應皆須加上 `Content-Type: application/json` header。

4. **POST `/echo` 要能讀取 request body**  
   使用 `data` 與 `end` 事件接收 body，再解析成 JSON 回傳。

5. **測試你的伺服器**  
   使用 `curl` 或任何 HTTP 客戶端工具測試所有路由，確保每條路由皆回傳正確結果。

---

## 範例

```js
// 啟動伺服器
// node server.js

// 測試指令
// curl http://localhost:3000/
// → { "message": "歡迎來到迷你 API！" }

// curl http://localhost:3000/users
// → { "users": ["Alice", "Bob", "Charlie"] }

// curl -X POST http://localhost:3000/echo \
//   -H "Content-Type: application/json" \
//   -d '{"name": "Alice", "age": 30}'
// → { "name": "Alice", "age": 30 }

// curl http://localhost:3000/not-exist
// → { "error": "Route not found" }  (HTTP 404)
```

---

## 提示

- `req.url` 包含路徑（例如 `/users`），`req.method` 包含 HTTP 動詞（`GET`、`POST`...）。
- 可用 `if / else if` 或 `switch` 比對路由，這正是 Express Router 的簡化版原理。
- 讀取 POST body 時，資料是以 chunk 方式流入：
  ```js
  let body = '';
  req.on('data', chunk => { body += chunk; });
  req.on('end', () => {
    const parsed = JSON.parse(body);
    // 在這裡處理 parsed
  });
  ```
- 別忘記在呼叫 `res.end()` 前先呼叫 `res.writeHead(statusCode, headers)`。
- `JSON.stringify(object)` 可將物件轉為字串再傳入 `res.end()`。

---

## 學習重點（與後端 API 的關聯）

- **框架底層原理**：Express 的 `app.get()`、`app.post()` 本質上就是在 `http.createServer` 的 callback 裡比對 `req.url` 和 `req.method`。了解這層後，框架的 magic 就不再神秘。
- **Request / Response 生命週期**：header 必須在 body 之前送出、`res.end()` 只能呼叫一次——這些限制在框架中同樣存在，只是被封裝起來了。
- **Streaming body**：POST body 是以 stream 方式送達，這解釋了為什麼後端需要 body-parser 類的 middleware（例如 Express 的 `express.json()`）。
- **HTTP 狀態碼語義**：手動撰寫 `404`、`200` 能加深對 HTTP 協議語義的直覺。

---

## 進階挑戰（選做）

1. **支援 Query String**：讓 `GET /users?limit=2` 只回傳前 N 個使用者。提示：使用 `new URL(req.url, 'http://localhost')` 解析 query string。
2. **靜態路由表**：用物件或 Map 取代 `if/else`，設計一個 `{ "GET /users": handler, "POST /echo": handler }` 的路由表結構，讓新增路由更優雅。
3. **錯誤處理**：當 POST body 不是合法 JSON 時，回傳 HTTP 400 與 `{ "error": "Invalid JSON" }`。
4. **模組化**：將路由邏輯拆成獨立的 `router.js`，主程式只負責啟動伺服器，練習 `module.exports` 的應用。
