# 第 11 週今日 Node.js 練習題：使用 Multer 實作檔案上傳 API

## 題目說明

使用 Express 與 `multer` 套件，建立一個可接收圖片上傳的 REST API。練習處理 `multipart/form-data` 請求，對上傳檔案做型別與大小驗證，並在伺服器端儲存檔案後回傳檔案資訊。

---

## 技術要求

- **概念**：multipart/form-data、Multer 中介軟體、檔案驗證、靜態檔案服務
- **需要的套件**：`express`、`multer`

---

## 具體任務

1. **初始化專案並安裝套件**
   ```bash
   mkdir upload-api && cd upload-api
   npm init -y
   npm install express multer
   ```

2. **設定 Multer 儲存引擎**
   - 使用 `multer.diskStorage` 將上傳檔案儲存到 `uploads/` 資料夾
   - 自訂 `filename`：格式為 `{timestamp}-{原始檔名}`（例如 `1726732800000-photo.jpg`）

3. **加入檔案驗證**
   - 只允許 `image/jpeg`、`image/png`、`image/gif` 三種 MIME 類型
   - 若型別不符，回傳 `400 Bad Request` 與錯誤訊息
   - 限制單檔最大 **2 MB**

4. **建立上傳路由**
   - `POST /upload`：接受單一欄位 `avatar` 的檔案上傳
   - 成功時回傳：
     ```json
     {
       "message": "上傳成功",
       "file": {
         "originalname": "photo.jpg",
         "filename": "1726732800000-photo.jpg",
         "mimetype": "image/jpeg",
         "size": 204800,
         "url": "/uploads/1726732800000-photo.jpg"
       }
     }
     ```

5. **提供靜態檔案存取**
   - 使用 `express.static` 讓 `/uploads/*` 路徑可直接存取已上傳的圖片

6. **測試 API**
   使用 `curl` 測試：
   ```bash
   curl -X POST http://localhost:3000/upload \
     -F "avatar=@/path/to/image.jpg"
   ```

## 範例

```js
// server.js
const express = require('express');
const multer  = require('multer');
const path    = require('path');
const fs      = require('fs');

const app = express();

// 確保上傳資料夾存在
const uploadDir = path.join(__dirname, 'uploads');
if (!fs.existsSync(uploadDir)) fs.mkdirSync(uploadDir);

// 設定儲存引擎
const storage = multer.diskStorage({
  destination: (req, file, cb) => cb(null, uploadDir),
  filename:    (req, file, cb) => cb(null, `${Date.now()}-${file.originalname}`),
});

// 檔案過濾器
const fileFilter = (req, file, cb) => {
  const allowed = ['image/jpeg', 'image/png', 'image/gif'];
  if (allowed.includes(file.mimetype)) {
    cb(null, true);
  } else {
    cb(new Error('只接受 JPEG、PNG、GIF 圖片'), false);
  }
};

const upload = multer({
  storage,
  fileFilter,
  limits: { fileSize: 2 * 1024 * 1024 }, // 2 MB
});

// 靜態檔案
app.use('/uploads', express.static(uploadDir));

// 上傳路由
app.post('/upload', upload.single('avatar'), (req, res) => {
  if (!req.file) return res.status(400).json({ error: '未收到檔案' });
  res.json({
    message: '上傳成功',
    file: {
      originalname: req.file.originalname,
      filename:     req.file.filename,
      mimetype:     req.file.mimetype,
      size:         req.file.size,
      url:          `/uploads/${req.file.filename}`,
    },
  });
});

// 全域錯誤處理（含 Multer 錯誤）
app.use((err, req, res, next) => {
  if (err instanceof multer.MulterError) {
    if (err.code === 'LIMIT_FILE_SIZE') {
      return res.status(400).json({ error: '檔案大小超過 2 MB 限制' });
    }
  }
  res.status(400).json({ error: err.message });
});

app.listen(3000, () => console.log('Server running on port 3000'));
```

---

## 提示

- Multer 的 `fileFilter` 只能拒絕檔案（傳入 `false`），**不會自動回傳 HTTP 錯誤**；你需要在路由或全域錯誤處理中判斷 `req.file` 是否存在。
- `multer.MulterError` 是 Multer 自訂的錯誤類別，可用 `instanceof` 判斷並區分超過大小限制（`LIMIT_FILE_SIZE`）等狀況。
- 部署到正式環境時，請考慮使用 **AWS S3** 或 **Cloudinary** 取代本機儲存；`multer-s3` 套件可直接配合 Multer 的儲存引擎介面使用。

## 學習重點（跟後端 API 的關聯）

| 概念 | 實際應用場景 |
|------|-------------|
| `multipart/form-data` | 用戶頭像上傳、文件附件、履歷 PDF 上傳 |
| 檔案型別驗證 | 防止惡意執行檔偽裝成圖片上傳 |
| 檔案大小限制 | 避免磁碟空間被濫用或 DoS 攻擊 |
| 靜態資源服務 | CDN 回源、圖片預覽 URL |
| Multer 儲存引擎 | 可替換為雲端儲存（S3、GCS）而不改動路由邏輯 |

## 進階挑戰（選做）

1. **多檔上傳**：改用 `upload.array('photos', 5)` 允許一次上傳最多 5 張圖片，並在回應中回傳所有檔案資訊的陣列。

2. **自動壓縮圖片**：搭配 `sharp` 套件，在存檔前將圖片縮放至寬度最大 800px，並轉換為 `webp` 格式以節省空間。

3. **刪除上傳檔案**：新增 `DELETE /uploads/:filename` 路由，使用 `fs.unlink` 刪除指定檔案，並處理檔案不存在的情況（回傳 404）。
